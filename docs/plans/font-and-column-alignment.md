# 코드블록 열 맞춤과 편집 글꼴 — 보류 중인 과제

- 작성일: 2026-10-09
- 성격: 기록용. 구현은 하지 않았고, 아래 결정이 나면 별도 요청으로 진행한다.
- 관련 문서: [editor-input-improvements.md](editor-input-improvements.md) (항목 2-c Tab 4칸 덩어리, 항목 6 제목 막대 어긋남)

## 문제 한 줄 요약

고정폭 글꼴이어도 **한글이 섞인 줄은 열이 어긋날 수 있다.** 영문·숫자·기호만 있는 줄은 맞는다.

## 현재 상태 (코드를 읽어 확인한 것, 화면에서 폭을 재서 확인한 것은 아님)

| 항목 | 현재 |
|---|---|
| 편집 모드 글꼴 | `--mono` = `ui-monospace, Consolas, monospace` (`src/index.css:14`, `src/App.css` 의 `.editor-textarea`) |
| 뷰어 코드블록 글꼴 | 같은 `--mono`, `white-space: pre` (`.wiki-code`) |
| 뷰어 일반 글 글꼴 | `--sans` = `Pretendard`, 시스템 기본, `Segoe UI`, `Malgun Gothic` 순. Pretendard 파일은 앱에 들어 있지 않아 이 PC 에 설치돼 있어야 쓰인다 |
| Tab 키 | 공백 4칸을 넣는다. 진짜 탭 문자(`\t`)는 넣지 않는다 |
| `tab-size` | 앱 CSS 에 설정 없음 → 붙여넣은 탭 문자는 기본 8칸 너비로 보인다 |
| 한글 폭 | Consolas 에는 한글 글리프가 없어 시스템이 대신 채우는 글꼴로 그려진다. 그 폭이 영문 2칸과 정확히 같지 않으면 한글이 하나 늘 때마다 열이 조금씩 밀린다 |

## 후보 해결책

1. **한글이 들어 있는 고정폭 글꼴을 `--mono` 맨 앞에 추가** (D2Coding, 나눔고딕코딩 등). 한글 폭이 영문의 정확히 2배라 열이 맞는다. 설치돼 있지 않은 PC 에서는 지금과 같게 보인다.
   - 이 PC 에 설치돼 있는지는 아직 확인하지 않았다.
2. **글꼴 파일을 앱에 넣어 배포.** 어느 PC 에서나 같게 보이지만 글꼴 라이선스 확인과 패키지 크기 증가가 따른다.
3. **편집 글꼴을 설정에서 고르게 하기.** 1번의 확장. 설치된 글꼴 목록을 읽어 고르게 한다.
4. **`tab-size: 4` 를 `.wiki-code` 와 편집기에 추가.** 붙여넣은 탭 문자가 4칸으로 보이게 한다. 한 줄 CSS 이고 위험이 낮다. (진짜 탭 문자를 Tab 키로 넣는 것은 별개의 결정이며 2-c 에서 방식 A 로 정했다.)

## 하지 않기로 한 것

- 맑은 고딕을 코드블록·편집 글꼴로 쓰는 것: 비례폭 글꼴이라 영문·숫자 폭이 글자마다 달라 열 맞춤이 불가능하다.
- 편집 모드에서 코드블록 안에서만 글꼴을 바꾸는 것: `textarea` 는 칸 전체가 글꼴 하나다. 편집기 교체(6-3)를 하지 않는 한 불가능하다.

## 먼저 확인할 것

- 이 PC 에 설치된 고정폭 글꼴 목록.
- 한글이 섞인 샘플 줄(`이름    나이` / `Kim     30`)로 현재 열이 실제로 얼마나 어긋나는지 화면에서 측정.
- 글꼴을 바꾸면 줄이 접히는 위치가 달라지므로 **제목 막대 어긋남 진단(6-1)과 함께** 보는 것이 안전하다.
