# 문제 해결 기록 (목차)

버그를 고칠 때마다 증상 → 원인 → 해결 순서로 남긴다. 자세한 코드 설명은 `docs/features/`에 둔다.
150줄을 넘어서 영역별 파일로 나눴다(`docs/troubleshooting/`). **새 기록은 해당 영역 파일의 맨 위에 추가하고, 이 목차에도 한 줄을 넣는다.** 영역이 마땅치 않으면 새 파일을 만든다.

## 문법 변환·뷰어 표시

파일: [`troubleshooting/syntax-viewer.md`](troubleshooting/syntax-viewer.md) — 본문 문법이 화면에 그려지는 방식(변환기·표·코드·각주·목차)에서 생긴 문제

- 본문 문법이 엉뚱하게 변환됨: 코드·곱셈의 `*`, 목차 기호, `[[A&B]]`, 각주 안 `[[링크]]` 등 (2026-11-19)

## 편집 모드(편집창·제목 강조·찾기·점프)

파일: [`troubleshooting/editor.md`](troubleshooting/editor.md) — 편집창, 제목 강조 배경, 줄 위치 계산, 찾기 칸에서 생긴 문제

- 편집창 아래 여백을 칸 높이만큼 주면 textarea 가 칸 밖으로 삐져나옴 (2026-10-07, 출시 전에 발견)
- 편집 모드 제목 강조가 문서 아래로 갈수록 한 줄에서 몇 줄씩 어긋남 (2026-10-12)
- 편집 모드 제목 강조 배경이 엉뚱한 줄에 겹쳐 보임 (2026-10-02)
- 찾기 칸에 글을 치면 문서의 선택된 글이 덮어써짐 (2026-10-15)

## 표 편집기

파일: [`troubleshooting/table-editor.md`](troubleshooting/table-editor.md) — 표 편집기 창의 키 이동·동작에서 생긴 문제

- 표 편집기에서 Tab 을 누르면 오른쪽에 셀이 있는데도 바로 아래 행으로 내려감 (2026-10-07)

## 상용구·추천

파일: [`troubleshooting/snippets.md`](troubleshooting/snippets.md) — 상용구 등록·저장·추천 팝업에서 생긴 문제

- 코드블록에서 `NAME` 을 치면 `E` 로 END·ERD·ELSE 가 추천됨 (2026-10-07)
- 대소문자만 다른 상용구(`MYSQL` / `mysql`)를 같이 등록할 수 없음 (2026-10-07)
- 상용구 단축어 `*`가 `_`로 바뀌어 저장됨 (2026-10-07)
- 추천 팝업·[편집] 점프 위치가 긴 줄 문서에서 몇 줄씩 틀림 (2026-10-12)

## 창·포커스·시작 속도

파일: [`troubleshooting/window-performance.md`](troubleshooting/window-performance.md) — 창 포커스, 깜빡임, 시작 속도에서 생긴 문제

- 사이드바에서 문서를 누를 때마다 뒤에 있는 다른 앱(클로드 앱 등)이 깜빡이며 비침 (2026-10-12)
- 앱을 켜고 클릭할 수 있기까지 15초 가까이 걸림 (2026-10-14)

## 문서·폴더 관리

파일: [`troubleshooting/documents.md`](troubleshooting/documents.md) — 문서·폴더 이름 바꾸기와 링크 따라가기에서 생긴 문제

- 주인공 폴더 이름을 두 번째로 바꾸면 등장인물의 "00" 문서가 안 따라감 (2026-10-03)
