# 줄 이동 (Ctrl+Alt+↑ / ↓)

## 한 줄 요약

문서 편집 모드에서 **Ctrl+Alt+↑** 를 누르면 현재 줄이 한 줄 위로, **Ctrl+Alt+↓** 를 누르면 한 줄 아래로 옮겨 간다. 글을 여러 줄 선택했으면 선택에 걸친 줄 **전체가 함께** 움직인다. VS Code 의 "줄 위/아래로 이동"과 같다.

## 쓰는 법

| 하고 싶은 일 | 방법 |
|---|---|
| 한 줄 옮기기 | 옮길 줄 아무 곳에 커서를 두고 **Ctrl+Alt+↑ / ↓** |
| 여러 줄 옮기기 | 줄들을 드래그로 선택하고 **Ctrl+Alt+↑ / ↓** (선택은 그대로 유지되어 이어서 계속 옮길 수 있다) |
| 계속 옮기기 | 키를 계속 누르거나 반복해서 누른다 |
| 되돌리기 | **Ctrl+Z** — 한 번 옮긴 것이 한 단계로 되돌아간다 |

예: 아래처럼 `나나` 줄에 커서를 두고 Ctrl+Alt+↑ 를 누르면 —

```text
가가            나나
나나|    ->     가가
다다            다다
```

## 동작 규칙

- **이웃 줄과 자리를 바꾼다.** 옮기는 줄들 바로 위(아래) 한 줄과 서로 위치가 바뀐다. 문서의 다른 부분은 건드리지 않는다.
- **커서·선택이 따라간다.** 줄 안의 같은 위치에 커서가 남고, 선택 방향(앞->뒤 / 뒤->앞)도 유지된다.
- **맨 윗줄에서 ↑, 맨 아랫줄에서 ↓** 는 아무 일도 없다. 문서 끝에 빈 줄이 있으면 그 빈 줄도 한 줄로 본다.
- **줄 전체를 선택해서** 선택이 다음 줄 맨 앞에서 끝나는 흔한 경우, 그 다음 줄은 옮기는 대상이 아니다.
- **줄바꿈이 윈도 방식(CRLF)인 파일**은 CRLF 를 그대로 유지한다.
- **코드블록(```) 줄도 그냥 줄로 옮긴다.** 코드블록 여는·닫는 줄을 옮기면 블록 구조가 바뀔 수 있다(VS Code 도 같다). 되돌리려면 Ctrl+Z.
- 상용구·파일 추천 팝업이 떠 있을 때는 방향키가 팝업 조작이 우선이다. 한글 조합 중에는 반응하지 않는다. Shift·Meta 가 같이 눌린 조합은 해당하지 않는다.
- 입력칸의 되돌리기(Ctrl+Z)가 이어지도록 편집은 `replaceRange`(execCommand)로 한다.

## 알아 둘 점

- **일부 노트북·그래픽 드라이버**(인텔 그래픽 등)는 **Ctrl+Alt+방향키 를 화면 회전 단축키**로 쓴다. 키를 눌렀더니 화면이 돌아가거나 앱에 키가 오지 않으면 그래픽 설정에서 "단축키 사용 안 함"으로 끄면 된다(이 앱에서는 처리할 수 없다).
- VS Code 에서 Ctrl+Alt+↑/↓ 는 원래 "커서 추가"이고 줄 이동은 Alt+↑/↓ 다. 여기서는 요청한 대로 Ctrl+Alt+↑/↓ 를 줄 이동으로 쓴다.
- 표 편집기 칸 안에서는 쓰지 않는다(문서 편집기 전용).

## 확인한 것 (실제 Electron 창, 실제 키 입력)

줄 4개 문서에서: 커서 줄 Ctrl+Alt+↑ 로 위로 이동(커서 따라감) · 맨 위에서 ↑ 는 그대로 · ↓ 두 번 이동 · 두 줄 선택 후 ↑ / ↓ 두 번으로 선택한 두 줄이 함께 이동하고 선택 유지 · Ctrl+Z 한 번에 되돌아감 · Ctrl 만 / Alt 만 누른 방향키는 줄을 옮기지 않음.

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| 줄 이동 | 줄 하나(또는 여러 줄)를 잘라 붙이지 않고 위·아래로 한 칸씩 옮기는 것 |
| 이웃 줄 | 옮기는 줄 바로 위 또는 바로 아래의 줄 |
| CRLF | 윈도 방식의 줄바꿈 문자(`\r\n`). 맥·리눅스는 `\n` 하나 |
| 되돌리기 | 방금 한 편집을 취소하는 것(Ctrl+Z) |
