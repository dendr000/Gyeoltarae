# 표 편집기의 열 기준 정렬

## 한 줄 요약

표 편집기에서 **고른 열의 값으로 표의 줄(행)을 오름차순·내림차순으로 정렬**한다. 줄 전체가 함께 움직여서 한 열만 따로 정렬돼 데이터가 어긋나는 일이 없다.

## 쓰는 법

**둘째 줄 툴바**의 "정렬" 묶음에 있는 단추 두 개(오름차순 `A→Z`, 내림차순 `Z→A`)를 누른다. 단추에 마우스를 올리면 **어느 열을 기준으로, 몇 행부터 몇 행까지** 정렬하는지 보인다. (예: `B열 기준 오름차순 정렬 — 2~6행`)

- **기준 열**: 고른 범위의 **첫 열**이다. 한 칸을 골랐으면 그 칸의 열, 열 글자(A, B…)를 눌러 열 전체를 골랐으면 그 열이다.
- **정렬할 행**:
  - **한 칸이나 한 행만** 골랐으면 **표 전체** 행.
  - **여러 행**을 골랐으면(Shift+클릭 등) **그 행들만**. 나머지 행은 제자리에 있다.
  - "첫 번째 행을 헤더로"가 켜져 있으면 **맨 윗줄(헤더)은 빼고** 정렬한다.
- 정렬한 뒤에도 고른 범위는 그대로이므로 단추를 다시 눌러 반대 방향으로 바꿀 수 있다.

## 정렬 순서

**숫자 → 글자 → 빈 칸** 순이다(엑셀과 비슷). 빈 칸은 오름·내림 모두 맨 아래로 간다.

| 종류 | 규칙 | 예 |
|---|---|---|
| **숫자** | 크기 순서. 합계와 같은 숫자 읽기 규칙을 쓴다(쉼표·통화 기호·짧은 단위 허용, [table-editor-stats.md](table-editor-stats.md) 참고) | `2 < 9 < 10 < 100`, `900원 < 1,200원`, `-5 < 3.5` |
| **글자** | 영문(대소문자 구분 없음) → 한글(가나다순). 글자 안의 숫자는 크기로 본다 | `item2 < item10`, `A, b, 가, 나` |
| **빈 칸** | 맨 아래 (공백만 있는 칸, `[br]` 만 있는 칸 포함) | |

- 내림차순은 숫자·글자 부분을 거꾸로 한 것이다(글자 → 숫자 순, 빈 칸은 여전히 맨 아래).
- **같은 값끼리는 원래 순서를 지킨다**(내림차순에서도). 그래서 점수가 같은 사람들은 정렬 전 순서대로 남는다.
- 날짜 꼴 글자(`2024-01-05`)는 숫자가 아니라 글자로 비교하되 앞에서부터 숫자 크기로 본다. `2023-12-31 < 2024-01-05 < 2024-02-01` 처럼 날짜 순서가 맞다. 단 `2024. 1. 5.` 같은 형식 차이가 섞이면 맞지 않을 수 있다.

## 병합된 칸이 있을 때

- **세로 병합(rowspan)이 걸린 행**이 정렬 범위에 있으면 **정렬할 수 없다**. 행을 옮기면 병합이 찢어지기 때문이다. 단추가 비활성이 되고 이유가 보인다("병합을 먼저 나누세요"). 병합을 나누거나 병합이 없는 행만 골라서 정렬한다.
- **가로 병합(colspan)** 은 한 줄 안에서 끝나므로 괜찮다. 병합에 가려진 칸이 기준 열이면 병합의 **대표 칸 글자**로 비교한다.

## 알아 둘 점

- 첫 줄이 `'''굵게'''` 로 저장된 표를 불러오면 "첫 번째 행을 헤더로"가 **꺼진 채** 열릴 수 있다. 그 상태에서 정렬하면 **머리글도 정렬 대상**이 되어 아래로 내려간다. 머리글이 있는 표는 먼저 체크를 켠다. (정렬 단추의 설명에 `1~N행` 으로 범위가 보이므로 첫 행이 들어가는지 확인할 수 있다.)
- 정렬을 되돌리는 단추는 없다. 잘못 정렬했으면 반대 방향으로 한 번 더 정렬해도 원래 순서가 돌아오지는 않으니(같은 값끼리 순서가 바뀔 수 있음), 필요하면 모달을 "취소"하고 다시 연다.
- 정렬은 **편집기 안의 표**만 바꾼다. "적용"을 눌러야 문서에 반영된다.

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| **오름차순** | 작은 것에서 큰 것 순서. 숫자는 1, 2, 3…, 글자는 가나다…. |
| **내림차순** | 큰 것에서 작은 것 순서. 오름차순의 반대. |
| **기준 열** | 어느 열의 값을 보고 줄 순서를 정할지. 줄 전체가 그 값을 따라 움직인다. |
| **안정 정렬** | 값이 같은 줄들의 원래 순서를 바꾸지 않는 정렬. |

## 구현 위치

- `src/lib/tableSort.js` — `sortRows`(정렬), `canSortRows`(세로 병합 검사), `sortScope`(어느 행을 정렬할지). 화면과 분리한 순수 함수이며 받은 격자를 바꾸지 않는다. 숫자 읽기는 `tableStats.js` 의 `parseCellNumber` 를 쓴다.
- `src/components/tableStructureOps.js` — 정렬 범위·차단 이유 계산(`sortRange`, `sortBlockedReason`)과 동작. 단추 그리기는 `TableStructureToolbar.jsx`. 행을 다시 놓는 부분(`reorderRows`)은 행 이동과 함께 쓰는 `tableGrid.js` 의 공용 함수다.
- 테스트: `tests/lib/tableSort.test.js` — 숫자·글자·섞인 열·빈 칸, 영문 → 한글, 행 전체 이동, 범위 밖 행 고정, 가로 병합, 세로 병합 차단, 정렬 범위 계산, 원래 격자 불변.
