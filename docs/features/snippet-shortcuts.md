# 상용구 단축키 (Alt+T / Alt+Shift+T)

> 갈피(Galpi)의 같은 이름 단축키를 그대로 옮긴 것. 갈피 원본: `Galpi-Frontend/src/domains/memo/shared/hooks/useMemoEvents.js`.

## 한 줄 요약

에디터에서 `Alt+T`를 누르면 상용구 모달이 열리고, `Alt+Shift+T`를 누르면 "타이핑 중 추천 팝업"이 켜졌다 꺼진다. 마우스로 사이드바까지 가지 않아도 된다.

## 사용법

| 키 | 하는 일 |
|---|---|
| `Alt+T` | 상용구 모달을 연다. 글자를 선택해 두었으면 그 내용이 새 상용구의 **본문** 칸에 미리 채워지고, 커서는 **단축어** 칸에 놓인다(단축어만 입력하면 바로 등록). 선택이 없으면 빈 모달. |
| `Alt+Shift+T` | "타이핑 중 추천 팝업"을 켜거나 끈다. 모달의 같은 이름 체크박스와 같은 스위치다. |

툴바에도 같은 기능의 버튼이 있다.

- **상용구 등록** — `Alt+T`와 같다.
- **추천 팝업** — `Alt+Shift+T`와 같다. 켜져 있으면 강조색으로 칠해지고, 마우스를 올리면 지금 상태("켜짐/꺼짐")가 보인다. 단축키는 화면에 아무 표시도 안 남기므로 상태는 이 버튼 색으로 확인한다.

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| **상용구** | 짧은 단축어를 치면 긴 문장·서식으로 바꿔 주는 자동 입력 항목. |
| **타이핑 중 추천 팝업** | 단축어의 앞부분을 치는 동안 커서 옆에 뜨는 후보 목록. 방향키 + Tab/Enter로 고른다. |
| **스페이스바 자동 치환** | 단축어를 끝까지 치고 스페이스를 누르면 팝업 없이 바로 바뀌는 기능. 추천 팝업과는 **별개의 스위치**라서 `Alt+Shift+T`는 이쪽을 건드리지 않는다. |
| **물리 키(`e.code`)** | 어떤 글자가 나오는지와 상관없이 "키보드의 어느 키를 눌렀는가". 한글 입력 상태에서는 T 키를 눌러도 글자(`e.key`)가 `t`가 아니라 `ㅅ`으로 오기 때문에, 단축키 판별에 물리 키(`KeyT`)도 같이 본다. |

## 구현 위치

- `src/lib/snippetShortcuts.js` — 눌린 조합이 어느 동작인지 판별하는 순수 함수(`matchSnippetShortcut`). 화면 없이 테스트할 수 있도록 에디터에서 분리했다.
- `src/store/useAppStore.js` — 모달 열림 상태(`snippetModalOpen`, `snippetModalPrefillContent`)와 `toggleSnippetSuggest`. 사이드바 ⚙ 버튼과 단축키가 같은 모달을 쓰도록 사전 모달(`Alt+Shift+H`)과 같은 방식으로 스토어에 둔다.
- `src/components/EditorPane.jsx` — 키 핸들러와 툴바 버튼.
- 테스트: `tests/lib/snippetShortcuts.test.js`, `tests/store/modals.test.js`.

## 갈피와 다른 점

- 갈피는 한 가지 "자동 상용구" 스위치만 토글하지만, 결타래는 추천 팝업/스페이스바 치환이 독립된 두 스위치다. `Alt+Shift+T`는 갈피의 해당 스위치(`galpi-bp-preview`)에 대응하는 **추천 팝업** 쪽만 바꾼다.
- 갈피에서 `Alt+Shift+H`(사전 등록)와 짝이던 단축키 체계를 따라, 결타래의 `Alt+H`(사전 순환 치환) · `Alt+Shift+H`(사전 등록) · `Alt+T` · `Alt+Shift+T`가 한 벌로 맞춰졌다.

## 알아둘 것

- `Alt+H`/`Alt+Shift+H`는 아직 `e.key`로만 판별해서 **한글 입력 상태에서는 안 먹을 수 있다**(새 `Alt+T`/`Alt+Shift+T`만 물리 키도 본다). 한글 상태에서 안 되는 게 확인되면 같은 방식으로 고친다.
- Windows에서 `Alt+글자`가 메뉴와 겹치는지는 실제 exe에서 확인해야 한다(브라우저 미리보기에서는 확인 불가).
