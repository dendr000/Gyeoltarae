# 목록 들여쓰기 하위 항목 · `---` 구분선

## 한 줄 요약

목록의 하위 항목을 **들여써서** 만들 수 있고(`* 첫째` 아래 ` * 둘째`), 대시 3개(`---`)만 써도 구분선이 된다.

## 목록의 하위 항목

````text
* 첫째
 * 둘째
  * 셋째
* 다시 첫째
````

→ 첫째 아래에 둘째, 둘째 아래에 셋째가 들어가고, "다시 첫째"는 최상위로 돌아온다.

- **한 단계가 공백 몇 칸이든 상관없다.** 1칸·2칸·4칸·탭 모두 같은 결과다. "앞 항목보다 더 들어갔는가"만 본다. (탭은 공백 4칸으로 센다)
- 들여쓰기가 같으면 같은 단계(형제), 줄이면 그 폭이 나왔던 단계까지 바깥으로 돌아온다. `* a` → 4칸 들여쓴 `* b` → 2칸 들여쓴 `* c` 는 b, c 가 모두 a 의 하위 항목이다.
- 번호 목록(`1. 항목`)도 같다. 번호 목록 아래에 들여쓴 `*` 항목은 그 번호 항목의 하위가 된다.
- **별을 겹쳐 쓰는 예전 방식은 그대로 된다**: `* 첫째` / `** 둘째` / `*** 셋째`. 별이 2개 이상이면 그 개수가 곧 깊이이고 들여쓰기는 보지 않는다.
- 첫 항목부터 들여쓰여 있어도(` * a`) 최상위 단계다.
- 빈 줄로 목록이 끊기면 그 뒤 목록은 들여쓰기 기준을 새로 잡는다.
- 항목 다음 줄에 다른 문법 없이 텍스트만 오면 그 항목의 이어쓰기 줄이 되는 기존 규칙은 그대로다.

### 이전에 안 되던 이유

예전에는 줄 앞 공백을 무시하고 별의 개수로만 깊이를 정했다. 그래서 ` * 둘째`, `  * 셋째` 는 모두 별이 1개인 최상위 항목이 되어 평평하게 나열됐다.

## 구분선

| 쓰는 법 | 결과 |
|---|---|
| `---` | 가장 얇은 구분선 (새로 추가) |
| `----` | 가장 얇은 구분선 (기존, `---` 와 같음) |
| `-----` / `------` / `-------` | 점점 굵은 구분선 (대시 5·6·7개) |

- 줄에 대시만 있어야 한다. `--- 설명` 처럼 다른 글자가 같이 있으면 구분선이 아니다.
- 대시 2개(`--`)나 8개 이상은 구분선이 아니다.
- 목록 바로 아래에 `---` 를 쓰면 목록이 끝나고 구분선이 된다. (예전에는 `---` 가 목록 항목의 이어쓰기 글자로 빨려 들어갔다)
- 취소선 `--글자--` 와는 겹치지 않는다. (구분선은 줄 전체가 대시일 때만)

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| **들여쓰기** | 줄 맨 앞에 공백(또는 탭)을 넣어 글을 오른쪽으로 밀어 넣는 것. |
| **하위 항목(중첩 목록)** | 어떤 항목 안에 딸린 항목. 화면에서는 한 칸 안쪽에 다른 모양의 점으로 보인다. |
| **구분선** | 문단 사이를 가로로 가르는 줄. 가로줄(hr)이라고도 한다. |

## 알려진 한계

- 별이 2개 이상인 줄(`**`)은 들여쓰기를 보지 않는다. `**` 와 들여쓰기를 섞어 쓰면(예: 첫 항목 `*`, 다음에 들여쓴 `** x`) 별 개수가 우선이다.
- 예전에 일부러 앞 공백을 넣어 평평하게 나열한 목록(` * a`, `  * b`)은 이제 하위 항목으로 보인다.
