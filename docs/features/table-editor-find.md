# 표 편집기의 찾아 바꾸기 (Ctrl+F)

## 한 줄 요약

표 편집기 안에서 **Ctrl+F**(또는 둘째 줄 툴바의 돋보기 단추)로 찾아 바꾸기 바를 열어, 표의 칸들에서 글자를 찾고 바꾼다. 문서 편집기의 찾기 바와 같은 모양·키를 쓴다.

> **문서 본문**에서의 찾기는 이미 있다: 편집 모드에서 **Ctrl+F**(찾기), **Ctrl+Shift+F**(찾아 바꾸기). 그쪽은 README 의 "편집 화면 (탭 · 찾기)" 절을 보면 된다. 표 편집기는 별도 창(모달)이라 따로 만들었다.

## 쓰는 법

1. 표 편집기에서 **Ctrl+F** (Ctrl+Shift+F 도 같음). 입력칸에 글자를 골라 둔 채 누르면 그 글자로 바로 찾는다.
2. **찾을 글자**를 치면 일치하는 칸이 **연한 노란 바탕 + 주황 테두리**로 표시되고, 지금 가리키는 칸은 굵은 고리가 생긴다. 바의 숫자(`2/5`)는 "지금 몇 번째 / 전체 몇 곳"이다.
3. **Enter** = 다음, **Shift+Enter** = 이전. 이동하는 동안 커서는 **찾기 입력칸에 그대로** 있어서 Enter 를 계속 눌러 넘길 수 있다. 가리키는 칸은 "고른 칸"이 되고 화면에 보이게 스크롤된다.
4. **바꿀 글자**를 쓰고 **바꾸기**(또는 바꿀 글자 입력칸에서 Enter) = 지금 가리키는 **한 곳**만 바꾸고 다음으로 간다. **모두 바꾸기** = 모든 곳. 결과는 `1곳을 바꿨습니다` / `3곳을 바꿨습니다` 로 알려 준다.
5. **Esc** 또는 X 단추로 닫는다(모달 자체는 닫히지 않는다).

## 선택 범위 안에서만

- **여러 칸을 골라 둔 채 열면** "선택 범위만 (B2:D5)" 가 **자동으로 켜져서** 그 범위 안에서만 찾고 바꾼다(엑셀과 같음). 범위는 **여는 순간 붙잡아 둔다** — 찾은 칸으로 이동하면 고른 칸이 바뀌지만 찾을 범위는 줄어들지 않는다.
- 체크를 끄면 표 전체. 한 칸만 골라 둔 채 열면 처음부터 표 전체이고, 한 칸일 때는 체크를 켤 수 없다(범위가 한 칸이라서). 바를 연 채로 열 글자·행 번호·Shift+클릭으로 여러 칸을 고르면 체크를 켤 수 있고, 켠 순간의 범위가 붙잡힌다.

## 찾는 규칙

문서 편집기의 찾기와 같다.

- **대소문자를 구분하지 않는다.** `apple` 로 `Apple`, `APPLE` 도 찾는다.
- **글자 그대로 찾는다**(정규식이 아님). `.`, `*`, `(`, `[br]` 같은 기호도 그냥 글자다.
- 한 칸 안에서 여러 번 나오면 모두 센다. 겹치는 것은 앞에서부터 겹치지 않게 센다(`aaa` 에서 `aa` 는 한 번).
- **바꾼 글자에 `$` 같은 기호가 있어도 그대로 들어간다.** 바꿀 글자를 비우면 찾은 글자를 지운다.
- 찾은 글자를 포함한 글자로 바꿔도(`a` → `aa`) 한 번씩만 바뀐다.
- **병합에 가려진 칸**은 입력칸이 없으므로 찾지도 바꾸지도 않는다. 병합의 대표 칸은 찾는다.
- 칸의 서식(배경색·글자색·굵기·정렬)은 바꾸지 않는다. 글자만 바뀐다.
- 첫 줄(헤더)도 찾고 바꾼다.

## 알아 둘 점

- 바꾼 결과를 되돌리는 단추는 없다. 잘못 바꿨으면 같은 방식으로 되돌려 바꾸거나 모달을 "취소"하고 다시 연다. "적용"을 눌러야 문서에 반영된다.
- 대소문자 구분·단어 단위 같은 옵션은 문서 편집기의 찾기와 마찬가지로 없다.
- `바꾸기` 는 **칸 단위가 아니라 한 곳 단위**다. 한 칸 안에 두 곳이 있으면 한 번에 한 곳씩 바뀐다.

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| **일치(매치)** | 찾을 글자와 같은 글자가 나온 곳 하나. 한 칸에 여러 곳이 있을 수 있다. |
| **정규식** | 패턴으로 글자를 찾는 문법(`a.*b` 등). 여기서는 쓰지 않고 입력한 글자를 그대로 찾는다. |
| **범위** | 연속한 칸의 묶음. `B2:D5` 는 B열 2행부터 D열 5행까지. |

## 구현 위치

- `src/lib/tableFind.js` — 순수 함수. `findInGrid`(찾기), `replaceMatchInGrid`(한 곳), `replaceAllInGrid`(모두), `matchIndexAtOrAfter`(바꾼 뒤 다음 곳).
- `src/components/useTableFind.js` — 상태와 동작(열기·닫기·다음·이전·바꾸기·범위). 찾은 곳으로 갈 때 입력칸에 포커스를 주지 않는다.
- `src/components/TableFindBar.jsx` — 바 그리기(문서 편집기 찾기 바의 입력칸·단추 스타일 `.find-bar-*` 재사용). `TableEditorModal.jsx` — 칸 강조 클래스(`cell-match`, `cell-match-current`)와 Ctrl+F 키 처리.
- `src/index.css`(`--find-match`, `--find-match-border` 색, 라이트·다크 한 곳), `src/App.css`(`.table-find-bar`, `.cell-match`).
- 테스트: `tests/lib/tableFind.test.js`.
