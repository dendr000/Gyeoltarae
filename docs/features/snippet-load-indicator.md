# 상용구 불러오는 중 표시

## 한 줄 요약

상용구가 많아서 불러오는 데 시간이 걸릴 때, 화면 위쪽 **"저장됨" 표시 옆**에 **돌아가는 동그라미 + "상용구 750/4,000" + 얇은 게이지바**가 나타나고, 다 불러오면 사라진다. 예전에는 아무 표시가 없어서 앱이 멈춘 것처럼 보였다.

```text
 [뷰어][듀얼][편집]        (돌아가는 동그라미) 상용구 750/4,000 [▓▓░░░░]  저장됨   글꼴   다크
```

## 동작

- **언제 나오나**: 앱을 켜서 작업 폴더를 열 때, 그리고 파일이 바뀌어 색인을 다시 만들 때, 상용구가 **100개 이상**이면 나온다. 100개 미만이면 순식간에 끝나므로 표시를 띄우지 않는다(번쩍임 방지).
- **무엇을 보여 주나**: 몇 개째 읽는지(`750/4,000`), 게이지바(읽은 비율), 돌아가는 동그라미. 숫자는 50개마다 갱신된다.
- **어디에 나오나**: 위쪽 헤더 오른쪽, "저장됨"(저장 상태) 바로 왼쪽. 마우스를 올리면 "상용구 N개를 불러오는 중입니다. 끝나면 사라집니다." 안내가 뜬다.
- **끝나면**: 표시가 사라진다. 파일 하나를 못 읽어서 건너뛰어도, 읽다가 오류가 나도 반드시 사라진다.
- **색**: 앱의 강조색(보라)을 쓰고 라이트·다크 모드 모두 같은 색 변수를 따른다. 운영체제에서 "동작 줄이기"를 켜 두었으면 동그라미가 더 천천히 돈다.

## 구조

| 파일 | 역할 |
|---|---|
| `src/lib/snippetLoad.js` | 표시를 켤 기준 개수(100), 진행 알림 간격(50), 게이지 백분율 — 순수 함수 |
| `src/store/useAppStore.js` | `snippetLoad`(`{ done, total }` 또는 `null`). 색인을 만들 때 상용구를 읽는 반복문이 진행 상황을 알리고 끝나면(실패해도) `null` |
| `src/components/EditorHeader.jsx` | "저장됨" 옆의 표시(동그라미·글·게이지바) |
| `src/App.css` | `.snippet-load*` 모양과 회전 애니메이션 |
| `tests/lib/snippetLoad.test.js` | 계산·스토어 진행 알림·헤더 구조 시험 |

## 확인한 것 (실제 Electron 창)

상용구 1,200개가 든 작업 폴더를 열면 표시가 나타나 "상용구 0/1,200"에서 "650/1,200"(게이지 54%), "1,150/1,200"(95%)로 올라가고, 다 읽으면 사라짐(남아 있지 않음). 표시는 헤더 오른쪽 영역 안에 있고 동그라미가 실제로 회전 애니메이션을 탄다.

## 알아 둘 것

- 파일 변경 때마다 색인을 다시 만드는 앱의 기존 동작 때문에, 상용구가 100개 이상이면 **글을 고쳐 저장된 뒤에도** 색인을 다시 만드는 동안 이 표시가 잠깐씩 나타날 수 있다. 상용구를 실제로 다시 읽고 있다는 뜻이다.
- 이 표시는 **상용구 읽기**만 보여 준다. 문서 전체를 읽는 단계(첫 색인의 다른 부분)에는 아직 표시가 없다.
- 상용구를 파일 하나씩 읽는 방식이라 개수가 많으면(수천 개) 실제로 오래 걸린다. 읽는 속도 자체를 빠르게 하는 일은 하지 않았다.

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| 상용구 | 짧은 이름을 치면 정해 둔 글로 바꿔 주는 기능(슬래시 명령도 상용구) |
| 색인(인덱스) | 문서·상용구 같은 데이터를 앱이 빨리 찾도록 미리 읽어 정리해 두는 것 |
| 게이지바 | 진행된 정도를 가로 막대의 채워진 길이로 보여 주는 표시 |
