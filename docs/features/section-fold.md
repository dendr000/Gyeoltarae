# 뷰어 문단 접기 (제목을 눌러 접고 펴기, `==# 제목 #==`)

## 한 줄 요약

뷰어 모드에서 **제목을 누르면 그 아래 내용(다음 같은 급 이상의 제목 앞까지)이 접히고**, 다시 누르면 펴진다. 글에 `==# 제목 #==` 로 쓰면(나무위키와 같은 문법) **처음부터 접힌 채로** 보인다. 편집 모드에서는 접지 않는다(편집창은 글자를 그대로 보여 주는 입력칸이라서).

## 쓰는 법

| 하고 싶은 일 | 방법 |
|---|---|
| 문단 접기/펴기 | 뷰어에서 제목(글자·빈 줄 어디든)을 누른다. 왼쪽의 화살표가 `v`(펼침) / `>`(접힘)로 바뀐다 |
| 처음부터 접어 두기 | 제목의 여는 `=` 바로 뒤와 닫는 `=` 바로 앞에 `#` 를 쓴다: `==# 제목 #==` |
| 처음부터 펼쳐 두기 | 지금까지처럼 `== 제목 ==` |
| 숨은 제목으로 이동 | 본문 `[목차]`·오른쪽에 떠 있는 목차·`[[문서#제목]]` 링크로 가면 **접힌 문단을 자동으로 펴고** 이동한다 |

- 하위 제목(`=== … ===`)은 윗 제목의 구역 안에 들어가서 **윗 제목을 접으면 함께 접힌다.** 하위 제목마다 따로 접을 수도 있다.
- `==# 제목 #==` 의 급수는 `=` 의 개수 그대로다(`=# a #=` 1급, `====# a #====` 4급). 제목에 `#` 표시는 보이지 않고, 목차와 `[[#제목]]` 이동용 이름에도 `#` 가 들어가지 않는다.
- 여는 쪽에만 `#` 가 있는 `==# 제목 ==`, 띄어쓰기 없이 쓴 `==#태그==`, 제목 글자가 `#` 로 시작하는 `== #태그 ==` 는 접힘 표시가 아니라 제목 글자의 일부로 본다.
- **내용이 하나도 없는 제목**(바로 다음에 같은 급 이상의 제목이 오거나 문서 끝)은 접을 게 없어서 화살표도 없고 눌러도 아무 일이 없다.
- **각주 목록**은 문서 맨 아래에 따로 있어서 문단을 접어도 항상 보인다.
- 제목 안의 링크(`[[문서]]`, `[편집]`)를 누르면 접지 않고 링크가 제 일을 한다. 제목 글자를 드래그해서 고른 직후에는 접지 않는다.

## 접힘 상태를 기억하는 범위

- 사용자가 접거나 편 상태는 **문서별로 기억**한다(앱을 끄면 잊는다). 듀얼 모드에서 편집창에 글을 쓰면 뷰어가 계속 다시 그려지는데, 그때마다 접힌 상태가 처음 상태(글에 적힌 상태)로 돌아가지 않도록 다시 입힌다.
- 기억하는 기준은 제목의 이름(id)이다. 제목 글자를 고치면 그 제목에 대해서는 기억한 상태가 사라지고 글에 적힌 처음 상태로 돌아간다.
- 글에서 `==# 제목 #==` 를 `== 제목 ==` 로 바꿔도, 그 전에 사용자가 이미 누른 적이 있는 제목은 사용자가 정한 상태가 이긴다.

## 어떻게 만들었나 (구조)

1. 파서(`src/lib/wikiParser.js`)가 제목 줄을 읽을 때 `#` 표시를 인식하고, 제목을 바로 html 로 만들지 않고 "제목 조각"으로 모아 둔다.
2. 본문을 다 읽은 뒤 `src/lib/sectionFold.js` 의 `wrapSections` 가 제목 뒤의 내용을 `<div class="wiki-section-body">` 로 감싸고 하위 제목은 그 안에 넣는다. 내용이 있는 제목에만 `class="wiki-heading wiki-foldable" data-folded="true|false"` 를 붙인다.
3. CSS(`src/App.css`)는 `data-folded="true"` 인 제목 바로 뒤의 구역 본문을 숨기고 화살표를 그린다(CSS 로 그린 꺾쇠, 이미지 없음).
4. 뷰어(`src/components/ViewerPane.jsx`)가 제목 클릭을 받아 `data-folded` 를 뒤집는다(`src/lib/sectionFoldDom.js`). 접힘은 html 을 다시 만들지 않고 속성만 바꾸므로 스크롤 위치가 유지된다.

## 알려진 한계

- **편집 모드에서는 접을 수 없다.** 편집창은 입력칸 위에 강조 표시를 덧그리는 구조라서 특정 줄을 숨기려면 줄 번호·커서·검색 위치·타자기 스크롤을 모두 손봐야 한다. 대신 뷰어의 목차로 이동한다.
- 같은 이름의 제목이 한 문서에 둘 이상이면 접힘 상태를 기억하는 기준(id)이 겹칠 수 있다.
- 제목 글자 왼쪽에 화살표 자리(22px)가 생기므로 접을 수 있는 제목은 접을 수 없는 제목(내용이 없는 제목)보다 글자가 조금 오른쪽에서 시작한다.

## 확인한 것 (실제 Electron 창, 실제 마우스 입력)

- 처음 상태: `==# 닫힌 문단 #==` 만 접혀서 숨김, 하위 제목도 함께 숨김, 열린 문단은 보임, 내용 없는 제목은 접을 수 없음.
- 제목 클릭으로 펴짐 -> 한 번 더 클릭으로 접힘, 열린 문단 클릭으로 접힘.
- 접힌 문단 안의 제목으로 본문 `[목차]` 링크·떠 있는 목차를 눌러 이동하면 문단이 펴지고 그 제목이 화면에 보임.
- 각주 목록은 문단을 접어도 보임.
- 듀얼 모드에서 편집창에 글을 쓴 뒤에도 사용자가 접어 둔 문단이 접힌 채로 유지됨.

| `src/components/ViewerPane.jsx` | 제목 클릭 처리, 목차·문서 링크 이동 시 펴기, 접힘 상태 기억 |
| `src/components/FloatingToc.jsx` | 떠 있는 목차에서 이동할 때 `onJump` 로 숨은 제목을 펴고 이동 |

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| 문단 | 제목 하나와 그 아래 내용(다음 같은 급 이상의 제목 앞까지) |
| 구역(section) | 제목 뒤의 내용을 하나로 묶은 덩어리. 접으면 이 덩어리가 숨는다 |
| 하위 제목 | 더 작은 급(= 가 더 많은) 제목. `==` 아래의 `===` |
| `data-folded` | 제목이 접혔는지를 적어 두는 html 속성. `true` 면 접힘 |
| 다시 입힌다 | 화면이 다시 그려져 처음 상태로 돌아갔을 때, 사용자가 정해 둔 상태를 되돌려 놓는 것 |
