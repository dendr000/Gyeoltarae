# 줄 이름순 정렬 (Ctrl+`)

## 한 줄 요약

편집 모드에서 여러 줄을 드래그해 선택하고 **Ctrl+`** (백틱, 숫자 1 왼쪽 키)을 누르면 그 줄들이 **이름순**으로 정렬된다. 이미 오름차순이면 **내림차순**으로 뒤집으니, 같은 키를 다시 누르면 반대 방향이 된다.

## 사용 예

| 누르기 전 | 1번 누름 (오름차순) | 2번 누름 (내림차순) |
|---|---|---|
| `다람쥐` `문서10` `가지` `문서2` `나비` `banana` `apple` | `가지` `나비` `다람쥐` `문서2` `문서10` `apple` `banana` | `banana` `apple` `문서10` `문서2` `다람쥐` `나비` `가지` |

## 정렬 규칙

- **이름순은 왼쪽 폴더 트리와 같은 한국어 순서**다: 기호 < 숫자 < 한글 < 영문.
- **숫자는 크기로 비교**한다(`문서2` 가 `문서10` 앞).
- **대소문자는 구분하지 않고**, 같은 것끼리는 원래 순서를 지킨다.
- **줄 앞의 공백(들여쓰기)은 무시**하고 비교하되, 줄 자체의 공백은 그대로 둔다.
- **빈 줄은 방향과 상관없이 맨 아래**로 간다.
- 정렬한 뒤 그 줄들이 **계속 선택된 채**로 남아서 바로 한 번 더 눌러 뒤집을 수 있다.
- **Ctrl+Z 로 되돌린다.**

## 하지 않는 경우 (키만 소비하고 아무것도 안 함)

- 선택이 없거나 **한 줄만** 선택했을 때.
- 선택에 코드블록의 여는·닫는 줄(```)이 **들어 있을 때** — 순서를 바꾸면 블록 구조가 깨진다. 블록 **안**의 줄만 골라 정렬하는 것은 된다.
- 이미 정렬되어 있어서 바뀌는 것이 없을 때(모두 같은 줄 등).
- 줄 전체를 골라서 다음 줄 맨 앞에서 선택이 끝나면 **그 다음 줄은 포함하지 않는다.**
- Shift·Alt 가 같이 눌린 조합에는 반응하지 않는다. Mac 은 Cmd+`.

## 관련 파일

| 파일 | 역할 |
|---|---|
| `src/lib/lineSort.js` | 선택에 걸친 줄을 정렬한 결과(`from/to/insert/selStart/selEnd`)를 계산하는 순수 함수 |
| `src/components/EditorPane.jsx` | Ctrl+` 키를 받아 결과를 입력칸에 적용(Ctrl+D 와 같은 자리) |
| `tests/lib/lineSort.test.js` | 정렬 규칙·범위·줄바꿈(CRLF)·코드블록 22개 + 연결 확인(소스 점검) 2개 |

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| 오름차순 / 내림차순 | 작은 것부터(가나다·ABC·1 2 3) / 큰 것부터 |
| 백틱(`) | 숫자 1 왼쪽, Esc 아래의 키. 한글 자판에서도 같은 키다 |
| CRLF | Windows 의 줄바꿈 방식(`\r\n`). 정렬해도 그대로 유지한다 |
