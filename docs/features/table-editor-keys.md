# 표 편집기의 셀 키 이동 (Tab · Enter · Shift+Enter)

## 한 줄 요약

표 편집기에서 셀 안에 있을 때 **Tab** 은 아래 행의 첫 번째 셀로, **Enter** 는 바로 아래 셀로 이동하고(없으면 새 행을 만든다), **Shift+Enter** 는 셀 안에서 줄바꿈(`[br]`)을 넣는다.

## 동작

| 키 | 동작 |
|---|---|
| **Tab** | 아래 행의 **첫 번째 셀**로. 어느 열에서 눌러도 첫 번째 셀이다. 마지막 행이면 **새 행을 만들고** 그 행의 첫 번째 셀로 간다. (예전에는 행 끝의 삭제 버튼 `[−]` 로 포커스가 갔다) |
| **Enter** | **같은 열의 바로 아래 셀**로. 마지막 행이면 **새 행을 만들고** 같은 열로 간다. |
| **Shift+Enter** | 셀 안에 `[br]` 을 넣는다(커서 자리에). 뷰어에서는 셀 안 줄바꿈으로 보인다. |
| Shift+Tab, Ctrl/Alt 조합 | 건드리지 않는다(평소 동작). |

- 이동한 셀에서는 글자가 있으면 **커서가 맨 뒤**에 놓인다(전체 선택이 아님 — 이어서 쓰거나 고칠 수 있게).
- **세로로 병합된 셀(rowspan)** 에서 Enter 를 누르면 병합이 끝난 다음 행으로 간다. 아래 칸이 다른 셀의 병합에 가려져 있으면 그 칸을 덮고 있는 셀로 간다. Tab 은 아래 행에서 병합에 가려지지 않은 첫 셀로 간다.
- **한글을 입력하는 중**(조합 중)의 Enter 는 글자를 확정하는 키라서 이동하지 않는다. 확정한 뒤 한 번 더 누르면 이동한다.
- Shift+Enter 로 넣은 `[br]` 은 입력칸의 되돌리기(Ctrl+Z)로 지워진다.
- 아래쪽의 "선택한 셀 내용" 큰 입력칸에서는 Enter 가 평소처럼 줄바꿈이다(이 키 이동은 표의 셀 입력칸에만 적용).

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| **셀** | 표의 한 칸. |
| **`[br]`** | 문서 문법에서 "여기서 줄바꿈"을 뜻하는 표시. 표 칸 안에서는 그냥 Enter 를 칠 수 없어서 이걸 쓴다. |
| **병합** | 여러 칸을 하나로 합친 것. 세로 병합(rowspan)은 아래 칸까지 한 셀이 차지한다. |

## 구현 위치

- `src/lib/tableNav.js` — 이동할 셀 계산(`tabTarget`, `enterTarget`, 병합 처리 포함).
- `src/components/TableEditorModal.jsx` — 셀 입력칸의 키 처리(`handleCellKeyDown`), 새 행을 만든 직후 포커스(`pendingFocusRef` + 효과), Shift+Enter 는 `execCommand('insertText')` 로 넣어서 되돌리기가 이어지게 함.
- 테스트: `tests/lib/tableNav.test.js`. 화면 동작은 실제 키 입력으로 확인했다(Enter 이동, 마지막 행에서 새 행, Tab 이 입력칸으로 이동, Shift+Enter 가 `줄1[br]줄2` 가 되고 미리보기에 줄바꿈 반영).

## 알려진 한계

- Shift+Tab(이전 셀)은 따로 만들지 않았다. 평소 포커스 이동이라 행 끝의 `[−]` 버튼을 거칠 수 있다.
- 화살표 키로 셀 사이를 이동하는 기능은 없다.
