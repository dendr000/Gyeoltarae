# 굵게(`'''`)와 들여쓰기를 한 덩어리로 — Ctrl+B 커서, ←/→, Backspace/Delete

## 한 줄 요약

- **Ctrl+B 로 글을 감싸면 커서가 닫는 `'''` 오른쪽 바깥**에 놓인다(이어서 바로 다음 글을 쓸 수 있다).
- 굵게 표시 **`'''` 세 글자를 한 덩어리**처럼 다룬다: 방향키로 한 번에 건너뛰고, Backspace/Delete 로 한 번에 지운다.
- **줄 맨 앞의 들여쓰기 공백**도 4칸 단위로 움직이고 지운다(VS Code 의 탭 칸 이동과 같다).

## 1. Ctrl+B

| 상황 | 결과 |
|---|---|
| 글을 선택하고 Ctrl+B | `'''선택한글'''` 로 감싸고, 커서는 닫는 `'''` **바로 오른쪽 바깥** |
| 선택 없이 Ctrl+B | `'''|'''` — 글을 써야 하므로 가운데에 커서. 다 쓰고 → 키 한 번이면 닫는 `'''` 를 건너뛰어 바깥으로 나온다 |

- 예전에는 감싼 뒤 안쪽 글이 선택된 상태로 남았다. 이 변경은 **Ctrl+B 에만** 적용된다. 툴바의 굵게 버튼, Ctrl+U(밑줄), 취소선은 예전 방식(안쪽 글 선택)이다.
- 손으로 `'` 를 하나씩 쳐서 굵게를 만드는 경우에는 영향이 없다(자동 괄호 쌍 규칙 그대로).

## 2. `'''` 한 덩어리

| 키 | 커서 바로 옆이 `'''` 일 때 |
|---|---|
| → / ← | `'''` 3글자를 한 번에 건너뛴다 |
| Shift+→ / Shift+← | 선택이 `'''` 한 덩어리씩 넓어진다 |
| Backspace | 왼쪽의 `'''` 3글자를 한 번에 지운다 |
| Delete | 오른쪽의 `'''` 3글자를 한 번에 지운다 |

- **정확히 따옴표 3개가 이어진 곳만** 덩어리다. 2개(이탤릭 `''`), 4개 이상, 5개(`'''''굵은 기울임'''''`)가 붙어 있으면 어디까지가 굵게 표시인지 모호해서 예전처럼 글자 하나씩 움직인다.
- **코드블록(```) 안에서는 `'''` 규칙을 끈다**(SQL 의 따옴표 등을 글자 단위로 편집해야 해서).
- 글을 선택한 상태의 ←/→(Shift 없이)와 Backspace/Delete 는 평소 동작 그대로다. Ctrl/Alt 가 같이 눌리면 평소 동작이다(Ctrl+←/→ 단어 이동 등).
- **한글을 조합하는 중에는 동작하지 않는다.**
- Ctrl+Z 한 번으로 한 번의 삭제가 되돌아간다.
- **한계**: 마우스로 `'''` 글자 사이를 클릭해 커서를 놓는 것은 막을 수 없다.

## 3. 줄 맨 앞 들여쓰기(공백 4칸 = 한 칸)

커서 앞의 같은 줄 글이 **공백뿐일 때만**(= 줄 맨 앞 들여쓰기 안에 있을 때) 적용된다. 단어 사이·글 뒤의 공백은 건드리지 않는다. 코드블록 안에서도 적용된다.

| 키 | 동작 |
|---|---|
| ← | 이전 4칸 단위 위치로(공백 8칸 뒤 → 4칸 위치, 6칸 뒤 → 4칸 위치) |
| → | 다음 4칸 단위 위치로, 단 들여쓰기가 끝나는 자리(글자 앞)를 넘지 않는다 |
| Backspace | ← 가 가는 위치까지 공백을 한 번에 지운다(공백 6칸 뒤라면 2칸, 8칸 뒤라면 4칸) |
| Delete | → 가 가는 위치까지 공백을 한 번에 지운다 |

- 한 칸만 움직이는 경우(공백 1칸, 5칸 뒤 등)는 평소 동작과 같아서 따로 가로채지 않는다.
- 탭 문자(`\t`)가 섞인 들여쓰기에는 적용되지 않는다. Tab 키는 공백 4칸을 넣으므로(`docs/features/editor-line-keys.md`) 이 앱에서 만든 들여쓰기는 모두 해당한다.

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| `'''` | 이 앱(나무위키 문법)에서 굵게 보이게 하는 표시. 글 앞뒤를 `'''글'''` 로 감싼다 |
| 한 덩어리(원자 단위) | 키 한 번에 통째로 움직이거나 지워지는 글. 편집 칸은 원래 글자 하나씩만 움직이므로, 키를 가로채서 비슷하게 만든다 |
| 이탤릭 | 글을 기울여 보이게 하는 표시(`''글''`, 따옴표 2개) |
| 한글 조합 | 한글 자모를 모아 글자를 만드는 입력 중인 상태. 이때의 키는 가로채지 않는다 |

## 알려진 한계

- 마우스 클릭으로 `'''` 사이에 커서를 놓는 것은 막을 수 없다.
- 한글 조합 중에는 동작하지 않는다(미리보기에서 한글 입력 상태의 동작은 시험하지 못했다).
