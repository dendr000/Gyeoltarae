# 줄 복제 (Ctrl+D) — 문서 어디서나

> 파일 이름(`code-line-duplicate`)은 처음에 코드블록 안에서만 되던 기능이어서 붙은 것이다. 0.95.0 부터 **문서 전체**에서 되지만 링크가 깨지지 않도록 이름은 그대로 둔다.

## 한 줄 요약

**Ctrl+D** 를 누르면 현재 줄이 바로 아래 줄에 복제된다. MySQL Workbench 같은 코드 편집기의 "줄 복제"와 같고, 코드블록 안뿐 아니라 문단·표 줄·목록·제목 어디서나 된다.

## 동작

````text
SELECT * FROM t WHERE id = 1;|     ← 커서가 여기 (줄 어디든)
          ↓ Ctrl+D
SELECT * FROM t WHERE id = 1;
SELECT * FROM t WHERE id = 1;|     ← 복제된 줄, 커서는 같은 열로 이동
````

- **복제 대상**: 커서가 있는 줄 전체(커서가 줄 중간이어도). **여러 줄을 선택했으면 선택에 걸친 줄 전체**를 통째로 복제하고, 선택도 복제본으로 옮겨 간다. 선택이 다음 줄 맨 앞에서 끝나면 그 다음 줄은 포함하지 않는다.
- **어디서나**: 문단, 표 줄(`||가||나||`), 목록(` * 항목`), 제목(`== 제목 ==`), 빈 줄, 코드블록 안의 줄 모두 복제된다. 예를 들어 표의 비슷한 행을 여러 개 만들 때 쓰면 편하다.
- **커서**: 복제된 줄의 같은 열로 옮겨 간다(계속 이어서 고칠 수 있게).
- **들여쓰기·줄 끝 공백**도 그대로 복제된다. 빈 줄이면 빈 줄이 복제된다. 윈도우 줄바꿈(CRLF) 문서도 정상이다.
- **되돌리기**: Ctrl+Z 한 번에 복제가 취소된다.
- 한글 입력 상태에서도 된다(물리 키 D 를 함께 본다).
- 빈 문서에서는 아무 일도 하지 않는다.

## 코드블록(```) 구조를 깨는 복제는 하지 않는다

복제본이 코드블록을 닫거나 열어 버리면 문서 모양이 달라진다. 그래서 **복제할 줄들을 지나는 사이 "코드블록 안/밖" 상태가 달라지면** 복제하지 않는다.

| 상황 | 결과 |
|---|---|
| 코드블록 **안의 일반 줄** | 복제된다 |
| 코드블록 **한 덩어리**(여는 ``` 줄부터 닫는 ``` 줄까지)를 통째로 선택 | 블록 전체가 복제된다 |
| **여는 ``` 줄만**, 또는 **닫는 ``` 줄만** 있는 줄 | 아무 일도 안 한다 |
| 블록 안의 줄과 닫는 ``` 줄을 함께 선택 / 블록 밖의 줄과 여는 ``` 줄을 함께 선택 | 아무 일도 안 한다 |
| 백틱 4개로 연 블록 안의 ``` 줄 | 코드 본문이므로 복제된다 |

(0.94.x 까지는 코드블록 밖과 ``` 줄이 들어 있는 모든 경우를 막았다.)

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| **줄 복제** | 지금 줄을 그대로 복사해서 바로 아래에 붙여 넣는 편집 기능. 비슷한 줄을 여러 개 쓸 때(컬럼 정의, 표의 행 등) 편하다. |
| **펜스(fence)** | 코드블록의 시작과 끝을 표시하는 ``` 줄. |

## 구현 위치

- `src/lib/lineDuplicate.js` — 복제 계산(`duplicateLinesEdit`). 코드블록 안/밖 상태는 `src/lib/codeFence.js` 의 `openCodeFenceAt` 으로 복제할 줄들의 앞과 뒤에서 비교한다.
- `src/components/EditorPane.jsx` — Ctrl+D 키 처리. 안쪽 글은 `execCommand('insertText')` 로 넣어서 되돌리기가 이어진다.
- 테스트: `tests/lib/lineDuplicate.test.js`. 화면 동작은 실제 키 이벤트로 확인했다(문단·표 줄·코드블록 안 복제, 한글 키값, ``` 줄은 변화 없음).

## 알려진 한계

- `{{{ ... }}}` 방식 코드블록은 구조를 따지지 않는다(``` 방식만 구조를 지킨다).
- 줄을 위/아래로 옮기는 기능(Alt+↑/↓)은 없다. (표 편집기에는 행·열 이동이 있다: [table-editor-structure.md](table-editor-structure.md))
- 선택한 글자만 복제하는 기능(VS Code 의 선택 복제)은 없고 항상 줄 단위다.
