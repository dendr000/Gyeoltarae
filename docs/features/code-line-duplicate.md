# 코드블록에서 Ctrl+D — 줄 복제

## 한 줄 요약

코드블록(```) 안에서 **Ctrl+D** 를 누르면 현재 줄이 바로 아래 줄에 복제된다. MySQL Workbench 같은 코드 편집기의 "줄 복제"와 같다.

## 동작

````text
```sql
SELECT * FROM t WHERE id = 1;|     ← 커서가 여기 (줄 어디든)
```
          ↓ Ctrl+D
```sql
SELECT * FROM t WHERE id = 1;
SELECT * FROM t WHERE id = 1;|     ← 복제된 줄, 커서는 같은 열로 이동
```
````

- **복제 대상**: 커서가 있는 줄 전체(커서가 줄 중간이어도). **여러 줄을 선택했으면 선택에 걸친 줄 전체**를 통째로 복제하고, 선택도 복제본으로 옮겨 간다. 선택이 다음 줄 맨 앞에서 끝나면 그 다음 줄은 포함하지 않는다.
- **커서**: 복제된 줄의 같은 열로 옮겨 간다(계속 이어서 고칠 수 있게).
- **들여쓰기·줄 끝 공백**도 그대로 복제된다. 빈 줄이면 빈 줄이 복제된다. 윈도우 줄바꿈(CRLF) 문서도 정상이다.
- **되돌리기**: Ctrl+Z 한 번에 복제가 취소된다.
- 한글 입력 상태에서도 된다(물리 키 D 를 함께 본다).
- **동작하지 않는 곳**: 코드블록 밖(문단·표·목록 등 — 평소 Ctrl+D 동작 그대로), 그리고 ``` 줄(여는 줄·닫는 줄) 자체. 선택이 ``` 줄을 걸쳐도 동작하지 않는다(복제하면 코드블록이 깨지므로).
- 언어가 없는 ``` 블록과 닫는 줄이 없는 블록(문서 끝까지 코드)에서도 동작한다.

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| **줄 복제** | 지금 줄을 그대로 복사해서 바로 아래에 붙여 넣는 편집 기능. 비슷한 줄을 여러 개 쓸 때(컬럼 정의 등) 편하다. |
| **펜스(fence)** | 코드블록의 시작과 끝을 표시하는 ``` 줄. |

## 구현 위치

- `src/lib/lineDuplicate.js` — 복제 계산(`duplicateLinesEdit`). 코드블록 판단은 `src/lib/codeFence.js` 의 `isInCodeFenceAt`(여는 줄은 아직 밖, 닫는 줄은 안쪽으로 셈)을 쓴다.
- `src/components/EditorPane.jsx` — Ctrl+D 키 처리. 안쪽 글은 `execCommand('insertText')` 로 넣어서 되돌리기가 이어진다.
- 테스트: `tests/lib/lineDuplicate.test.js`. 화면 동작은 실제 키 입력으로 확인했다(코드블록 안 복제와 커서 위치, Ctrl+Z 한 번에 복구, 코드블록 밖에서는 아무 변화 없음).

## 알려진 한계

- `{{{ ... }}}` 방식 코드블록 안에서는 동작하지 않는다(``` 방식만).
- 줄을 위/아래로 옮기는 기능(Alt+↑/↓)은 없다.
