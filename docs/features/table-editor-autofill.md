# 표 편집기의 자동 채우기 (채우기 핸들)

## 한 줄 요약

표 편집기에서 칸을 고르면 **오른쪽 아래 모서리에 작은 네모(채우기 핸들)** 가 나타난다. 이것을 **아래·오른쪽·위·왼쪽으로 끌면** 고른 칸이 씨앗이 되어 `1, 2 → 3, 4, 5…`, 날짜, 요일, `항목1 → 항목2…` 처럼 규칙을 읽어 이어서 채운다. 엑셀의 자동 채우기와 같은 방식이다.

## 쓰는 법

1. 씨앗이 될 칸을 고른다. 한 칸이어도 되고 두세 칸이어도 된다(예: `1`, `2` 가 든 두 칸). 고른 범위의 **오른쪽 아래 칸 모서리**에 진한 색 작은 네모가 보인다.
2. 그 네모를 **아래로**(고른 열마다 채움) 또는 **오른쪽으로**(고른 행마다 채움) 끈다. 끄는 동안 채워질 칸이 **점선과 연한 색**으로 미리 보인다.
3. 놓으면 채워지고, 고른 범위가 **채운 칸까지 늘어난다**(이어서 한 번 더 끌 수 있다).
4. 끄는 도중 **Esc** 를 누르면 취소된다. 고른 범위 안에서 놓으면 아무 일도 일어나지 않는다.
5. **Ctrl** 을 누른 채 놓으면 규칙이 반대가 된다(복사 ↔ 이어 가기, 아래 표 참고).

### 위·왼쪽으로 끌기와 더블클릭

- **위·왼쪽으로 끌면 거꾸로 이어 간다.** 씨앗 `3, 4` 를 위로 끌면 `2, 1, 0`(가까운 칸부터), `화` 를 위로 끌면 `월, 일, 토`, `2024-03-01` 은 `2024-02-29, 02-28…`. 반복하는 씨앗(`a, b`)은 이어 붙는 쪽부터 반복한다(위로: `b, a, b`).
- 위·아래·왼쪽·오른쪽으로 모두 벗어나게 끌었으면 **범위에서 가장 멀리 간 쪽**이 채워진다. 같으면 아래 → 오른쪽 → 위 → 왼쪽 순이다.
- **핸들을 두 번 누르면(더블클릭)** 이웃한 열의 데이터가 이어진 곳까지 **아래로 한 번에** 채운다(엑셀과 같음). 고른 범위의 **왼쪽 열**을 먼저, 없으면 오른쪽 열을 보며, 그 열에서 씨앗 줄에 글자가 있고 그 아래로 글자가 이어진 칸 수만큼 채운다(빈 칸이나 표 끝에서 멈춤). 기준이 되는 이웃 열이 없으면 아무 일도 안 한다.

## 이어 가는 규칙

| 씨앗 | 결과 | 예 |
|---|---|---|
| **숫자 둘 이상**, 차이가 일정 | 같은 차이로 이어 감 | `1, 2` → `3, 4, 5` · `10, 20` → `30, 40` · `5, 3` → `1, -1` |
| **숫자 하나** | **그대로 복사**(엑셀과 같음). Ctrl 을 누르면 1씩 늘어남 | `7` → `7, 7, 7` / Ctrl: `8, 9` |
| **글자 속 숫자** (`항목1`, `3호선`, `₩500`) | 하나만 있어도 **가장 뒤의 정수**를 1씩 늘림. Ctrl 을 누르면 복사 | `항목1` → `항목2, 항목3` · `A-1` → `A-2` · `v1.2.3` → `v1.2.4` |
| **날짜** (`2024-01-05`, `2024.01.05`, `2024/01/05`, `2024년 1월 5일`) | 하루씩. 씨앗이 둘 이상이면 날짜 차이만큼, **같은 일자에 달만 바뀌면** 달 단위 | `2024-01-31` → `02-01, 02-02` · `1/1, 2/1` → `3/1, 4/1` |
| **요일·월 이름** (`월`~`일`, `월요일`~, `1월`~`12월`, `Mon`~, `January`~) | 한 바퀴 돌며 이어 감. 씨앗이 둘 이상이면 간격만큼 | `금` → `토, 일, 월` · `11월` → `12월, 1월` · `월, 수` → `금, 일, 화` |
| **그 밖의 글자**, 또는 규칙이 맞지 않는 여러 칸 | 씨앗을 **순서대로 반복** | `가, 나` → `가, 나, 가` · `1, 2, 4` → `1, 2, 4, 1` |

### 서식이 유지되는 경우

- **숫자**: 천 단위 쉼표(`1,000, 2,000 → 3,000`), 앞의 0(`001, 002 → 003`), 소수 자릿수(씨앗 중 가장 긴 쪽, `1, 1.5 → 2.0, 2.5`)가 유지된다.
- **글자 속 숫자**: 앞뒤 글자와 통화 기호, 앞의 0(`No.001 → No.002`), 쉼표(`1,200원 → 1,201원`)가 유지된다. 숫자는 **정수만** 늘린다(`3.5점` 은 소수점 뒤 `5` 가 늘어난다).
- **날짜**: 쓴 형식 그대로(구분 기호, 두 자리로 맞춰 쓰는지)다. **달·해가 바뀌는 날과 윤년**을 맞게 센다. 달 단위로 이어 갈 때 그 달에 없는 일자는 말일로 맞춘다(`12/31, 1/31` → `2/28, 3/31, 4/30`).
- **영문 요일·월**: 쓴 글자꼴을 따른다(`Mon` → `Tue`, `mon` → `tue`, `MON` → `TUE`).
- **칸의 서식**(배경색·글자색·굵기·정렬)은 씨앗 칸의 것을 순서대로 반복해서 복사한다.

### 읽지 않는 것

- `2023-02-29`, `2024-13-45` 처럼 **없는 날짜**는 날짜로도, 글자 속 숫자로도 읽지 않고 **그대로 반복**한다.
- 씨앗 중 빈 칸이 있으면 반복한다(빈 칸도 그대로 이어진다).
- 서로 다른 묶음(`월` 과 `Mon`), 다른 형식의 날짜, 앞뒤 글자가 다른 글자 속 숫자(`a1`, `b2`)가 섞이면 반복한다.
- 월·일이 아닌 규칙(분기 `1분기`, 간지 등)은 글자 속 숫자 규칙으로만 이어 간다. 추세(회귀)로 이어 가는 엑셀의 고급 동작은 없다.

## 병합된 칸이 있을 때

- 고른 범위(씨앗)에 병합된 칸이 있으면 핸들이 **나타나지 않는다**.
- 끈 자리에 병합된 칸이 걸리면 미리 보기가 나타나지 않고 놓아도 채워지지 않는다.
- 표 끝을 넘어서 끌 수는 없다(표의 마지막 행·열까지 채운다). 행·열이 더 필요하면 먼저 추가한다.

## Ctrl+D 와 다른 점

| | 아래로 채우기(Ctrl+D) | 자동 채우기(핸들 끌기) |
|---|---|---|
| 하는 일 | 첫 행(한 행만 골랐으면 바로 위 행)의 내용을 **그대로 복사** | 씨앗의 **규칙을 읽어 이어 붙임**(복사도 포함) |
| 범위 | 고른 범위 안을 채움 | 고른 범위는 씨앗, 끈 칸까지를 **새로 채움** |
| 자세히 | [table-editor-structure.md](table-editor-structure.md) | 이 문서 |

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| **채우기 핸들** | 고른 범위의 오른쪽 아래 모서리의 작은 네모. 끌어서 채울 곳을 정한다. |
| **씨앗(시드)** | 규칙을 읽는 기준이 되는 칸들. 이어질 값은 씨앗에서 계산한다. |
| **등차** | 이웃한 값의 차이가 일정한 숫자의 나열. `1, 3, 5, 7`(차이 2). |

## 구현 위치

- `src/lib/fillSeries.js` — 이어질 글자 계산(`continueSeries`). 숫자·글자 속 숫자·날짜·요일·월 이름 규칙. 화면과 분리한 순수 함수.
- `src/lib/tableAutoFill.js` — 격자에 적용(`autoFill`), 끈 방향·칸 수 판단(`dragFillTarget`), 채울 수 있는지(`canAutoFill`), 채운 뒤 범위(`extendedRange`).
- `src/lib/tableGrid.js` — `regionHasMerge`(영역에 병합이 있는지).
- `src/components/useAutoFillDrag.js` — 핸들 끌기(마우스 이동·놓기·Esc, 미리보기). `TableEditorModal.jsx` — 핸들 그리기(`.fill-handle`), 칸의 `data-cell` 표시, 미리보기 클래스.
- 테스트: `tests/lib/fillSeries.test.js`(이어 가는 규칙), `tests/lib/tableAutoFill.test.js`(격자 적용, 끌기 방향, 병합·표 끝). 핸들 끌기는 미리보기에서 실제 마우스 이벤트로 확인했다.

## 한계

- 위·왼쪽으로 끌어 채울 때 칸 수는 표의 가장자리까지다(표 밖으로 나가는 만큼은 채우지 않는다).
- 더블클릭 채우기는 **아래 방향**만 된다(옆으로 끝까지 채우는 것은 없다).
- 키보드만으로 하는 자동 채우기 단축키는 없다(핸들 끌기만). 같은 값을 아래로 복사하는 것은 Ctrl+D.
- 월 단위로 이어 가는 날짜 규칙은 씨앗의 **일자가 모두 같을 때**만 적용된다.
- 실제 Electron 앱 창이 아니라 브라우저 미리보기에서 확인했다.
