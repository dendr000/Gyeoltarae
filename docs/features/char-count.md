# 글자 수 표시 (문서 전체 · 드래그한 글자)

## 한 줄 요약

편집·뷰어 화면 맨 아래의 **표시줄**에 열린 문서의 **전체 글자 수가 맨 오른쪽에 늘** 보이고, 글을 **드래그해서 고르면 고른 글자 수**가 그 왼쪽에 보인다. 둘 다 기본은 **줄바꿈을 세지 않는 글자 수**이고, 메뉴 **설정 > 줄바꿈 포함 글자 수** 를 켜면 **드래그한 글자 수에 한해** 줄바꿈도 1자로 센다.

```text
                                                      선택 12자      글자 수 409자
```

- 전체 글자 수는 **오른쪽 끝에 고정**이다. 드래그하면 그 왼쪽에 "선택 N자" 가 생기고 풀면 사라지는데, 그래도 전체 글자 수 자리는 움직이지 않는다.
- **드래그 글자 수는 설정과 상관없이 늘 센다**(기본 동작).
- 전체 글자 수에는 "(줄바꿈 포함)" 같은 기준 표시를 쓰지 않는다.

## 세는 기준

**공백·특수문자·한자를 모두 포함해서 문자 하나를 1자로 센다.** 바이트 수나 토큰 수는 쓰지 않는다. 줄바꿈만 설정에 따라 다르다.

| | 줄바꿈 | 설정 "줄바꿈 포함 글자 수" 의 영향 |
|---|---|---|
| **문서 전체 글자 수** | 세지 않음 | 받지 않음(늘 기본 글자 수) |
| **드래그한 글자 수** | 기본은 세지 않음 | **켜면 줄바꿈도 1자로 센다** |

| 글 | 기본 글자 수 | 줄바꿈 포함 |
|---|---|---|
| `가나다` | 3 | 3 |
| `가 나` (공백도 1자) | 3 | 3 |
| `#→·/&()` (특수문자) | 7 | 7 |
| `漢字` | 2 | 2 |
| `가` 줄바꿈 `나` | 2 | 3 |
| `😀`, `𠮷` | 1 | 1 (자바스크립트의 `length` 는 2 지만 여기서는 1) |
| 한 줄 9자 x 41줄 | 369 | 409 (줄 사이 줄바꿈 40 추가) |

- **윈도 줄바꿈(CRLF)** 은 줄바꿈 하나로 본다(포함으로 셀 때 1자). 낱개 `\r` 도 줄바꿈이다.
- 자모가 풀어 쓰인 한글(NFD, 맥에서 온 글 등)은 완성된 글자 1자로 합쳐서 센다.
- **문서 전체 글자 수는 문서 원문**(위키 문법 기호 `'''`, `==`, `[[`, `||` 등 포함)을 센다. 뷰어에 보이는 글자 수와 다를 수 있다. 위키 문법 기호도 문서에 들어 있는 글자이기 때문이다.

## 보이는 곳

- 표시줄은 **문서가 열려 있을 때** 편집·뷰어·듀얼 모드 모두 화면 맨 아래에 보인다(문서가 없으면 안 보인다).
- 마우스를 올리면 설명이 보인다: 전체 글자 수는 "공백·특수문자·한자를 모두 포함해 문자 하나를 1자로 셉니다 (줄바꿈은 세지 않습니다)", 드래그 글자 수는 "줄바꿈 포함 글자 수 설정" 안내.
- **전체 글자 수**는 글을 치는 대로 바로 갱신된다.
- **선택 글자 수**: 편집창에서는 선택 범위(드래그, Shift+방향키, Ctrl+A 모두), 뷰어에서는 마우스로 드래그한 글을 센다. 고른 글이 없으면 보이지 않는다. 뷰어에서는 **문서 본문 안에서 고른 글만** 센다(사이드바·메뉴의 글씨를 드래그한 것은 세지 않는다). 뷰어의 선택은 눈에 보이는 글자 기준이라 위키 문법 기호는 빠진다.

## 설정: 줄바꿈 포함 글자 수

- 메뉴 **설정 > 줄바꿈 포함 글자 수**(체크 항목, **기본 꺼짐**). 켜면 드래그한 글자 수가 줄바꿈도 1자로 센 값이 되고, 끄면 줄바꿈을 세지 않는다. 고른 글을 그대로 둔 채 설정을 바꿔도 센 값이 바로 바뀐다. 문서 전체 글자 수는 이 설정과 상관없다.
- 값은 이 PC 의 앱 설정 파일(`config.json`)의 `countNewlines` 에 저장되고(`true` 일 때만 켜짐), 메뉴에서 바꾸면 바로 반영된다.
- 0.133.0 에 있던 "선택 글자 수"(드래그 글자 수 표시를 켜고 끄는 항목, `selectionCharCount`)는 0.136.0 에서 이 항목으로 바뀌었다. 드래그 글자 수는 이제 늘 보인다.

## 확인한 것 (실제 Electron 창, 실제 마우스·키 입력)

`가나다`/`라마바 漢字 😀` 두 줄 문서(줄바꿈 제외 11자, 포함 13자)에서: 전체 글자 수 **11자**(기본 글자 수) · Shift+→ 3번으로 3글자 고르면 "선택 3자" 가 전체 글자 수 **왼쪽**에 생기고 전체 글자 수 자리(오른쪽 끝 좌표)는 그대로 · Ctrl+A 는 "선택 11자" · 설정 **줄바꿈 포함**을 켜면 같은 선택이 "선택 13자", 끄면 다시 11자 · 뷰어에서 마우스로 `라마바 ` 를 드래그하면 "선택 4자" · 선택을 풀면 "선택" 만 사라지고 전체 글자 수 위치는 그대로.

## 한계

- 전체 글자 수는 **문서 원문 기준**이라 뷰어에서 보이는 글자 수와 다르다(문법 기호 포함). 렌더링된 글자만 세는 옵션은 아직 없다.
- 전체 글자 수에 줄바꿈을 포함해서 세는 옵션은 없다(드래그 글자 수에만 있다).
- ZWJ 로 이어 붙인 이모지(가족 이모지 등)는 구성하는 이모지 개수만큼 센다(코드 점 기준). 보이는 모양 하나(자소 묶음)를 1자로 세는 방식이 아니다.
- 공백 제외 같은 **다른 기준은 아직 없다**.
- 아주 긴 문서(수십만 자)는 글을 칠 때마다 전체를 다시 세므로 약간의 비용이 있다.

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| 글자 수 | 글에 들어 있는 문자의 개수. 글자·공백·기호 모두 1개씩 |
| 줄바꿈 포함 글자 수 | 줄바꿈 문자(Enter 로 만든 줄 나눔)도 글자로 세는 기준 |
| 기본 글자 수 | 줄바꿈은 세지 않고 나머지(글자·공백·기호)를 세는 기준 |
| 코드 점 | 문자 하나에 대응하는 번호. 이모지처럼 큰 번호의 문자도 하나로 센다 |
| NFC / NFD | 한글을 완성된 글자(NFC)로 저장하느냐, 자모로 풀어서(NFD) 저장하느냐의 차이 |
| 드래그 | 마우스 버튼을 누른 채 움직여 글을 고르는 것 |
