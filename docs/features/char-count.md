# 글자 수 표시 (문서 전체 · 드래그한 글자)

## 한 줄 요약

편집·뷰어 화면 맨 아래의 **표시줄**에 열린 문서의 **전체 글자 수**가 늘 보이고, 글을 **드래그해서 고르면 고른 글자 수**도 함께 보인다. 센 기준은 **줄바꿈 포함 문자 수**다. 고른 글자 수는 메뉴 **설정 > 선택 글자 수** 로 켜고 끈다(기본 켜짐).

```text
                                         글자 수 409자 (줄바꿈 포함)   선택 12자
```

## 세는 기준 (줄바꿈 포함 문자 수)

**공백·특수문자·한자·줄바꿈을 모두 포함해서 문자 하나를 1자로 센다.** 바이트 수나 토큰 수는 쓰지 않는다.

| 글 | 글자 수 | 설명 |
|---|---|---|
| `가나다` | 3 | 한글 한 글자 = 1자 |
| `가 나` | 3 | 공백도 1자 (탭·전각 공백 포함) |
| `#→·/&()` | 7 | 특수문자도 1자씩 |
| `漢字` | 2 | 한자도 1자씩 |
| `가` 줄바꿈 `나` | 3 | 줄바꿈도 1자 |
| `😀`, `𠮷` | 1 | 이모지·확장 한자도 1자 (자바스크립트의 `length` 는 2 로 세지만 여기서는 1) |
| 한 줄 9자 x 41줄 | 409 | 9 x 41 = 369 + 줄 사이 줄바꿈 40 |

- **윈도 줄바꿈(CRLF)** 도 줄바꿈 1자다. 낱개 `\r` 은 1자.
- 자모가 풀어 쓰인 한글(NFD, 맥에서 온 글 등)은 완성된 글자 1자로 합쳐서 센다.
- **문서 전체 글자 수는 문서 원문**(위키 문법 기호 `'''`, `==`, `[[`, `||` 등 포함)을 센다. 뷰어에 보이는 글자 수와 다를 수 있다. 위키 문법 기호도 문서에 들어 있는 글자이기 때문이다.

## 보이는 곳

- 표시줄은 **문서가 열려 있을 때** 편집·뷰어·듀얼 모드 모두 화면 맨 아래에 보인다(문서가 없으면 안 보인다).
- 마우스를 올리면 "줄바꿈 포함 문자 수: 공백·특수문자·한자·줄바꿈을 모두 포함해 문자 하나를 1자로 셉니다" 설명이 보인다.
- **전체 글자 수**는 글을 치는 대로 바로 갱신된다.
- **선택 글자 수**: 편집창에서는 선택 범위(드래그, Shift+방향키, Ctrl+A 모두), 뷰어에서는 마우스로 드래그한 글을 센다. 고른 글이 없으면 보이지 않는다. 뷰어에서는 **문서 본문 안에서 고른 글만** 센다(사이드바·메뉴의 글씨를 드래그한 것은 세지 않는다). 뷰어의 선택은 눈에 보이는 글자 기준이라 위키 문법 기호는 빠진다.

## 설정: 선택 글자 수

- 메뉴 **설정 > 선택 글자 수**(체크 항목, 기본 켜짐). 끄면 드래그해도 선택 글자 수가 보이지 않고(선택을 따라가는 일도 하지 않는다) **전체 글자 수는 계속 보인다.**
- 값은 이 PC 의 앱 설정 파일(`config.json`)의 `selectionCharCount` 에 저장되고(`false` 일 때만 꺼짐), 메뉴에서 바꾸면 바로 반영된다.

## 확인한 것 (실제 Electron 창, 실제 마우스·키 입력)

`가나다`/`라마바 漢字 😀` 두 줄 문서에서: 전체 글자 수 **13자**(글자 11 + 줄바꿈 2, 이모지·한자 1자씩) · Shift+→ 3번으로 3글자 고르면 "선택 3자", Ctrl+A 는 "선택 13자" · `abc` 를 치면 16자로 갱신되고 선택 표시는 사라짐 · 뷰어에서 마우스로 `라마바 ` 를 드래그하면 "선택 4자" · 설정을 끄면 드래그해도 선택 표시가 없고 전체 글자 수만 보임, 다시 켜면 보임 · 사이드바 글씨를 선택해도 세지 않음 · 문서를 열기 전에는 표시줄이 없음.

## 한계

- 전체 글자 수는 **문서 원문 기준**이라 뷰어에서 보이는 글자 수와 다르다(문법 기호 포함). 렌더링된 글자만 세는 옵션은 아직 없다.
- ZWJ 로 이어 붙인 이모지(가족 이모지 등)는 구성하는 이모지 개수만큼 센다(코드 점 기준). 보이는 모양 하나(자소 묶음)를 1자로 세는 방식이 아니다.
- 줄바꿈 제외·공백 제외 같은 **다른 기준은 아직 없다**(요청한 줄바꿈 포함 기준만 있다).
- 아주 긴 문서(수십만 자)는 글을 칠 때마다 전체를 다시 세므로 약간의 비용이 있다.

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| 글자 수 | 글에 들어 있는 문자의 개수. 글자·공백·기호·줄바꿈 모두 1개씩 |
| 줄바꿈 포함 문자 수 | 줄바꿈 문자(Enter 로 만든 줄 나눔)도 글자로 세는 기준 |
| 코드 점 | 문자 하나에 대응하는 번호. 이모지처럼 큰 번호의 문자도 하나로 센다 |
| NFC / NFD | 한글을 완성된 글자(NFC)로 저장하느냐, 자모로 풀어서(NFD) 저장하느냐의 차이 |
| 드래그 | 마우스 버튼을 누른 채 움직여 글을 고르는 것 |
