# 편집 모드의 각주 색 구분과 각주 편집 상자

## 한 줄 요약

각주(`[* 내용]`)가 길어지고 `[br]`(줄 안 줄바꿈)이 여러 번 섞이면 한 줄이 아주 길어져서 고치기 어려웠다. 그래서 **편집 모드에서 각주마다 색을 칠해 어디서 시작해 어디서 끝나는지 보이게** 하고, **각주 안에 커서를 두고 Alt+E(또는 뜨는 "각주 편집" 단추)를 누르면 그 각주만 여러 줄 상자에서 고칠 수 있게** 했다. 상자에서는 `[br]` 이 진짜 줄바꿈으로 보이고, 적용하면 다시 `[br]` 로 저장된다. 파일에 저장되는 모양은 그대로다(기존 문서와 호환).

## 색 구분

| 보이는 것 | 뜻 |
|---|---|
| 옅은 파랑·초록·주황·보라 배경 | 각주 하나. 문서 위에서부터 센 순서대로 네 색을 돌려 쓴다(뷰어의 각주 번호와 같은 순서) |
| 같은 색의 더 진한 배경 | 그 각주 안의 `[br]` |

- 색은 글자 뒤에 깔리는 배경판에만 칠해서 **글자 크기·위치는 달라지지 않는다**(제목 강조와 같은 방식).
- 코드블록(```) 안의 `[* ...]` 는 뷰어도 각주로 그리지 않으므로 칠하지 않고 번호도 세지 않는다.
- 한 줄 안의 각주만 센다(각주가 줄을 넘어가는 경우는 뷰어도 각주로 보지 않는다).

## 각주 편집 상자

1. 커서를 각주의 대괄호 안(`[*` 와 `]` 사이)에 둔다. 커서 아래에 **"각주 편집 Alt+E"** 단추가 뜬다. (글을 드래그해 고른 상태에서는 뜨지 않는다.)
2. **Alt+E** 를 누르거나 단추를 누르면 그 각주의 내용이 여러 줄 상자로 열린다. `[br]` 자리는 줄바꿈으로 보인다.
3. 고친 뒤 **Ctrl+Enter**(또는 "적용")를 누르면 본문에 반영되고, 줄바꿈은 다시 `[br]` 로 저장된다. **Esc**(또는 "취소")는 버린다. 상자 밖을 클릭하면 **고친 내용이 있을 때만** 반영하고 닫는다.
4. 반영한 뒤 커서는 각주 내용의 끝에 놓여서 바로 Alt+E 로 다시 열 수 있다. 반영은 일반 입력처럼 기록되므로 **Ctrl+Z 한 번으로 되돌아간다**.

### 상자 안에서 쓸 수 있는 입력 도우미

상자는 본문 편집기와 **같은 함수**를 쓴다(`EditorPane.jsx` 의 `assistRef`/`getArea`/`emitChange` 로 "지금 고치는 입력칸"을 상자로 바꿔 끼움). 그래서 본문에서 되는 것은 거의 그대로 된다.

| 기능 | 키·동작 |
|---|---|
| 상용구 추천 팝업 | 글자를 치면 뜨고, `Tab`/`Enter` 로 확정, `Esc` 는 **팝업만** 닫는다(상자는 그대로). 슬래시 명령(`/각주` 등)도 된다 |
| 상용구 자동 치환 | 스페이스 자동 치환(설정이 켜져 있을 때), `Alt+Enter` 수동 치환, `Alt+Shift+T` 팝업 켜기/끄기, `{#}` 자리 사이를 `Tab` 으로 이동 |
| 상용구 등록 | `Alt+T` - 지금까지 고친 글을 반영하고 상자를 닫은 뒤 창이 열린다 |
| 괄호·따옴표 자동 닫기 | `( [ { < ' "` 짝 넣기, 선택 감싸기, 닫는 글자 건너뛰기 |
| 서식 | `Ctrl+B` 굵게, `Ctrl+U` 밑줄, `Ctrl+Shift+Alt+-` 취소선 |
| 한자 사전 | `Alt+H` 순환 치환, `Alt+Shift+H` 등록(반영하고 상자를 닫은 뒤 창이 열린다) |
| 링크 보조 | `[[파일:` 이미지 이름 추천, `]]` 를 치면 문서 이름 자동 보정, 링크 안에서 `Enter` 로 링크 빠져나가기 |
| 줄 편집 | `Alt+←/→` 줄 처음/끝, `Alt+↑/↓` 줄 이동, `Ctrl+D` 줄 복제, 정렬 단축키, `Tab`/`Shift+Tab` 들여쓰기, 목록 `Enter` 이어쓰기, 굵게 표시를 한 덩어리로 이동·삭제 |

상자 안에서 **쓰지 않는 것**(본문 전용이라): `Ctrl+F` 찾기, `Ctrl+S` 저장, `Alt+E`(상자 열기), 타자기 위치 맞추기, 동작 상용구(`{!표}`·`{!이미지}` 등 - 표 편집기 같은 창을 본문에서 여는 것이라 상자에서는 아무 일도 하지 않고 친 글자를 그대로 둔다).

### 저장 규칙

- 줄바꿈 → `[br]`. 줄 끝 공백과 앞뒤의 빈 줄은 지운다. 가운데의 빈 줄은 `[br][br]` 로 남는다.
- 각주 안에는 `]` 를 쓸 수 없다(각주를 닫아 버리므로, 뷰어의 규칙도 같다). 상자에서 `]` 를 치면 전각 `］` 로 바뀐다.
- 상자를 연 사이에 그 자리의 글이 달라졌으면(다른 문서로 옮겼거나 고쳤으면) 아무것도 바꾸지 않는다.

## 알아 둘 것

- 각주 안에 `[[문서 링크]]` 나 `[0]` 처럼 **짝이 맞는 대괄호**를 써도 각주가 거기서 끝나지 않는다(뷰어와 편집기가 `src/lib/footnoteSyntax.js` 의 같은 규칙을 쓴다). 짝 없이 낱개로 쓴 `]` 만 편집 상자에서 적용할 때 전각 `］` 로 바뀐다.

- 색 구분은 기본 켜짐이고, 메뉴 **설정 > 각주 색**을 끄면 각주를 색칠하지 않는다(각주 편집 상자·Alt+E 는 그대로 쓸 수 있다). 값은 앱 설정 파일(config.json)에 저장되고 바로 반영된다. 각주가 없는 문서는 예전과 똑같이 그려진다.
- 밝은 테마와 어두운 테마 모두 보이도록 색을 투명하게 섞어 칠한다. 어두운 테마의 실제 화면으로 확인했다.
- Alt+E 는 커서가 각주 안일 때만 동작하고, 아닐 때는 키를 그대로 둔다. 단축키 설정 화면에서 바꾸는 기능은 아직 없다.
- 각주 본문을 문서 아래로 모으는 새 문법(예: `[*가]` 로 표시만 하고 내용은 따로 적기)은 만들지 않았다. 파일 형식을 바꾸지 않기 위해서다.

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| 각주 | 본문 아래에 번호로 모여 보이는 덧붙임 글. 위키에서는 `[* 내용]` 으로 쓴다 |
| `[br]` | 글 안에서 줄을 바꾸는 표시. 각주 안에서 줄을 나눌 때도 쓴다 |
| 배경판 | 입력칸 뒤에 같은 글을 투명하게 겹쳐 그려 두고 배경색만 보이게 하는 층. 글자 위치가 어긋나지 않게 입력칸과 같은 크기로 맞춘다 |
| 실행 취소(Ctrl+Z) | 방금 한 편집을 되돌리는 기능. 상자에서 반영한 내용도 한 번에 되돌아간다 |
