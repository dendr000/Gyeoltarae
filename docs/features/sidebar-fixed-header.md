# 사이드바 고정 머리 (검색칸, + 새 문서, + 새 폴더)

## 한 줄 요약

왼쪽 사이드바의 **검색칸과 "+ 새 문서"·"+ 새 폴더" 단추가 맨 위에 고정**되어, 문서·폴더 목록이 길어서 스크롤해도 늘 보인다. 예전에는 이것들도 목록과 함께 위로 밀려 사라졌다.

## 동작

- 사이드바는 위에서부터 **제목("결타래") → 고정 머리(검색칸 + 두 단추) → 스크롤되는 목록**이다. 스크롤은 목록 영역만 한다.
- 두 단추는 작업 폴더(맨 위) 아래에 새 문서·새 폴더를 만든다(이전과 같다). 각 폴더 줄에 마우스를 올리면 나오는 "+문서"·"+폴더"는 그대로 그 폴더 안에 만든다.
- 검색 결과 창은 고정 머리 위에 겹쳐서 목록 위로 뜬다(단추 위를 덮는다).
- 분류·자료·틀·이미지·상용구·사전 같은 아래 공간은 이전처럼 목록과 함께 스크롤된다.

## 구조

| 파일 | 역할 |
|---|---|
| `src/App.jsx` | 사이드바의 고정 영역(`app-sidebar-fixed`)에 검색칸과 두 단추를 두고 그 아래에 스크롤 영역(`app-sidebar-body`) |
| `src/components/FileTree.jsx` | 두 단추를 여기서 뺐다(고정 영역으로 옮김) |
| `src/App.css` | `.app-sidebar-fixed` — 줄어들지 않고(`flex-shrink: 0`), 위에 쌓이고, 사이드바 배경색과 아래 선 |
| `tests/components/sidebarFixedHeader.test.js` | 구조 점검 |

## 확인한 것 (실제 Electron 창)

문서 60개를 만든 작업 폴더에서 목록을 맨 아래까지 스크롤해도(스크롤 위치 1,654px) 검색칸·단추의 위치가 그대로(검색칸 51~95, 단추 95~126) · 스크롤한 채 "+ 새 문서"를 눌러 새 문서 창이 뜸 · 검색어를 치면 결과 창이 단추를 덮고 목록 위에 보임(결과 창 안을 눌러도 목록이 아니라 결과가 눌림).

## 용어 설명 (초보자용)

| 용어 | 뜻 |

| 고정 | 스크롤해도 제자리에 남아 있는 것 |
