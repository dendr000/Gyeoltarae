# 화면 모드 단축키 (Ctrl+E, Ctrl+1/2/3)

## 한 줄 요약

**Ctrl+E** 는 뷰어와 편집을 오가고(듀얼은 건너뜀), **Ctrl+1 / 2 / 3** 은 각각 뷰어 / 듀얼 / 편집으로 바로 간다. 헤더의 모드 단추를 누르는 것과 같다.

## 키 표

| 키 | 지금 모드 | 이동하는 모드 |
|---|---|---|
| Ctrl+1 | 어느 모드든 | 뷰어 |
| Ctrl+2 | 어느 모드든 | 듀얼 |
| Ctrl+3 | 어느 모드든 | 편집 |
| Ctrl+E | 뷰어 | 편집 |
| Ctrl+E | 편집 | 뷰어 |
| Ctrl+E | 듀얼 | 뷰어 |

- 듀얼에서 Ctrl+E 를 누르면 뷰어로 간다. 한 번 더 누르면 편집이 되고, 그다음부터는 뷰어와 편집만 오간다(듀얼로는 Ctrl+2 로만 간다).
- Shift 나 Alt 가 같이 눌린 조합과 한글 입력 조합 중에는 반응하지 않는다. 한글 자판 상태에서도 된다. Mac 은 Cmd.
- **새 문서·표 편집기·사전 같은 창(모달)이 떠 있는 동안은 무시한다.** 뷰어로 바뀌면 편집 영역이 화면에서 사라지는데, 표 편집기 같은 창은 편집 영역 안에 들어 있어서 작업 중이던 내용이 날아가기 때문이다.
- 모드 단추에 마우스를 올리면 단축키가 안내 글로 보인다.

## 관련 파일

| 파일 | 역할 |
|---|---|
| `src/lib/modeShortcut.js` | 눌린 키와 현재 모드로 이동할 모드를 정하는 순수 함수 |
| `src/App.jsx` | 전역 keydown 에서 모달이 없을 때만 모드를 바꿈 (Ctrl+M·Ctrl+W 와 같은 자리) |
| `src/components/EditorHeader.jsx` | 모드 단추 안내 글에 단축키 표시 |
| `tests/lib/modeShortcut.test.js` | 키 판별 12개 + 연결 확인(소스 점검) 3개 |

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| 뷰어 / 듀얼 / 편집 | 렌더된 문서만 보기 / 왼쪽 편집·오른쪽 미리보기를 함께 보기 / 편집 영역만 보기 |
| 모달 | 화면 위에 떠서 닫기 전에는 다른 곳을 못 쓰는 창(새 문서 이름 입력, 표 편집기 등) |
| 전역 keydown | 화면 어디에 포커스가 있든 키가 눌리면 받는 처리 |
