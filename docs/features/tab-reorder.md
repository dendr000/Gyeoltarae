# 탭 순서 바꾸기 (Ctrl+Alt+←/→, 탭을 누른 채 방향키)

## 한 줄 요약

지금 열린 탭은 **Ctrl+Alt+←/→** 로, 위쪽 탭 바에서 **탭을 마우스로 누른 채**(버튼을 떼기 전까지) **← / →** 방향키를 누르면 그 탭이 한 칸씩 왼쪽/오른쪽으로 옮겨 간다.

## Ctrl+Alt+←/→ — 지금 열린 탭 옮기기 (0.128.0)

- **Ctrl+Alt+←** 는 지금 열려 있는(활성) 탭을 한 칸 왼쪽으로, **Ctrl+Alt+→** 는 한 칸 오른쪽으로 옮긴다. 글을 쓰는 중(입력칸에 커서가 있는 중)에도, 뷰어 모드에서도 된다. 마우스가 필요 없다.
- 맨 왼쪽 탭에서 ←, 맨 오른쪽 탭에서 →는 아무 일도 없다. 열린 탭이 없으면 아무 일도 없다.
- 이름 입력창·표 편집기 같은 창이 떠 있으면 무시한다. 한글 조합 중과 Shift·Meta 가 같이 눌린 조합은 해당하지 않는다.
- **Alt+←/→ (Ctrl 없이)** 는 편집기의 "줄 맨 앞/맨 뒤로 이동"이고 그대로다. Alt+↑/↓ 는 줄 이동([line-move.md](line-move.md))이다. 탭 이동은 Ctrl+Alt+←/→ 로만 한다.
- 탭을 한 번 클릭한 뒤 방향키만으로 옮기는 방식은 아니다: 클릭하면 문서가 열리며 글 입력칸이 포커스를 받아 방향키가 글 커서 이동에 쓰이기 때문이다(그 상태의 키를 가로채면 글 쓰는 중 커서 이동이 막힌다). 그래서 조합키(Ctrl+Alt)로 구별했다.
- 일부 노트북·그래픽 드라이버(인텔 그래픽 등)는 **Ctrl+Alt+방향키를 화면 회전 단축키**로 쓴다. 키를 눌렀더니 화면이 돌아가거나 앱에 키가 오지 않으면 그래픽 설정에서 "단축키 사용 안 함"으로 끈다(앱에서는 처리할 수 없다).

## 탭을 누른 채 방향키 (0.126.0)

1. 순서를 바꾸고 싶은 탭 위에서 마우스 왼쪽 버튼을 **누른 채로 둔다.**
2. 그 상태에서 **←** 또는 **→** 를 누른다. 누를 때마다 탭이 한 칸씩 움직인다(키를 계속 누르고 있으면 계속 움직인다).
3. 마우스 버튼을 뗀다. 순서는 그대로 남는다.

| 하는 일 | 결과 |
|---|---|
| 탭을 누른 채 → | 그 탭이 오른쪽으로 한 칸 |
| 탭을 누른 채 ← | 그 탭이 왼쪽으로 한 칸 |
| 맨 왼쪽 탭에서 ← / 맨 오른쪽 탭에서 → | 아무 일 없음 |
| 탭을 누르지 않고 ← / → | 평소대로 글 커서가 움직인다(탭은 그대로) |
| 탭의 ✕(닫기) 단추를 누른 채 | 해당 없음(닫기 단추는 옮기기를 시작하지 않는다) |
| 탭을 그냥 클릭 | 그 탭으로 전환(예전과 같다) |

## 동작 규칙

- **옮기는 것은 탭 순서뿐**이다. 지금 열려 있는(활성) 탭은 그대로이고, 탭 안의 문서·스크롤 위치·저장 안 된 표시도 바뀌지 않는다. 활성이 아닌 탭을 옮겨도 그 탭으로 전환되지 않는다.
- **옮긴 뒤 버튼을 떼는 클릭은 탭 전환으로 처리하지 않는다.** 옮기는 사이 그 자리에 다른 탭이 와 있을 수 있어서, 의도하지 않은 전환을 막는 것이다. 옮기지 않고 그냥 눌렀다 뗀 클릭은 예전처럼 전환한다.
- 탭이 많아 탭 바에 가로 스크롤이 생겼을 때, 옮긴 탭이 가려지지 않게 보이는 자리로 스크롤한다.
- Shift·Ctrl·Alt 가 같이 눌린 방향키와 한글 조합 중에는 반응하지 않는다.
- 탭 순서는 앱을 켜 둔 동안만 유지된다(탭 목록 자체가 앱을 끄면 사라지는 것과 같다).
- 누르는 동안 탭 글자가 선택되지 않도록 탭에서 글자 선택을 막았다.

| 파일 | 역할 |

## 확인한 것 (실제 Electron 창, 실제 마우스·키 입력)

Ctrl+Alt+←/→: 탭 3개(가·나·다*)에서 글 입력칸에 커서가 있는 채 Ctrl+Alt+← 두 번 = `다* 가 나`, 맨 왼쪽에서 ← 는 그대로, Ctrl+Alt+→ 두 번 = `가 나 다*` · Alt+← 만 누르면 탭은 그대로고 커서가 줄 처음으로 감 · Ctrl+← 만 누르면 탭은 그대로.

누른 채 방향키(0.126.0):

탭 3개(가·나·다, 다가 활성)에서: 누르지 않고 → 는 변화 없음 · `가` 를 누른 채 → 두 번 = `나 다* 가` · 맨 오른쪽에서 → 는 그대로 · ← 로 한 칸 되돌림 · 버튼을 뗀 뒤 활성 탭은 그대로(`다*`) · 뗀 뒤 ← 는 탭을 더 옮기지 않음 · 그냥 클릭은 전환(`가*`).

## 한계

- 마우스 버튼을 **누르고 있는 동안에만** 된다. 탭을 클릭해 활성으로 만든 뒤 버튼을 뗀 상태에서 방향키로 옮기는 방식은 아니다(그 상태의 방향키는 글 커서 이동이 먼저이기 때문). 그 방식이 필요하면 다른 키 조합을 정해서 추가할 수 있다.
- 탭을 마우스로 끌어서 옮기는 기능은 아직 없다.

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| 탭 | 위쪽에 가로로 나열된, 열어 둔 문서 하나하나의 이름표 |
| 활성 탭 | 지금 화면에 보이는 문서의 탭(색이 달라 보인다) |
| 누른 채 | 마우스 왼쪽 버튼을 눌렀지만 아직 떼지 않은 상태 |
