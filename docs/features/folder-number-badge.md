# 폴더 이름 앞 숫자 배지

## 한 줄 요약

파일 트리에서 폴더 이름이 `01 올인원 DBMS`, `02 …` 처럼 숫자로 시작하면, 문서와 똑같이 숫자를 이름 옆 **배지**로 따로 보여 준다.

## 모양

| 실제 이름 | 트리에 보이는 모양 |
|---|---|
| `01 올인원 DBMS!! 설계부터 운영까지!!` (폴더) | `01` 배지 + `올인원 DBMS!! 설계부터 운영까지!!` |
| `01 데이터베이스 개론 및 DBMS 환경 설정` (문서) | `01` 배지 + `데이터베이스 개론 및 DBMS 환경 설정` |
| `강의` | `강의` (배지 없음) |

## 규칙

- 이름 맨 앞이 **숫자 + 공백 + 이름**이면 숫자가 배지가 된다. 숫자의 앞자리 0(`01`, `02`)은 그대로 보인다.
- 숫자 뒤에 공백이 없으면(`2024년 기록`, `3D`) 번호로 보지 않는다.
- 숫자만 있는 이름(`01`)은 번호로 떼어내지 않는다(이름이 사라지지 않게).
- 폴더 이름을 바꾸거나 새로 만들 때 입력하는 이름은 숫자까지 포함한 실제 이름이다. 배지는 **보이는 모양만** 나눈 것이라 실제 폴더 이름과 정렬 순서는 그대로다.
- 문서와 폴더가 같은 규칙을 쓴다. 이 규칙은 폴더 위치와 상관없이 **모든 폴더**에 적용된다(따즈아 폴더 아래에만 해당하는 것이 아니다).

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| **배지(badge)** | 이름 옆에 작은 상자 모양으로 따로 보여 주는 표시. 여기서는 순서 번호. |
| **파일 트리** | 화면 왼쪽의 폴더·문서 목록. |

## 구현 위치

- `src/lib/displayName.js` — 이름 앞 숫자를 떼어내는 규칙(`splitLeadingNumber`). 문서 이름 → 에디터 제목에서 번호를 떼는 곳도 같은 함수를 쓴다.
- `src/components/TreeLabel.jsx` — 번호 배지와 이름을 그리는 작은 컴포넌트. 문서 행과 폴더 행이 같이 쓴다. (예전에는 문서 행에만 이 코드가 있었다)
- `src/components/FileTree.jsx` — 문서 행·폴더 행에서 `TreeLabel` 사용.
- 테스트: `tests/components/treeLabel.test.js`.

## 알려진 한계

- 배지는 **파일 트리에만** 적용했다. 이동 창 등 폴더 이름이 보이는 다른 화면은 손대지 않았다.
- 이전 이름(숫자 없는 폴더)을 숫자 붙은 이름으로 바꾸면 배지가 생기고, 숫자를 지우면 사라진다(이름 자체가 바뀌는 것).
