# 폴더 기본 틀 — 폴더에 글양식(틀)을 지정해 새 문서에 자동 적용

## 한 줄 요약

폴더를 **우클릭 → "기본 틀 설정…"** 에서 글양식(틀) 하나를 골라 두면, 그 폴더(와 아래 폴더)에서 **새 문서를 만들 때 그 틀이 자동으로 골라진다.** 새 강의 폴더가 생길 때마다 코드를 고칠 필요가 없다 — 틀을 한 번 만들어 두고 폴더에 지정하면 된다.

## 쓰는 법

1. 사이드바 **틀** 에서 글양식(틀)을 만든다(이미 있으면 생략). 틀의 내용이 새 문서의 시작 내용이 된다. (예: `=  =` + ` ```DBeaver ` 코드블록 묶음)
2. 파일 트리에서 강의 폴더를 **우클릭 → 기본 틀 설정…** → 드롭다운에서 틀을 고르고 **저장**.
3. 그 폴더에서 **새 문서**를 만들면 "글양식(틀)" 칸에 그 틀이 이미 골라져 있다(`강의 틀 (이 폴더의 기본 틀)`). 그대로 만들면 그 틀 내용으로 시작한다.
4. 해제하려면 같은 창에서 **(설정 안 함)** 을 고르고 저장한다.

### 새 문서 창의 "글양식(틀)" 칸

글을 직접 치는 칸이 아니라 **목록에서 고르는 칸**이다(예전에는 긴 안내문이 적힌 입력칸이었다).

| 항목 | 뜻 |
|---|---|
| 맨 위 항목 (기본 선택) | **자동.** 폴더 기본 틀이 있으면 `틀 이름 (이 폴더의 기본 틀)`, 없고 이 폴더에 내장 기본 내용이 있으면 `이 폴더의 기본 내용`, 둘 다 없으면 `빈 문서` |
| 틀 이름들 | 직접 고른 틀. 폴더 기본 틀보다 우선한다 |
| `빈 문서 (틀을 쓰지 않음)` | 폴더 기본 틀이 있거나 내장 기본 내용이 있는 폴더에서만 나온다. 고르면 그것들을 모두 건너뛰고 `[[분류:]]` 한 줄로 시작한다 |

## 동작 규칙

- **새 문서 시작 내용의 우선순위**: ① 새 문서 창에서 직접 고른 틀 → ② 폴더 기본 틀 설정 → ③ 내장 폴더 기본 내용(`docs/features/folder-doc-template.md` 의 따즈아 01·02) → ④ `[[분류:]]` 한 줄. "틀을 쓰지 않음"을 고르면 ②③ 을 건너뛴다.
- **물려받기**: 폴더에 설정이 없으면 **가장 가까운 윗 폴더**의 설정이 적용된다(여러 겹이면 가까운 것 하나만). 예) `따즈아` 에 정해 두면 그 아래 모든 강의 폴더가 같은 틀을 쓰고, 그중 한 강의에만 다른 틀을 정하면 그 강의만 달라진다. 설정 창에는 윗 폴더 설정이 적용 중이라는 안내가 나온다.
- **저장 위치**: 폴더 안의 숨김 파일 `.wikidesk-default-template.json` (`{ "template": "틀 이름" }`). 폴더 이름을 바꾸거나 옮겨도 설정이 따라간다. 파일 트리에는 보이지 않는다. 이 PC 가 아니라 **워크스페이스(폴더)에 저장**되므로 폴더를 다른 PC 로 옮겨도 유지된다.
- **틀 내용 처리**: 새 문서 창에서 직접 틀을 고른 것과 똑같다. 틀 안의 `{{{#!if}}}` 등은 한 번 풀려서 복사되고, 비어 있는 `[[분류:]]` 칸은 작품 폴더 자동 분류와 폴더의 "자동 분류"(`docs/features/auto-category.md`)가 채운다.
- **적용되는 길**: 새 문서를 만드는 모든 길 — "+ 새 문서", 폴더의 "새 문서", 우클릭 메뉴 "새 문서", 없는 문서 링크(`[[없는 문서]]`)를 눌러 만드는 문서. 파일을 끌어다 놓아 가져온 문서에는 적용되지 않는다(가져온 내용 그대로).
- **정해 둔 틀이 없어졌을 때**: 틀을 지우거나 이름을 바꾸면 폴더 설정은 그 이름을 그대로 들고 있다. 그 틀을 찾지 못하면 오류 없이 다음 우선순위(내장 기본 내용 → 빈 분류 줄)로 넘어간다. 설정 창에는 `이름 (없는 틀)` 로 보인다 — 새 틀을 골라 다시 저장하면 된다.

## 기존 따즈아 01·02 폴더의 내장 기본 내용을 틀로 옮기려면

지금 `01 올인원 …`, `02 배워서 …` 폴더는 코드에 박혀 있는 내용(`src/lib/folderDocTemplate.js`)을 쓴다. 그대로 두어도 되고(폴더 기본 틀 설정이 없으면 이 내용이 쓰인다), 앞으로는 틀로 관리하고 싶다면:

1. 기존 문서 하나의 내용을 복사해 사이드바 **틀** 에 새 틀(예: `강의 틀`)로 만든다.
2. 그 폴더에 "기본 틀 설정…"으로 지정한다 — 이 설정이 내장 기본 내용보다 우선한다.

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| 글양식(틀) | 사이드바 "틀"에 만들어 두는 문서. 새 문서를 만들 때 그 내용을 한 번 복사해서 시작한다 |
| 기본 틀 | 폴더에 미리 지정해 둔 글양식. 그 폴더에서 새 문서를 만들면 자동으로 골라진다 |
| 숨김 파일 | 이름이 `.` 으로 시작해서 파일 트리에 나타나지 않는 설정용 파일 |
| 물려받기 | 아래 폴더가 윗 폴더의 설정을 그대로 따르는 것 |

## 알려진 한계

- 틀 이름으로 연결하므로 틀 이름을 바꾸면 폴더 설정이 끊긴다(위 "정해 둔 틀이 없어졌을 때"). 폴더 설정을 자동으로 따라 바꾸지는 않는다.
- 한 폴더에는 틀을 하나만 지정할 수 있다. 여러 틀 중 고르려면 새 문서 창의 드롭다운에서 직접 고른다.
- 이 설정 창과 새 문서 창은 글자를 치는 칸이 아니라 목록 고르기라서, 틀이 매우 많으면 목록이 길어진다.
