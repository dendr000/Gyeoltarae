# 이미지 이름 바꾸기 · 우클릭 메뉴 · 문서에 넣기

## 한 줄 요약

사이드바 **이미지** 영역의 이미지를 **우클릭**하면 메뉴가 뜬다: **문서에 넣기 · 문법 복사 · 이름 바꾸기 · 삭제**. 그리고 **이미지 이름을 바꾸면 문서에 이미 쓰여 있는 `[[파일:옛이름]]` 도 같이 새 이름으로 바뀐다**(열려 있는 문서 포함). 예전에는 이름을 바꾸면 문서 속 그림이 "없음"으로 끊어졌다.

## 이미지 우클릭 메뉴

| 항목 | 하는 일 |
|---|---|
| **문서에 넣기** | 지금 열려 있는 문서의 **커서 자리에** `[[파일:이름]]` 을 **단독 줄로 바로 넣는다.** 클립보드(복사해 둔 글)를 쓰지 않으므로 복사해 둔 다른 내용이 지워지지 않는다. **듀얼·편집 모드에서 문서가 열려 있을 때만** 메뉴에 나온다(뷰어 모드에는 편집창이 없다) |
| **문법 복사 (`[[파일:이름]]`)** | 한 번 클릭했을 때와 같다 — `[[파일:이름]]` 을 클립보드에 복사한다 |
| **이름 바꾸기** | 더블클릭과 같다 — 이름 칸이 입력 상태가 된다. 새 이름을 쓰고 **Enter**(취소는 **Esc**). **우클릭으로 바꾸면 클릭 때처럼 클립보드를 덮어쓰지 않는다** |
| **삭제** | 이미지를 휴지통으로 보낸다(이미지 옆 × 단추와 같다) |

- 한 번 클릭은 그대로 `[[파일:이름]]` 문법 복사, 더블클릭은 그대로 이름 바꾸기다. 마우스를 올리면 "클릭: 문법 복사 · 더블클릭: 이름 바꾸기 · 우클릭: 메뉴" 안내가 뜬다.
- 더블클릭은 먼저 한 번 클릭으로 인식되어 **클립보드가 덮어써지므로**, 복사해 둔 글이 있을 때는 우클릭 > 이름 바꾸기가 편하다.

## 이름을 바꾸면 문서도 같이 바뀐다

- 이미지 이름을 바꾸면 **문서·틀·자료·분류 페이지·상용구** 중 그 이미지를 쓰는 곳의 `[[파일:옛이름]]` 이 모두 새 이름으로 바뀐다. 바뀐 문서 수가 이미지 영역 아래에 "문서 2개의 이미지 링크도 함께 바꿨습니다" 로 잠깐 보인다.
- **너비·옵션은 그대로**다: `[[파일:고양이\|300px\|link=문서명]]` → `[[파일:야옹이\|300px\|link=문서명]]`.
- **이름이 정확히 같은 이미지만** 바뀐다. `고양이2`, `큰 고양이` 처럼 이름이 비슷한 다른 이미지의 참조는 그대로다.
- **코드블록(``` 로 감싼 줄) 안의 글은 건드리지 않는다.** 설명용 예시일 수 있어서다.
- 같은 이름의 이미지가 이미 있어 **번호가 붙은 이름**(예: `강아지 (1)`)으로 바뀌면 문서에도 그 최종 이름이 들어간다.
- **열려 있는 문서**: 저장 안 된 글이 있어도 먼저 저장한 뒤 바꾸고, 열려 있는 화면(탭)의 글도 같이 바뀐다. 안 그러면 그 탭이 나중에 저장되면서 옛 이름으로 되돌려 버린다.
- 파일 하나(문서 하나)씩 디스크에서 다시 읽고 바꾼 것만 저장한다. 이미지를 쓰지 않는 문서는 건드리지 않는다.

## 확인한 것 (실제 Electron 창, 실제 마우스·키 입력)

문서 3개(`가`: 참조 1개 + 코드블록 안 참조 1개, `나`: 참조 1개, `다`: 참조 없음)와 이미지 `고양이` 로: 이미지 우클릭 → 메뉴 4개(문서에 넣기·문법 복사·이름 바꾸기·삭제) · 이름 바꾸기를 눌러 `야옹이` 로 Enter → 이미지 항목과 파일이 `야옹이` 로 바뀜, "문서 2개의 이미지 링크도 함께 바꿨습니다" 표시 · **열려 있던 문서의 편집창 글이 바로 `[[파일:야옹이\|200px]]` 로 바뀜**(코드블록 안은 그대로) · 디스크의 `가`, `나` 도 바뀌고 `다` 는 그대로 · 편집창 맨 끝에 커서를 두고 우클릭 > 문서에 넣기 → `[[파일:야옹이]]` 가 단독 줄로 들어가고 편집창이 포커스를 유지.

## 알아 둘 것·한계

- 이미지가 **이름이 같은 참조와 다르게 쓰인 경우**(예: 이름 앞뒤 공백)는 공백을 무시하고 같은 이미지로 본다. 대소문자는 구분한다.
- 이름 바꾸는 동안 다른 문서를 동시에 고치고 있으면(앱을 두 개 켜는 경우 등) 그 순간의 글이 덮어써질 수 있다. 일반적인 사용에서는 해당되지 않는다.
- **뷰어 모드**에서는 "문서에 넣기"가 메뉴에 나오지 않는다(편집창이 없어서). 이때는 "문법 복사"를 쓴다.
- 이미지를 문서에 넣은 뒤 문서 안(뷰어)에서 바로 이름을 바꾸는 기능은 없다.
