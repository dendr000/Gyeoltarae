# 폴더 범위 영어 단어 추천

## 한 줄 요약

문서에 써 온 **영어 단어**(CREATE, employee_id …)를 기억해 두었다가, **같은 범위의 다른 문서**를 쓸 때 추천 팝업에 올려 준다. 문서 A 에서 `CREATE` 를 썼다면 같은 범위의 문서 B 에서 `C` 만 쳐도 `CREATE` 가 뜬다. 직접 상용구를 만들지 않아도 된다.

## 범위

- **기본 범위 = 두 번째 단계 폴더.** 워크스페이스 루트 아래 폴더 → 그 아래 폴더까지가 한 범위다. 예) `강의/따즈아`, `웹툰/멸망 이후의 세계`. 지금 쓰는 문서가 속한 범위의 단어만 후보가 된다.
- 최상위 폴더 바로 아래에 있는 문서는 그 최상위 폴더가 범위다. 루트 바로 아래의 문서는 범위가 없어서 단어 추천이 없다.
- **최상위 폴더마다 "전체 문서에서 단어 모으기"를 켤 수 있다.** 켜면 그 폴더 아래 모든 문서(두 번째 단계 폴더가 달라도)의 단어를 쓴다. 예) `강의` 를 켜면 `강의/따즈아` 를 쓸 때 `강의/다른강의` 의 단어도 뜬다. 다른 최상위 폴더(`웹툰` 등)의 단어는 섞이지 않는다. 기본은 모든 폴더가 꺼짐이다.

## 쓰는 법과 설정

1. 평소처럼 글을 쓰면 상용구와 같은 추천 팝업에 **`단어(범위 이름)` 라고 표시된 후보**가 섞여 뜬다. 후보를 고르는 방법(방향키, Tab, Enter, 숫자)은 상용구와 같다.
2. 설정: 상용구 모달(사이드바 "상용구 관리" 또는 Alt+T) → **폴더별 사용** 탭 아래쪽.
   - "문서에서 쓴 영어 단어도 추천에 올리기" — 전체 켜기/끄기(기본 켜짐).
   - 최상위 폴더마다 "전체 문서에서 단어 모으기" 체크(기본 꺼짐).
   - 설정은 이 PC 에 저장된다.

## 동작 규칙

| 항목 | 규칙 |
|---|---|
| 단어로 보는 글 | 영문자로 시작하고 영문자·숫자·밑줄이 이어지는 **3글자 이상**(`CREATE`, `emp`, `employee_id`). 한글, 숫자로 시작하는 것(`12abc`), 영문자·숫자에 붙은 중간 글자는 아니다. 한글 바로 뒤의 영어(`NULL값`)는 단어다 |
| 단어로 세지 않는 글 | `[[위키 링크·분류]]`, `{{틀}}`, `<표 속성 태그>`, 주소(URL) 안의 글자 |
| 코드블록 안의 글 | 단어로 센다(SQL 예시가 주 용도) |
| 대소문자 | 같은 단어는 하나로 묶는다. 보여 주는 모양은 가장 많이 쓴 모양(같으면 대문자 쪽이 앞). 친 글자는 대소문자 구분 없이 찾는다(`cre` → `CREATE`) |
| 후보 순서 | **상용구가 먼저**, 단어는 그 뒤. 단어끼리는 친 글자와 대소문자가 같은 것, 그다음 **많이 쓴 순서** |
| 이미 같은 이름의 상용구가 있는 단어 | 단어 후보로는 올리지 않는다(상용구가 이미 뜨므로) |
| 이 문서에서만 나온 단어 | 후보에서 뺀다 — 방금 치고 있는 글자가 후보로 되돌아오지 않게 |
| 언제 뜨나 | 상용구 추천 팝업이 뜨는 곳과 같다: "타이핑 중 추천 팝업"이 켜져 있을 때, 그리고 언어가 적힌 코드블록(```sql 등) 안. 코드블록 안에서는 단어 중간(`NAME` 의 끝 `E`)에서 시작하는 글자로는 찾지 않는다 |
| 적용되지 않는 곳 | 스페이스바 자동 치환과 Alt+Enter 는 상용구만 쓴다(단어는 해당 없음) |
| 반영 시점 | 문서를 저장하면(색인이 다시 만들어질 때) 새 단어가 반영된다. 아직 저장 전인 글자는 반영되지 않는다 |

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| 추천 팝업 | 글을 치다 보면 커서 아래에 나타나는 후보 목록 |
| 색인(인덱스) | 앱이 문서 내용을 미리 훑어 단어별로 정리해 둔 목록. 매번 문서를 다시 읽지 않고 빨리 찾으려는 용도 |
| 범위 | 어떤 문서들의 단어를 서로 공유하는가의 경계. 여기서는 폴더로 정한다 |
| 두 번째 단계 폴더 | 워크스페이스 바로 아래 폴더(첫 번째) 안의 폴더 |

## 알려진 한계

- 문서를 저장해야 새 단어가 반영된다(저장할 때마다 색인을 다시 만든다). 큰 워크스페이스에서는 저장할 때 문서 전체를 한 번 훑는 계산이 더해진다(설정을 끄면 계산하지 않는다).
- 한글 문서 위주인 폴더에서는 후보가 적거나 없다.
- 영어 단어가 아닌 것(변수명 조각, 오타)도 3글자 이상이면 후보가 된다. 많이 쓴 것이 위에 오므로 보통은 문제가 없다.
- 설정 화면은 미리보기 창이 작아서 스크린샷으로 확인하지 못했고, 화면 구성은 DOM 으로 확인했다.
