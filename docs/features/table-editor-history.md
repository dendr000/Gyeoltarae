# 표 편집기의 되돌리기 · 다시 실행

## 한 줄 요약

표 편집기 안에서 한 일을 **한 단계씩 되돌리고 다시 실행**할 수 있다. 둘째 줄 툴바 맨 앞의 **되돌리기(↶)·다시 실행(↷)** 단추나 **Ctrl+Z / Ctrl+Y** 로 쓴다.

## 쓰는 법

| 동작 | 단추 | 키 |
|---|---|---|
| 되돌리기 | 툴바 맨 앞 ↶ | **Ctrl+Z** |
| 다시 실행 | ↷ | **Ctrl+Y** 또는 **Ctrl+Shift+Z** |

- 더 되돌릴 것이 없으면 ↶ 가, 다시 실행할 것이 없으면 ↷ 가 꺼진다.
- 한글 자판 상태에서도 키가 된다(물리 키 Z·Y 를 함께 본다).
- 되돌려도 **고른 칸은 표 안으로 맞춰진다**(행을 지워서 표가 줄어든 상태로 돌아가도 고른 칸이 표 밖에 남지 않는다).

## 무엇이 한 단계인가

| 한 일 | 되돌리기 단계 |
|---|---|
| 칸에 글자를 치는 것 | **같은 칸에 이어서 치는 동안은 한 단계**. 1초 넘게 쉬었다가 다시 치거나 다른 칸으로 가면 새 단계 |
| 삽입·이동·복제·채우기(Ctrl+D)·정렬·자동 채우기(핸들 끌기) | 한 번에 한 단계 |
| 찾아 바꾸기의 바꾸기 / 모두 바꾸기 | 한 번에 한 단계 |
| 숫자 서식·조건부 색·열 너비·줄무늬 적용 | 한 번에 한 단계 |
| 색·굵게·정렬(맞춤) 적용, 병합·나누기, 행·열 삭제·추가 | 한 번에 한 단계 |
| 붙여넣기(Ctrl+V) | 한 단계(표가 자동으로 커지는 것 포함) |
| **행·열 바꾸기(전치)** | 한 단계 — "첫 번째 행을 헤더로" 체크가 같이 꺼지는 것도 함께 되돌아간다 |
| "첫 번째 행을 헤더로" 체크 켜기·끄기 | 한 단계 |

- 고른 칸·고른 범위를 옮기는 것은 기록하지 않는다(내용이 바뀐 것만 기록한다).
- 기록은 최대 200단계까지 남기고 오래된 것부터 버린다.
- 새로운 변경을 하면 "다시 실행" 목록은 비워진다(되돌린 뒤 다른 일을 하면 앞의 것은 다시 실행할 수 없다). 엑셀과 같다.

## 알아 둘 점

- **모달 안에서만** 되돌린다. "적용"을 눌러 문서에 넣은 뒤에는 이 기록이 사라진다. 문서에 넣은 표를 되돌리려면 문서 편집기의 Ctrl+Z 를 쓴다.
- **"취소"** 는 이 모달에서 한 모든 편집을 버린다(기록과 상관없이).
- **찾기 바·서식 패널 안의 입력칸**(찾을 글자, 값 입력 등)에서 누르는 Ctrl+Z 는 그 입력칸의 평소 글자 되돌리기다. 표 되돌리기가 아니다. 칸에 쓰는 글자(칸 입력창과 아래 "선택한 셀 내용" 입력창)는 표 되돌리기로 처리된다.
- 되돌리기·다시 실행을 눌러도 찾기 바의 검색어나 서식 패널의 입력값은 바뀌지 않는다.

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| **되돌리기(undo)** | 방금 한 일을 취소하고 그 전 상태로 돌아가는 것. |
| **다시 실행(redo)** | 되돌린 것을 다시 적용하는 것. |
| **묶기(coalesce)** | 글자 하나마다 단계가 생기지 않도록 이어진 입력을 한 단계로 합치는 것. |

## 구현 위치

- `src/lib/gridHistory.js` — 기록 규칙(`createHistory`, `record`, `undo`, `redo`). 화면과 분리한 순수 함수. 묶기 규칙(같은 key, 1초 이내), 개수 제한, 다시 실행 목록 비우기.
- `src/components/useGridHistory.js` — 격자와 헤더 설정을 기록과 함께 드는 React 훅(`setGrid` 의 두 번째 인자 `{ coalesce }` 로 묶을 이름을 줌, `setGridAndHeader` 로 둘을 한 단계로).
- `src/components/TableEditorModal.jsx` — 단축키 처리(Ctrl+Z/Y), 고른 칸 보정, 칸 입력의 묶기 이름(`cell:행:열`). `TableStructureToolbar.jsx` — ↶·↷ 단추.
- 테스트: `tests/lib/gridHistory.test.js`. 화면 동작은 미리보기에서 눌러 확인했다(글자 연속 입력이 한 단계, 정렬·전치 되돌리기, 전치와 헤더 체크 동시 복원, 키 조합 3종과 한글 키값, 줄어든 표에서 선택 보정).

## 한계

- 문서에 적용한 뒤에는 이 기록으로 되돌릴 수 없다(문서 편집기의 Ctrl+Z 사용).
- 칸의 글자 안에서 일부만 되돌리는 세밀한 되돌리기는 없다(칸에 이어서 친 한 묶음이 한 단계).
- 실제 Electron 앱 창이 아니라 브라우저 미리보기에서 확인했다.
