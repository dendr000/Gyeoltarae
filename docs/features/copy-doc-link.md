# 문서 링크 복사 (Shift+클릭) 와 [[문서명(폴더명)]]

## 한 줄 요약

사이드바 문서 목록에서 문서를 **Shift+왼쪽 클릭**하면 그 문서를 가리키는 **링크 글**(`[[문서명]]`)이 클립보드에 복사된다. 같은 이름의 문서가 여럿이면 어느 폴더의 문서인지 구분하는 **`[[문서명(폴더명)]]`** 로 복사된다(나무위키의 동음이의 문서 표기처럼). 복사한 글을 문서에 붙여 넣으면 바로 링크가 된다.

## 쓰는 법

1. 사이드바 문서 목록에서 문서 줄을 **Shift 를 누른 채 클릭**한다. 문서는 열리지 않는다.
2. 목록 아래에 **"복사됨: [[변수와 RAM(파이썬)]]"** 같은 안내가 뜬다(복사하지 못하면 "복사하지 못했습니다").
3. 편집 모드에서 링크를 넣을 자리에 **Ctrl+V** 로 붙여 넣는다.

| 문서 | 복사되는 글 |
|---|---|
| 이름이 하나뿐인 문서 `혼자` | `[[혼자]]` |
| `0891 치고마` (앞에 순서 번호) | `[[치고마]]` (목록에 보이는 번호 뗀 이름) |
| 같은 이름이 둘: `03 멘토씨리즈 C언어(개정판)/03 변수와 RAM` | `[[변수와 RAM(멘토씨리즈 C언어(개정판))]]` |
| 같은 이름이 둘: `05 파이썬/변수와 RAM` | `[[변수와 RAM(파이썬)]]` |

- **그냥 클릭**은 예전처럼 문서를 연다. Shift+클릭에 다른 기능은 없었다(확인함).
- Shift 를 누른 채 눌러도 글자 범위가 선택되지 않는다.
- 폴더 줄에서의 Shift+클릭은 아무 일도 없다(문서에서만 된다).

## `[[문서명(폴더명)]]` 문법 (이번에 새로 지원)

이름이 같은 문서가 여럿일 때 `[[문서명]]` 만 쓰면 뷰어에서 "문서 N개와 일치 — 클릭해서 선택" 고르기 링크가 된다. 이제 `[[문서명(폴더명)]]` 로 쓰면 **그 폴더의 문서로 바로 연결**된다. 복사 기능이 만드는 글이 이 문법이다. 직접 써도 된다.

- **폴더명**은 그 문서가 **바로 들어 있는 폴더**의 이름이다. 목록에 보이는 이름(앞 순서 번호를 뗀 이름)이나 번호가 붙은 실제 폴더 이름 둘 다 된다: `[[변수와 RAM(파이썬)]]`, `[[변수와 RAM(05 파이썬)]]`.
- **폴더 이름에 괄호가 있어도 된다:** `[[변수와 RAM(멘토씨리즈 C언어(개정판))]]`.
- **제목으로 바로 가는 링크**도 된다: `[[변수와 RAM(파이썬)#메모리]]`.
- **보이는 글자**는 쓴 그대로 `변수와 RAM(파이썬)` 이다. 다르게 보이게 하려면 `[[변수와 RAM(파이썬)|파이썬의 변수]]` 처럼 `|` 뒤에 쓴다.
- **문서 이름 자체에 괄호가 있는 문서**(`함수(개념)`)는 이름 그대로 찾는 것이 먼저라서 영향이 없다.
- 폴더 이름이 맞지 않으면 "없는 문서" 점선 링크가 된다. 같은 폴더 이름이 두 곳 이상에 있어서 그래도 하나로 좁혀지지 않으면 고르기 링크가 된다.

## 어떻게 링크 글을 정하나

사이드바에서 문서 하나를 가리키는 **가장 짧은** 글을, 만든 글을 실제로 해석해 보아 **그 문서 하나로 풀리는 것만** 쓴다.

1. 목록에 보이는 이름(번호 뗀 이름)만으로 하나로 풀리면 → `[[이름]]`
2. 아니면 그 이름에 폴더를 붙여서(번호 뗀 폴더 이름 → 번호 있는 폴더 이름) → `[[이름(폴더)]]`
3. 그래도 안 되면 번호가 붙은 파일 이름으로 같은 순서로 → `[[01 시작]]`, `[[01 시작(공통)]]`
4. 목록에 아직 없는 문서는 풀리는지 확인할 수 없으므로 `[[이름]]`

## 알아 둘 점과 한계

- 문서 이름에 `#`, `|`, `]]` 가 들어 있으면 위키 문법이 다르게 읽어서 링크가 의도대로 안 될 수 있다(`#` 는 제목 이동, `|` 는 보이는 글자 구분). 이 경우 이름을 고치는 것이 가장 안전하다.
- 같은 폴더 이름이 여러 위치에 있고 문서 이름도 같으면 폴더로도 구분되지 않아 번호가 있는 파일 이름을 쓴다. 번호도 없으면 하나로 가리킬 수 없다.
- Shift+클릭 복사는 **사이드바의 문서 목록**에서만 된다(분류·자료·틀 목록은 해당 없음).
- 편집 중 `[[이름]]` 을 치면 문서가 하나로 풀릴 때 파일 이름으로 바꿔 주는 기존 자동 완성은 `[[문서명(폴더명)]]` 에는 적용되지 않는다(치는 그대로 둔다).

## 확인한 것 (실제 Electron 창, 실제 마우스 입력)

`강의/03 멘토씨리즈 C언어(개정판)/03 변수와 RAM`, `강의/05 파이썬/변수와 RAM`, `메모/혼자` 문서에서: Shift+클릭으로 앞의 둘은 `[[변수와 RAM(멘토씨리즈 C언어(개정판))]]` / `[[변수와 RAM(파이썬)]]`, 하나뿐인 것은 `[[혼자]]` 가 복사되고 안내가 뜸 · 실제 클립보드에도 같은 글이 들어감 · 문서는 열리지 않고 글자 범위 선택도 없음 · 그냥 클릭은 문서를 엶 · 뷰어에서 `[[변수와 RAM(파이썬)]]` 은 파이썬 문서로, `[[변수와 RAM(멘토씨리즈 C언어(개정판))]]` 은 C언어 문서로 연결되고 `[[변수와 RAM]]` 은 고르기 링크, `[[혼자]]` 는 정상 연결.

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| 위키링크 | `[[문서명]]` 처럼 대괄호 두 개로 다른 문서를 가리키는 문법. 뷰어에서 누르면 그 문서로 간다 |
| 동음이의(같은 이름) 문서 | 이름이 같지만 다른 폴더에 있는 서로 다른 문서 |
| 클립보드 | Ctrl+C 로 복사한 글이 잠깐 저장되는 곳. Ctrl+V 로 붙여 넣는다 |
| Shift+클릭 | Shift 를 누른 채 마우스 왼쪽 버튼을 누르는 것 |
