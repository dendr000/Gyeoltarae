# 인물 표 보기 (헤더 "인물 표" 단추)

## 한 줄 요약

등장인물 문서에 이미 적어 둔 인물 블록(`= 이름 =` 제목, `특기:값` 줄, 회차 줄)을 **표로 모아 보여 주고**, 이름·속성·회차로 걸러 보고 정렬하는 화면이다. 문서 글은 **읽기만 하고 바꾸지 않는다**(저장 형식 그대로).

## 쓰는 법

1. 인물이 많은 문서를 연다.
2. 위쪽 헤더의 **인물 표** 단추를 누른다. 뷰어 자리에 표가 나온다(편집 전용 모드였다면 듀얼로 바뀐다). 다시 누르거나 **문서로**를 누르면 원래 문서 화면으로 돌아간다.
3. 걸러 보기:
   - **검색칸**: 이름·속성 값·비고·소속에서 글자를 찾는다(대소문자 무시).
   - **값 칩**: 왼쪽 상자에서 속성(특기 등)을 고르면 그 값이 `복사 7` 처럼 인원수와 함께 나온다. 누르면 그 값을 가진 인물만 남는다. 같은 속성 안에서는 하나라도 맞으면, 속성이 다르면 모두 맞아야 한다.
   - **회차 범위**: 시작~끝 사이에 등장하는 회차가 하나라도 있는 인물만 남는다(한쪽만 적어도 된다).
   - **초기화**: 검색·칩·회차 범위를 한꺼번에 지운다(정렬은 그대로).
4. **정렬**: 열 머리를 누르면 오름차순, 한 번 더 누르면 내림차순, 또 누르면 문서에 적힌 순서로 돌아간다. 값이 없는 인물은 어느 쪽이든 맨 뒤에 둔다.
5. **행 누르기**: 문서 보기로 돌아가 그 인물 제목 위치로 이동한다. 행 오른쪽 연필 단추는 편집기에서 그 제목 줄로 커서를 옮긴다.
6. **표로 복사**: 지금 보이는 인물(거른 결과)을 위키 표(`||` 문법) 글자로 클립보드에 복사한다. 다른 문서에 붙여 넣어 쓸 수 있고, 원래 문서는 바뀌지 않는다.
7. 걸러 보기·정렬 상태는 문서별로 이 PC 에 기억한다(최근 60개 문서). 문서 안에는 아무것도 쓰지 않는다.

## 인물을 읽는 규칙

```text
= 귀능 =                         <- 제목: 인물 이름
특기:복사                         <- 속성 줄: 짧은 키 + 콜론 + 값 (표의 열이 된다)
서장의 비서인 판다 혼혈.           <- 설명: 첫 줄만 "비고"에 쓴다
078 긁적긁적                      <- 회차 줄: 숫자 3~5자리 + 공백 + 제목·대사
```

- 아래에 더 작은 제목이 없는 제목 하나가 인물 한 명이다. 그 위에 있는 더 큰 제목은 **소속**(예: `1부 > 서장`)이 된다.
- 속성 열은 문서에서 많이 쓰인 순서로 자동 만든다. 같은 키가 두 번 나오면 값을 쉼표로 잇는다.
- 첫·끝 회차와 횟수는 회차 줄에서 계산한다(번호가 뒤섞여 있어도 최솟값·최댓값을 쓴다).
- 코드블록(```` ``` ````) 안, `[[분류:...]]`, `[목차]`, 표 줄, 목록·인용 줄은 읽지 않는다. 이름 속 각주는 떼고, `???` 이름은 중복으로 세지 않는다.
- 같은 이름이 둘 이상이면 행은 모두 보이고 `중복` 표시가 붙는다.

## 문서 점검과의 연결

인물 문서로 보이는 글(인물 3명 이상, 절반 이상이 속성이나 회차를 가짐)에서는 메뉴 **편집 > 문서 점검**이 `속성·회차가 없는 인물`, `이름이 같은 인물`을 "참고" 수준으로 알려 준다. 일반 문서에는 이 점검이 나오지 않는다. ([`doc-check.md`](doc-check.md))

## 성능

- 표 화면이 열려 있을 때만 글을 읽는다. 글이 바뀌면 입력을 막지 않게 뒤로 미뤄서(`useDeferredValue`) 계산한다.
- 행은 화면에 보이는 것만 그린다(행 높이 고정 + 위아래 빈 칸). 실제 창에서 인물 1,000명 문서의 표가 바로 열렸고 그려진 행은 27개였다.

## 알려진 한계

- 지금 열린 문서 한 개만 본다(작품 폴더 전체 표는 아직 없음).
- 표에서 값을 고쳐 문서에 되쓰는 기능은 없다(보기 전용).
- 속성 줄과 일반 문장이 헷갈리면 설명으로 처리한다(키가 12자를 넘거나 숫자로 시작하거나 `http://` 같은 주소면 속성이 아님).
- 칩은 한 번에 40개까지만 보여 주고 나머지는 "외 N개"로 줄인다(검색으로 거를 수 있다).

## 용어 설명 (초보자용)

- **파싱(parsing)**: 글자로 된 문서를 프로그램이 다루기 쉬운 항목(이름, 특기, 회차…)으로 나누어 읽는 것.
- **칩(chip)**: 누르면 켜지고 꺼지는 작은 알약 모양 단추. 여기서는 속성 값을 거르는 데 쓴다.
- **가상 스크롤(windowing)**: 수천 행이 있어도 화면에 보이는 행만 실제로 그려서 느려지지 않게 하는 방법.
- **소속**: 인물 제목 위에 있는 더 큰 제목(예: 1부, 서장)으로, 어느 묶음에 속한 인물인지 나타낸다.
