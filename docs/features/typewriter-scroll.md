# 타자기 스크롤 — 글 쓰는 줄을 화면의 고른 높이에 고정

## 한 줄 요약

편집창을 **세로로 5등분**해서, 글을 쓰는 줄(커서)이 **고른 구역의 한가운데**에 머물도록 편집창이 알아서 스크롤된다. 시선을 한 곳에 둔 채 글을 쓰게 하려는 기능이다. 창 맨 위 메뉴 **설정 > 타자기 스크롤**에서 구역을 고르며, **기본은 끔**이다.

## 구역

편집창 높이를 위에서부터 5등분한 구역이다. 커서 줄의 가운데가 그 구역의 한가운데에 온다.

| 설정 | 커서 줄의 높이 | 이런 때 |
|---|---|---|
| 끔 (기본) | 브라우저 기본 스크롤 | 평소와 같다 |
| 1 · 맨 위 | 편집창 높이의 10% | 아래를 넓게 보며 쓰고 싶을 때 |
| **2 · 위** | 30% | 시선을 눈높이 위쪽에 두고 싶을 때 |
| **3 · 가운데** | 50% | 화면 정면을 유지하며 쓰고 싶을 때 |
| 4 · 아래 | 70% | 앞 문장을 위에 많이 보며 쓰고 싶을 때 |
| 5 · 맨 아래 | 90% | 화면 아래에서 쓰는 것에 가깝다 |

## 언제 움직이나

- **글을 쓸 때**: 글자 입력, Enter, 지우기, 붙여넣기, 되돌리기(Ctrl+Z) 직후. 줄이 바뀔 때(Enter, 긴 줄이 접혀 다음 줄로 넘어갈 때)만 한 줄만큼 움직이고, 같은 줄에서 타이핑하는 동안은 가만히 있다.
- **커서를 옮길 때**: 방향키, Home·End, PageUp·PageDown. 키를 누르고 있어도 따라간다.
- **움직이지 않을 때**: 마우스로 글을 클릭하거나 휠·스크롤바로 스크롤할 때, 찾기·바꾸기·[편집] 점프처럼 앱이 직접 스크롤을 정하는 동작.

## 문서 맨 위·맨 아래

- **글 맨 위 근처**에서는 스크롤할 곳이 없어서(이미 맨 위) 커서가 선택한 구역보다 위에 있다. 쓰다 보면 구역에 도달한 뒤부터 고정된다.
- **글 맨 아래**에서는 편집창 아래쪽 여백([editor-scroll-past-end.md](editor-scroll-past-end.md))이 있어서 마지막 줄도 구역에 놓을 수 있다.

## 한계

- **아주 긴 글(30만 자 초과)에서는 동작하지 않는다.** 글을 쓸 때마다 커서 위치를 재는데 그 비용이 글 길이에 비례해서, 약 1만 자에 1ms, 8만 자에 12ms, 40만 자에 56ms 정도 든다(브라우저 미리보기에서 잰 값). 한도를 넘으면 브라우저 기본 스크롤로 돌아간다. 작업 폴더에서 가장 긴 문서는 약 1만 자다.
- **뷰어(오른쪽 렌더링 화면)는 따라 움직이지 않는다.** 듀얼 모드에서 편집창만 움직인다. 두 창의 스크롤을 맞추는 기능은 없다.
- 표 편집기 등 창(모달) 안에서는 해당 없다.

## 설정 저장

- 값은 이 PC 의 앱 설정 파일(`config.json`)에 `typewriterZone`(0 = 끔, 1~5 = 구역)으로 저장되어 다음 실행에도 유지된다. 메뉴에서 바꾸면 열려 있는 편집기에 바로 적용된다.
- 설정 파일의 값이 0~5 가 아니거나 망가져 있으면 끔으로 본다.
- 메뉴 구성은 [settings-menu.md](settings-menu.md).

## 관련 파일

| 파일 | 역할 |
|---|---|
| `src/lib/typewriterScroll.js` | 구역 -> 비율, 커서 줄이 그 구역에 오게 하는 스크롤 값 계산, 길이 한도, 커서를 옮기는 키 판별(순수 함수) |
| `shared/typewriterZone.js` | 설정값(0~5) 검증 — 메인과 화면이 함께 씀 |
| `src/components/EditorPane.jsx` | `recenterCaret`: 글을 쓸 때(onChange)와 방향키 등(keydown 다음 프레임)에 편집창을 스크롤 |
| `electron/settingsMenu.js`, `electron/main.js` | 메뉴 "설정 > 타자기 스크롤"(선택 항목 6개), 값 저장·알림 |
| `src/store/useAppStore.js` | `typewriterZone` 상태, `initSettings` 가 읽고 변경을 따라감 |
| `tests/lib/typewriterScroll.test.js`, `tests/electron/sortSetting.test.js` | 계산·검증·메뉴·스토어·연결 시험 |

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| 타자기 스크롤 | 타자기로 글을 칠 때 종이가 줄마다 올라가서 치는 자리가 늘 같은 높이인 것처럼, 글 쓰는 줄이 화면의 같은 높이에 머물게 하는 방식 |
| 구역 | 편집창을 위에서 아래로 5등분한 칸. 1 이 맨 위, 5 가 맨 아래 |
| 커서 줄 | 지금 글을 쓰고 있는(커서가 있는) 줄 |
| scrollTop | 편집창이 위에서 얼마나 내려와 있는지(px). 이 값을 바꿔서 글을 움직인다 |
| 선택 항목(radio) | 여러 개 중 하나만 고르는 메뉴 항목. 고르면 나머지는 체크가 풀린다 |
