# 돋보기 (마우스 휠 클릭)

## 한 줄 요약

**마우스 휠(가운데 버튼)을 한 번 누르면 마우스 위치를 중심으로 둥근 돋보기가 떠서 그 둘레를 키워 보여 주고, 한 번 더 누르면 꺼진다.** 돋보기가 켜진 동안 **휠을 굴리면 배율이 바뀌고**, 크기는 메뉴 **설정 > 돋보기 크기**에서 4단계로 고른다. 돋보기는 마우스 입력을 가로채지 않아서 **클릭·마우스 오버·드래그·입력이 그대로 동작**하고, 팝업·메뉴·창의 글자도 키워서 보인다.

## 쓰는 법

| 동작 | 결과 |
|---|---|
| 휠 클릭 | 켜짐. 마우스 자리가 돋보기의 한가운데가 된다 |
| 마우스 움직이기 | 돋보기가 마우스를 따라간다(마우스가 늘 중심) |
| 휠 위로 굴리기 | 확대(눈금 하나마다 1.2배) |
| 휠 아래로 굴리기 | 축소 |
| 휠 클릭 한 번 더 / `Esc` | 꺼짐 |
| 왼쪽 클릭·오른쪽 클릭·드래그·입력 | 평소처럼 진짜 화면에 들어간다 |

- 배율은 **1.5배 ~ 8배**이고 처음에는 2.5배다. 휠로 바꾼 배율은 돋보기를 껐다 켜도 이어진다(앱을 다시 켜면 처음 값).
- 돋보기가 켜진 **동안에는 휠이 문서를 스크롤하지 않고 배율만 바꾼다.** 문서를 스크롤하려면 돋보기를 끄고 한다.
- 휠 클릭에 원래 붙어 있는 윈도의 **자동 스크롤**(클릭하면 마우스를 움직여 끌려가는 것)과 링크의 **새 창 열기**는 막아 둔다.

## 크기 선택

메뉴 **설정 > 돋보기 크기**(하위 메뉴, 하나만 고르는 라디오)에서 둥근 돋보기의 지름을 고른다.

| 단계 | 지름 |
|---|---|
| 작게 | 160px |
| **보통(기본)** | 240px |
| 크게 | 340px |
| 아주 크게 | 460px |

- 고른 값은 이 PC 의 앱 설정 파일(`config.json`)의 `magnifierSize`(`small`·`normal`·`large`·`xlarge`)에 저장되어 **다음 실행에도 유지**된다. 값이 없거나 이상하면 보통으로 본다.
- 돋보기가 켜진 채로 크기를 바꾸면 바로 반영된다.

## 클릭·마우스 오버가 되는 이유

돋보기는 **마우스 입력을 받지 않는 그림층**이다(`pointer-events: none`). 마우스가 돋보기를 뚫고 아래의 진짜 화면에 닿는다. 그리고 돋보기의 확대 중심이 마우스 위치이므로, **돋보기 한가운데에 보이는 것이 곧 마우스 바로 아래의 진짜 요소**다. 그래서 따로 흉내 낼 필요 없이 클릭, 마우스 오버(툴팁 포함), 드래그가 진짜 화면에서 일어난다. 그 결과로 화면이 바뀌면(툴팁이 뜨거나 메뉴가 열리거나 글을 치면) 돋보기도 따라서 바뀐다.

## 만들어진 방식

1. 켜는 순간 앱 화면(`body` 안 전체)을 **복제**해 둥근 창 안에 넣고, 마우스 위치가 창 한가운데에 오도록 옮긴 뒤 CSS 로 키운다. 그림(스크린샷)이 아니라 요소 복제라서 **키워도 글자가 선명**하다.
2. 복제본은 **shadow DOM** 안에 둔다. 앱이 `document.querySelector` 로 요소를 찾을 때 복제본의 요소가 섞이지 않게 하려는 것이다.
3. 앱 화면이 바뀌거나(`MutationObserver`), 스크롤·입력이 있으면 한 프레임에 한 번씩 복제본을 다시 만든다. 복제로는 안 따라오는 **입력 칸의 현재 글, 스크롤 위치, 체크 상태**는 따로 채워 넣는다.
4. 마우스 아래 요소에 닿는 `:hover` 효과(버튼이 밝아지는 것 등)는 복제본에 닿지 않으므로, 앱의 CSS 에서 `:hover` 규칙을 찾아 "복제본용 표시 클래스" 규칙으로 바꿔 두고 마우스 아래 요소(와 조상)에 그 표시를 붙인다.

| 파일 | 역할 |
|---|---|
| `shared/magnifier.js` | 크기 4단계·지름, 배율 범위·휠 한 눈금 계산(`nextZoom`), 돋보기 위치·복제본 변환 — 메인과 화면이 함께 쓰는 순수 함수 |
| `src/lib/magnifierDom.js` | `:hover` 규칙 바꾸기, 마우스 아래 요소 표시, 입력값·스크롤 채우기, 복제 만들기 |
| `src/components/Magnifier.jsx` | 휠 클릭 켜기/끄기, 마우스·휠·`Esc` 처리, 복제본 갱신, 크기 설정 반영 |
| `electron/settingsMenu.js`, `electron/main.js`, `src/store/useAppStore.js`, `src/lib/mockApi.js` | 메뉴 "돋보기 크기" 와 값(`magnifierSize`) 저장·전달 |
| `src/App.css` (`.magnifier-host`) | 둥근 모양·테두리·그림자·마우스 입력 무시 |
| `tests/lib/magnifier.test.js`, `tests/lib/magnifierDom.test.js`, `tests/electron/magnifierSetting.test.js` | 계산·복제 규칙·설정·구조 시험 |

## 확인한 것 (실제 Electron 창, 실제 마우스 입력)

휠 클릭으로 켜면 한가운데가 마우스 자리와 일치(240px 돋보기) · 휠 위로 1번 2.5배에서 3배, 아래로 2번 2.08배 · 마우스를 사이드바 목록으로 옮기면 돋보기가 따라가며 그 목록 항목의 오버 색이 복제본에도 보임 · **돋보기가 켜진 채로 왼쪽 클릭해서 다른 문서가 열림** · 크기를 크게(340px)·작게(160px)로 바꾸면 켜진 돋보기에 바로 반영 · `Esc` 와 휠 클릭 한 번 더로 꺼짐 · 앱의 `document.querySelectorAll` 에 복제본이 섞이지 않음.

## 한계

- **앱 창 안의 화면만 키운다.** 운영체제가 그리는 것(창 맨 위 메뉴 막대, 파일 열기 창, 글자를 한글로 조합하는 중에 뜨는 변환창, 마우스를 올렸을 때 뜨는 기본 말풍선 `title`)은 키워지지 않는다.
- **돋보기가 마우스를 따라다녀서** 돋보기 가장자리에 보이는 요소를 곧바로 누를 수는 없다. 누르려는 요소를 돋보기 한가운데로 가져온 뒤 누른다(운영체제 화면 돋보기와 같은 방식).
- 복제본에는 **글자 선택(파란 하이라이트)과 깜빡이는 커서(캐럿)가 보이지 않는다.** 진짜 화면에는 있다.
- 복제본에서는 앱의 **포커스 테두리**(`:focus`)와 **누르는 중 효과**(`:active`)가 보이지 않고 마우스 오버(`:hover`)만 따라온다.
- 아주 긴 문서에서 글을 칠 때는 한 프레임마다 화면 복제를 다시 하므로 약간 느려질 수 있다.
- 휠로 **드래그한 영역을 돋보기로 보는 기능은 아직 없다**(2단계 계획).

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| 돋보기 | 화면의 한 곳을 둥근 창 안에서 크게 보여 주는 도구 |
| 휠 클릭 | 마우스 가운데 휠을 굴리지 않고 눌러 딸깍 하는 것 |
| 배율 | 몇 배로 키우는지. 2배면 가로세로 두 배 |
| 복제 | 화면을 그림으로 찍는 것이 아니라 화면 요소 전체를 똑같이 한 벌 더 만드는 것 |
| shadow DOM | 문서 안에 따로 격리된 작은 화면 영역. 바깥 문서의 검색에 안의 요소가 잡히지 않는다 |
| pointer-events: none | 마우스 클릭·이동을 받지 않고 그대로 아래로 통과시키는 설정 |
| 마우스 오버(hover) | 클릭하지 않고 마우스를 올려 두기만 한 상태 |
