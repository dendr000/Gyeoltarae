# 상용구 활성 폴더 · 닫으면 '전체'로 자동 복귀

> 갈피(Galpi)의 `galpi-bp-active-folder`(활성 폴더) 개념을 옮기고, 거기에 "닫으면 '전체'로 자동 복귀" 설정을 더한 것. 같은 기능을 갈피에도 넣었다.

## 한 줄 요약

상용구를 폴더로 나눠 정리해도, 정리가 끝나 모달을 닫으면 자동으로 '전체'로 돌아가서 모든 폴더의 상용구를 에디터에서 쓸 수 있다. 이 자동 복귀는 모달의 체크박스로 끌 수 있다.

## 동작

- **활성 폴더**: 상용구 모달 위쪽 폴더 선택에서 고른 폴더. 에디터의 자동 추천 팝업, 스페이스바 자동 치환, `Alt+Enter`는 **그 폴더 + '공통' 폴더**의 상용구만 쓴다. '전체'면 모든 폴더. 툴바 "상용구 삽입" 목록은 이 범위와 무관하게 항상 전체에서 고른다.
- **"닫으면 '전체'로 자동 복귀"** 체크박스(모달의 "스페이스바 자동 치환" 바로 옆, **기본 켜짐**):
  - 켜짐 — 모달을 어떤 방법으로 닫든(X, 바깥 클릭, "에디터에서 열기") 활성 폴더가 '전체'가 된다.
  - 꺼짐 — 고른 폴더가 닫은 뒤에도, 앱을 다시 켠 뒤에도 유지된다. 한 폴더의 상용구만 집중해서 쓰고 싶을 때.
- 폴더 범위가 남아 있을 때는 사이드바 "상용구" 제목이 `상용구 · 무협 폴더만 사용 중`으로 바뀐다. 다른 폴더의 단축어가 안 먹히는 이유를 바로 알 수 있게 하려는 것이다.

기본(켜짐)에서는 모달이 열려 있는 동안에만 폴더 범위가 의미가 있고(그동안은 에디터를 쓸 수 없다) 닫으면 바로 '전체'로 돌아가므로, 예전과 쓰는 느낌이 같다.

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| **활성 폴더** | 지금 에디터가 쓰는 상용구 폴더 범위. 모달에서 고른 폴더가 곧 활성 폴더다. |
| **'공통' 폴더** | 어느 폴더를 활성으로 골라도 항상 같이 쓰이는 폴더. 폴더를 '전체'로 두고 등록하면 여기에 저장된다. |
| **자동 복귀** | 모달을 닫는 순간 활성 폴더를 '전체'로 되돌리는 동작. |

## 구현 위치

- `src/lib/snippetScope.js` — 범위 규칙 순수 함수(`selectActiveSnippets`, `nextFolderAfterClose`).
- `src/store/useAppStore.js` — `activeSnippetFolder`, `snippetResetFolderOnClose`, `setActiveSnippetFolder`, `setSnippetResetFolderOnClose`, 그리고 닫을 때 복귀하는 `closeSnippetModal`. 저장 키는 `wikidesk-snippet-active-folder`, `wikidesk-snippet-reset-folder-on-close`.
- `src/components/SnippetModal.jsx` — 폴더 선택을 스토어에 연결, 체크박스.
- `src/components/EditorPane.jsx` — 활성 범위의 상용구만 감지에 사용.
- `src/components/SnippetSidebar.jsx` — 범위 표시.
- 테스트: `tests/lib/snippetScope.test.js`, `tests/store/modals.test.js`.

## 갈피와 같은 점 / 다른 점

- 같음: 활성 폴더 = 선택한 폴더 + '공통', '전체'면 전부. 모달을 열 때 기본값은 '전체'.
- 다름: 갈피는 활성 폴더가 닫은 뒤에도 항상 남고(그래서 '전체'로 되돌리는 걸 잊으면 상용구가 안 먹혔다), 결타래/갈피 둘 다 이제 이 자동 복귀를 설정으로 선택할 수 있다.
