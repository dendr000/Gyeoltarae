# 툴바 위에서 휠로 좌우 스크롤

## 한 줄 요약

편집 툴바(제목·목록·굵게 … 버튼 줄)는 한 줄이라 창이 좁으면 버튼이 잘린다. 이제 **툴바 위에 마우스를 두고 휠을 굴리면 좌우로 스크롤**된다. 스크롤바를 잡을 필요가 없다.

## 동작

- 휠을 **아래로** 굴리면 오른쪽으로, **위로** 굴리면 왼쪽으로 스크롤된다. (실제 휠 3칸에 300px, 즉 한 칸에 100px)
- 맨 왼쪽·맨 오른쪽 끝에서는 더 가지 않는다.
- **끝까지 갔는데 같은 방향으로 더 굴리면** 아무것도 가로채지 않는다(브라우저 기본 동작에 맡김).
- 툴바가 **넘치지 않을 만큼 넓으면**(스크롤할 게 없음) 휠을 건드리지 않는다.
- **트랙패드 등으로 가로로 굴린 입력**과 **Ctrl+휠(확대·축소)** 은 건드리지 않는다.
- 줄 단위·페이지 단위로 보내는 휠(`deltaMode` 1·2)도 한 줄 16px, 한 페이지 = 보이는 너비로 환산해서 처리한다.
- 편집창이 비활성(문서를 안 연 상태)이라 툴바가 없으면 아무 일도 없다.

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| **휠(wheel)** | 마우스의 가운데 굴리는 바퀴. 보통 위아래 스크롤에 쓴다. |
| **스크롤바** | 창 가장자리의 막대. 끌어서 화면을 옮긴다. |
| **패시브 리스너** | "이 입력은 기본 동작을 막지 않겠다"고 미리 약속한 이벤트 처리기. 휠을 가로채려면 이 약속을 하지 않아야 해서 직접 이벤트를 붙였다. |

## 구현 위치

- `src/lib/horizontalWheel.js` — 새 스크롤 위치 계산(`wheelScrollLeft`).
- `src/components/useHorizontalWheelScroll.js` — 툴바에 휠 이벤트를 붙이는 훅(React 의 `onWheel` 은 패시브라 `preventDefault` 가 안 먹어서 `addEventListener(..., { passive: false })` 로 붙임). `src/components/EditorPane.jsx` 가 툴바에 연결.
- 테스트: `tests/lib/horizontalWheel.test.js`. 화면 동작은 실제 마우스 휠로 확인했다(아래로 3칸 → 300px, 위로 → 끝에서 멈춤).

## 알려진 한계

- 다른 가로 스크롤 줄(표 편집기 안 등)에는 적용하지 않았다. 편집 툴바만 해당한다.
