# 표 편집기 창 — 도움말, 적용 단추, 닫기, 글자 서식 단축키, 행·열 추가, 칸 오가기

## 한 줄 요약

표 편집기 창의 **맨 위 오른쪽**에 `도움말` · `적용` · `✕` 가 있고, 이 줄은 아래로 스크롤해도 **따라와서** 행이 아무리 많아져도 `적용`을 바로 누를 수 있다. 표 위에 작은 글씨로 적혀 있던 안내는 **도움말 팝업**으로 옮겼다. `취소` 단추는 없앴고, 창 **바깥은 빠르게 두 번 클릭**해야 닫힌다. 칸 안에서 **Ctrl+B(굵게)·Ctrl+U(밑줄)** 가 된다.

## 맨 위 오른쪽 줄

| 단추 | 하는 일 |
|---|---|
| `도움말` | **마우스를 올리면** 도움말 팝업이 보이고, **누르면 고정**된다(고정한 팝업은 바깥을 누르면 닫힌다). 팝업으로 마우스를 옮겨도 닫히지 않는다 |
| `적용` | 표를 문서에 넣고 창을 닫는다. 예전에는 창 맨 아래에 있어서 행이 많으면 한참 내려가야 했다 |
| `✕` | **적용하지 않고** 닫는다 |

- 이 줄은 `position: sticky` 로 창의 맨 위에 고정된다. 행을 40개 늘려 맨 아래까지 내려가도 `적용`이 같은 자리에서 눌린다.
- 아래쪽의 `취소` 단추와 `적용` 단추 줄은 없어졌다. 닫기만 하려면 `✕` 나 바깥 두 번 클릭을 쓴다.

## 행·열 추가·삭제 단추의 자리와 위치 고정

| 단추 | 자리 |
|---|---|
| `+ 행 추가` | 표의 **마지막 행 바로 아래** (가로로 긴 점선 단추) |
| `+` (열 추가) | **열 글자 줄(A, B, …)의 오른쪽 끝** |
| `−` (행 삭제) | 각 행의 오른쪽 끝 |
| `−` (열 삭제) | 표 맨 아래 줄의 각 열 아래 |

- 예전에는 행·열 추가가 표 아래에 같이 있었다. 행을 하나 추가하면 표가 길어져 단추만 아래로 내려가고 마우스는 그대로라서, 여러 행을 늘리려면 계속 마우스를 옮겨야 했다.
- 지금은 단추를 누르면 **누른 단추가 같은 화면 자리에 남도록 창을 자동으로 스크롤**한다(`useKeepPosition`). 그래서 같은 자리를 계속 눌러 행을 여러 개 추가할 수 있다. 행 삭제도 같다(지운 자리에 올라오는 아래 행의 `−` 가 그 자리에 온다).
- 한계: 내용이 창에 다 들어가서 스크롤할 여지가 없을 때는 보정할 수 없다. 열 추가는 표가 창 너비를 넘기 전(처음 서너 번)에는 단추가 오른쪽으로 밀린다(넘은 뒤에는 가로 스크롤을 맞춰 제자리에 남는다). 맨 끝까지 스크롤된 상태에서 마지막 행·열을 지우면 표가 줄어드는 만큼 보정하지 못할 수 있다.

## 칸 <-> "선택한 셀 내용" 오가기 (F2, Ctrl+Enter)

- 칸을 하나만 골랐을 때 표 위쪽에 **"선택한 셀 내용" 큰 입력칸**이 나타난다(긴 글을 편집하기 편하다).
- 칸에서 **F2**(또는 **Ctrl+Enter**)를 누르면 커서가 큰 입력칸 맨 뒤로 가고, 한 번 더 누르면 **원래 칸**(F2 를 처음 누른 칸)으로 돌아온다. 마우스로 일일이 누를 필요가 없다.
- 여러 칸을 골라서 큰 입력칸이 없을 때는 아무 일도 없다. 찾기 바·서식 패널 안, 한글 조합 중에는 가로채지 않는다.
- Enter(아래 칸 이동)·Shift+Enter(칸 안 줄바꿈)와 키가 겹치지 않는다. 규칙은 `src/lib/tableJump.js`(순수 함수)다.

## 도움말 팝업

- 글씨는 14px(제목 15px)이고 **주제별 8개**로 나뉜다: 칸 고르기 / 스타일과 병합 / 글자 서식 단축키 / 복사·붙여넣기·채우기 / 찾기·되돌리기 / 칸 안에서 이동·입력 / 툴바 읽는 법 / 적용하고 닫기.
- 키는 작은 상자(`Ctrl+B` 모양)로 따로 보이고 그 옆에 한 줄 설명이 붙는다. 한 항목은 160자 이하다.
- 내용은 `src/lib/tableEditorHelp.js` 한 곳에 있다. 기능을 추가하면 여기에 항목을 더하면 된다(시험이 모양을 점검한다).
- 도구 단추에 마우스를 올리면 나오는 짧은 설명(`title`)과 꺼져 있을 때의 이유는 그대로다.

## 창 닫기

- **바깥(어두운 배경)을 한 번 클릭**해서는 닫히지 않는다. **빠르게 두 번 클릭(더블클릭)** 해야 닫히고, 닫으면 **적용하지 않는다.** 한 번 클릭으로 닫히면 작업 중이던 표가 실수로 날아가기 때문이다.
- **창 안쪽에서의 더블클릭**(칸의 글자를 더블클릭해 고르는 등)은 닫히지 않는다 — 배경 자체를 눌렀을 때만 닫는다.
- 다른 창(새 문서 이름 입력, 분류·상용구 창 등)은 예전과 같다(바깥 한 번 클릭으로 닫힘). 표 편집기만 바뀌었다.

## 글자 서식 단축키 (Ctrl+B, Ctrl+U)

문서 편집기와 같은 키다. 칸의 입력칸과 아래 "선택한 셀 내용" 큰 입력칸 모두에서 된다. 한글 자판이어도 된다(물리 키 위치도 본다).

| 상황 | Ctrl+B (굵게) | Ctrl+U (밑줄) |
|---|---|---|
| 글자를 골랐다 | 그 글자만 `'''글자'''` 로 감싼다. 이미 감싸져 있으면 벗긴다 | 그 글자만 `__글자__` 로 감싼다. 이미 감싸져 있으면 벗긴다 |
| 글자를 고르지 않았다 | **선택한 칸(범위) 전체를 굵게** 한다(툴바의 굵게 단추와 같음) | 표시 한 쌍(`____`)을 넣고 그 사이에 커서를 둔다 |
| 입력칸이 아니다(표 단추 위 등) | 선택 범위 전체 굵게 | 아무 일도 없다 |

- **씌운 뒤에도 그 글자가 계속 선택**되어 있어서 바로 한 번 더 누르면 벗겨진다.
- **되돌리기(Ctrl+Z)** 는 표 편집기의 되돌리기로 한 번에 돌아온다.
- 칸 전체 굵게는 표 문법으로 저장될 때 `'''칸 내용'''` 이 된다. 첫 행을 헤더로 쓰는 표의 맨 윗줄은 이미 굵게라서 눈에 띄는 변화는 없다.
- 찾기 바·서식 패널 안의 입력칸에서는 이 단축키를 가로채지 않는다.

## 확인한 것 (실제 Electron 창, 실제 마우스·키 입력)

행 추가 단추를 같은 좌표에서 12번 눌러 12번 모두 그 단추를 눌렀다(2행 → 14행) · 행 `−` 를 같은 좌표에서 5번 눌러 5번 모두 행 삭제 단추였다 · 열 추가는 표가 창 너비를 넘긴 뒤 같은 자리에 남음 · F2 와 Ctrl+Enter 로 3행 2열 칸 → 큰 입력칸 → 같은 칸 왕복(글자 보존), 다른 칸에서도 왕복, 여러 칸 선택 때는 아무 일 없음.

앞선 확인(0.113.0):

도움말 팝업(올리면 열리고, 팝업으로 옮겨도 유지, 치우면 닫힘, 글씨 14px, 창 안에 들어옴) · 바깥 한 번 클릭(유지) · 칸 안 더블클릭(유지) · 바깥 두 번 클릭(닫힘) · 행 40개 늘려 맨 아래로 스크롤해도 `적용` 클릭 가능 · Ctrl+B/Ctrl+U 로 씌우기·벗기기와 선택 유지 · 고르지 않은 Ctrl+B 의 칸 굵게 · `적용`으로 문서에 표가 들어감.

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| 위치 고정(keep position) | 단추를 눌러 내용이 늘거나 줄어도 그 단추가 화면의 같은 자리에 남도록 스크롤을 맞추는 것 |
| 모달 | 화면 위에 떠서 닫기 전에는 뒤를 쓸 수 없는 창. 표 편집기가 이렇게 뜬다 |
| 고정 헤더(sticky) | 스크롤해도 창 맨 위에 붙어 있는 줄 |
| 더블클릭 | 같은 곳을 빠르게 두 번 누르는 것 |
| 도움말 팝업 | 단추에 마우스를 올리면 그 자리에 떠서 보이는 설명 상자 |
| `'''글자'''` / `__글자__` | 문서 문법에서 굵게 / 밑줄을 뜻하는 표시 |
