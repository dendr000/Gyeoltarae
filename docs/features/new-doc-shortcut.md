# Ctrl+N 으로 새 문서 만들기

## 한 줄 요약

**Ctrl+N** 을 누르면 **지금 열려 있는 문서가 있는 폴더**에 새 문서를 만드는 창이 뜬다. 사이드바에서 그 폴더를 찾아 스크롤해 올려 "새 문서" 단추를 누르는 것과 같은 일이다.

## 쓰는 법

1. 사이드바에서 `03 멘토씨리즈 C언어(개정판)` 같은 폴더 안의 아무 문서나 연다(눌러서 열린 상태).
2. **Ctrl+N** 을 누른다.
3. "새 문서" 창이 뜬다(문서 이름, 글양식(틀) 고르기 — 폴더의 기본 틀이 있으면 그 틀이 "자동"이다). 이름을 쓰고 Enter(또는 확인)를 누르면 **그 폴더 안에** 문서가 만들어지고 바로 열린다.

| 상황 | 새 문서가 만들어지는 곳 |
|---|---|
| 폴더 안의 문서가 열려 있다 | **그 문서가 있는 폴더** |
| 작업 폴더 바로 아래의 문서가 열려 있다 | 작업 폴더 |
| 열린 문서가 없다 | 작업 폴더(맨 아래 "+ 새 문서" 단추와 같음) |

- 폴더별 "새 문서" 단추·폴더 우클릭 "새 문서"와 **같은 창·같은 규칙**이다(전국도감 번호 칸, 폴더 기본 틀, 자동 분류 등 폴더별 설정이 그대로 적용됨).
- 편집 중에도(글 입력칸에 커서가 있어도) 동작한다. 한글을 입력하는 중(조합 중)에는 반응하지 않는다.
- **이름 입력창 등 다른 창이 떠 있으면 무시한다**(창이 겹쳐 뜨거나 작업 중이던 창에 영향을 주지 않게). Shift·Alt 가 같이 눌린 Ctrl+N 은 해당하지 않는다.
- 한글 자판 상태에서도 된다(물리 키 위치 N 을 본다).

## 구조

- 키 판별과 폴더 결정은 `src/lib/newDocShortcut.js` 의 순수 함수 `isNewDocKey`, `newDocTargetDir` 다(시험: `tests/lib/newDocShortcut.test.js`).
- `src/App.jsx` 의 전역 키 처리가 Ctrl+N 이면 사이드바 단추와 같은 `handleCreateDoc` 를 부른다. 키 처리는 한 번만 등록하고, 항상 최신 함수를 부르도록 ref 에 넣어 둔다.
- 경로 구분자는 `\` 와 `/` 둘 다 받는다(윈도 경로).

## 확인한 것 (실제 Electron 창, 실제 키 입력)

- 열린 문서가 없을 때 Ctrl+N -> 이름 입력창이 뜨고 작업 폴더에 문서가 만들어짐.
- `강의/03 폴더/기존문서` 를 연 채 Ctrl+N -> `03 폴더` 안에 문서가 만들어지고 작업 폴더에는 만들어지지 않음.
- 이름 입력창이 떠 있을 때 Ctrl+N -> 창이 겹쳐 뜨지 않음(1개 그대로).

## 한계

- 열려 있는 문서가 **틀·자료·분류 같은 특수 폴더의 문서**이면 그 폴더에 만들려고 한다(폴더별 "새 문서" 단추를 그 폴더에서 누른 것과 같다). 일반 문서 폴더에서 쓰는 것을 전제로 했다.
- 폴더를 열기만 하고 문서를 열지 않은 상태(사이드바에서 폴더만 펼친 상태)는 "열린 문서가 없음"과 같게 작업 폴더에 만든다.

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| 작업 폴더 | 결타래가 문서를 모아 두는 맨 위 폴더(처음에 고른 폴더) |
| 글양식(틀) | 새 문서에 미리 채워 넣을 기본 내용 |
| 조합 중 | 한글을 쓸 때 글자가 아직 확정되지 않은 상태 |
