# 사전 등록 규칙: 한자/영문 칸에는 한글을 쓸 수 없다

## 한 줄 요약

사전(한자 등록) 창의 **원문**에는 한글, **한자/영문**에는 한자나 영문을 적는다. 한자/영문 칸에 한글이 들어가면 등록되지 않는다.

## 동작

| 입력 | 결과 |
|---|---|
| 원문 `동방`, 한자/영문 `東方` | 등록 |
| 원문 `東方`, 한자/영문 `동방` | 순서를 바로잡아 `동방(東方)` 으로 등록 |
| 원문 `중`, 한자/영문 `중` | 등록 안 됨. 창에 "한자/영문 칸에는 한글을 쓸 수 없습니다" 안내가 뜸 |
| 일괄 등록의 `중(중)` 줄 | 그 줄만 건너뛰고 나머지는 등록. 결과에 "한글이 있는 줄은 등록되지 않습니다" 안내 |

- 이유: 한글끼리 등록하면 한자 검색에도 안 잡히고 Alt+H 순환 치환도 엉뚱해진다.
- 이미 사전에 있는 항목은 바꾸지 않는다(`용양위(龍양衛)` 처럼 일부러 한글이 섞인 것도 있다). 새로 등록할 때만 막는다.

## 구조

`src/lib/dictEntry.js`(규칙) -> `useAppStore.js` 의 일괄 등록(단일 등록도 같은 함수)과 `DictModal.jsx`(안내). 시험: `tests/lib/dictEntry.test.js`.

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| 한자 등록 | 한글 낱말과 그 한자를 짝으로 사전에 저장하는 기능(Alt+Shift+H) |
| 일괄 등록 | `동방(東方)` 같은 줄을 여러 개 붙여 넣어 한 번에 등록하는 기능 |
