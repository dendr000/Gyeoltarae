# 설정 메뉴 — 정렬 뒤집기, 타자기 스크롤

## 한 줄 요약

창 맨 위 메뉴(파일·편집·보기·**설정**·창)의 **설정**에서 편집기의 동작을 고른다. 항목은 둘이다: ① 정렬 단축키의 "다시 누르면 뒤집기", ② "타자기 스크롤"([typewriter-scroll.md](typewriter-scroll.md)). 아래는 ①의 설명이다. 기본은 **항상 오름차순**이고, 항목을 켜면 **이미 오름차순일 때 다시 눌러 내림차순으로 뒤집을 수 있다**(오름차순/내림차순 둘 다 가능).

## 메뉴 항목

| 위치 | 항목 | 기본 |
|---|---|---|
| 설정 | **정렬 단축키: 다시 누르면 오름차순 <-> 내림차순 뒤집기** (체크 표시 항목) | 꺼짐 |
| 설정 | **타자기 스크롤** (하위 메뉴, 선택 항목 6개: 끔 / 구역 1 맨 위쪽 / 구역 2 위쪽 / 구역 3 가운데 / 구역 4 아래쪽 / 구역 5 맨 아래쪽) | 끔 |

적용 대상은 두 단축키 모두다.

| 단축키 | 기능 | 문서 |
|---|---|---|
| Ctrl+` | 선택한 줄을 이름순으로 정렬 | [line-sort.md](line-sort.md) |
| Ctrl+Shift+` | 선택한 줄을 묶음 단위로 이름순 정렬 | [block-sort.md](block-sort.md) |

## 동작 비교

예: `* 자` / `* 가` / `* 마` 를 선택하고 정렬 단축키를 누른다.

| 누른 횟수 | 설정 꺼짐 (기본) | 설정 켜짐 |
|---|---|---|
| 1번 | `* 가` `* 마` `* 자` (오름차순) | `* 가` `* 마` `* 자` (오름차순) |
| 2번 | 그대로 (이미 오름차순이라 바뀌는 것이 없다) | `* 자` `* 마` `* 가` (내림차순) |
| 3번 | 그대로 | `* 가` `* 마` `* 자` (다시 오름차순) |

- **설정이 꺼져 있으면** 어떤 상태의 글에서 눌러도 결과는 항상 오름차순이다. 내림차순으로 놓인 글을 누르면 오름차순이 되고, 이미 오름차순이면 아무 변화도 없다.
- **설정이 켜져 있으면** 정렬되어 있지 않은 글은 먼저 오름차순이 되고, 이미 오름차순인 글에서는 내림차순으로 뒤집힌다. 손으로 먼저 가나다 순으로 적어 둔 글에서 눌러도 뒤집히니 주의한다.

## 저장과 반영

- 값은 이 PC 의 앱 설정 파일(`config.json`, 마지막으로 연 작업 폴더가 저장되는 같은 파일)에 정렬 뒤집기는 `sortFlip`, 타자기 스크롤은 `typewriterZone`(0 = 끔, 1~5 = 구역)으로 저장되어 **다음 실행에도 유지**된다.
- 메뉴에서 바꾸면 열려 있는 편집기에 **바로 적용**된다(앱을 다시 켤 필요 없음).
- 브라우저 미리보기(개발 중 화면)처럼 메뉴가 없는 환경은 항상 기본(꺼짐)이다.

## 관련 파일

| 파일 | 역할 |
|---|---|
| `electron/settingsMenu.js` | "설정" 메뉴(체크 항목) 정의 — 값 읽기·저장은 호출한 쪽에 맡겨서 Electron 없이 시험한다 |
| `electron/main.js` | 메뉴에 "설정" 추가, 값을 `config.json` 에 저장(`readSettings` 로 모양을 바로잡아 읽음), 화면에 `settings:changed` 알림(전체 설정), `settings:get` 응답 |
| `shared/typewriterZone.js` | 타자기 구역 값(0~5) 검증 — 메인과 화면이 함께 씀 |
| `electron/preload.cjs` | 화면에 `getSettings` / `onSettingsChanged` 노출 |
| `src/store/useAppStore.js` | `sortFlip` 상태와 `initSettings`(시작할 때 읽고 변경 알림을 구독) |
| `src/lib/lineSort.js`, `src/lib/blockSort.js` | `{ flip }` 옵션 — 꺼지면 오름차순만, 켜지면 이미 오름차순일 때 내림차순 |
| `src/components/EditorPane.jsx` | 두 단축키에 설정값(`flip`)을 넘김 |
| `tests/electron/sortSetting.test.js` | 메뉴 항목(정렬 뒤집기·타자기 구역 선택), 스토어, 연결 소스 점검 |

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| 오름차순 / 내림차순 | 작은 것부터(가나다·ABC·1 2 3) / 큰 것부터 |
| 체크 항목 | 눌러서 켜고 끄는 메뉴 항목. 켜져 있으면 왼쪽에 체크 표시가 보인다 |
| 뒤집기 | 이미 오름차순인 글을 내림차순으로 바꾸는 것 |
| config.json | 앱이 이 PC 에 저장하는 설정 파일. 사용자 폴더(`AppData`) 아래 앱 이름 폴더에 있다 |
