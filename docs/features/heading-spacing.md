# 큰 제목(1., 2., 3. …) 앞 간격

## 한 줄 요약

뷰어에서 큰 제목(`= 제목 =`, 번호 1. 2. 3. …) 앞의 간격을 넓혀서, 다음 큰 문단으로 넘어갔다는 느낌이 나게 했다.

## 바뀐 것

| | 예전 | 지금 |
|---|---|---|
| 큰 제목(h1) 앞 간격 | 20px | **52px** |
| 문서 맨 처음의 큰 제목 | 20px | 20px (그대로) |
| 작은 제목(`== 제목 ==` 등) 앞 간격 | 20px | 20px (그대로) |

- 바로 앞이 작은 제목(예: `1.4. 복합 정렬`)이어도, 문단이어도 큰 제목 앞은 52px 벌어진다. 작은 제목에서 큰 제목으로 넘어가는 경우도 포함한다.
- 실제 화면에서 측정했다(큰 제목 앞 간격 52px, 첫 큰 제목 20px, 작은 제목 20px).

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| **큰 제목(h1)** | `= 제목 =` 처럼 `=` 한 쌍으로 쓰는 가장 큰 제목. 번호는 1. 2. 3. 순서로 붙는다. |
| **작은 제목(h2~h6)** | `== 제목 ==` 처럼 `=` 를 더 많이 쓰는 제목. 번호는 1.1. 1.2. 처럼 붙는다. |
| **마진(margin)** | 요소 바깥의 여백. 앞 요소와의 거리를 만든다. |

## 구현 위치

- `src/App.css` — `.wiki-rendered h1` 의 `margin-top: 52px`, `.wiki-rendered > h1:first-child` 는 20px.

## 알려진 한계

- 에디터(왼쪽 편집창)의 줄 간격은 바뀌지 않았다. 뷰어(렌더링 화면)만 해당한다.
- 간격 값(52px)이 마음에 안 들면 위 CSS 한 줄만 바꾸면 된다.
