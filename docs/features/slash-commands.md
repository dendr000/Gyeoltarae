# 슬래시 명령 (`/접기`, `/목차`, `/표` …)

## 한 줄 요약

글(문단)에서 `/` 를 치고 이름을 고르면 위키 문법이 들어가고 커서가 알맞은 자리에 선다. `/접기` → 접기 블록(제목 칸에 커서, **Tab** 을 누르면 내용 칸), `/목차` → `[목차]` + `[clearfix]`, `/표` → 툴바 "표" 버튼처럼 **표 편집기**가 열린다. 명령은 상용구 폴더 `명령` 에 들어 있어서 직접 추가·수정할 수 있다.

## 쓰는 법

| 입력 | 결과 |
|---|---|
| `/접` 까지 치고 **Tab** | `{{{#!folding ▌` / `▌` / `}}}` — 커서는 첫 ▌(제목 칸). 제목을 치고 **Tab** → 내용 칸 |
| `/목차` + Tab | `[목차]` 와 `[clearfix]` 두 줄 |
| `/표` + Tab | 친 `/표` 는 지워지고 표 편집기가 열린다(툴바 "표 삽입/편집"과 같은 창) |
| `/글자색` + Tab | `{{{#▌ ▌}}}` — 색 코드를 치고 Tab → 글자 |
| `/` 만 치기 | 줄 맨 앞이면 전체 명령 목록이 뜬다 |

- **추천 팝업 설정이 꺼져 있어도** `/` 를 칠 때는 명령 목록만 뜬다(툴바 "추천 팝업" 버튼과 무관). 켜져 있으면 다른 상용구와 같이 뜬다.
- 후보 확정: **Tab** 또는 Enter(방향키로 고르기). 이름을 다 치고 스페이스를 눌러도 펼쳐지고(스페이스바 자동 치환이 켜져 있을 때), **Alt+Enter** 로도 펼친다.
- **Tab 으로 건너뛰는 자리**는 글을 치면 위치가 같이 밀리므로, 제목을 길게 써도 Tab 이 정확히 내용 칸으로 간다. 갈 자리가 없으면 Tab 은 평소처럼 들여쓰기다. 문서를 바꾸면 남은 자리는 사라진다.

## 들어 있는 명령 (폴더 `명령`, 55개)

| 묶음 | 명령 |
|---|---|
| 블록 | `/접기` `/목차` `/목차만` `/clearfix` `/구분선` `/코드` `/코드언어` `/문법` `/인용` `/목록` `/번호목록` `/박스` `/스타일` `/조건` `/코멘트` |
| 제목 | `/제목1` ~ `/제목6` |
| 글자 모양 | `/굵게` `/기울임` `/밑줄` `/취소선` `/위첨자` `/아래첨자` `/글자색` `/글자크기` `/각주` `/줄바꿈` |
| 링크·불러오기 | `/링크` `/링크표시` `/앵커` `/태그` `/틀호출` `/include` `/문서수` `/행`(표의 한 행) |
| 창 열기(동작) | `/표` `/그라데이션` `/이미지` `/자료` `/틀` `/분류` `/별칭` — 툴바의 같은 이름 버튼과 같은 창을 연다 |
| 언어 코드블록 | `/sql` `/mysql` `/java` `/python` `/cpp` `/js` `/html` `/css` `/bash` — 언어 이름이 적힌 코드블록 |

문법은 README 의 "문법" 표를 따른다. 전체 목록과 본문은 `scripts/snippet-packs/commands.js` 또는 앱의 상용구 모달(폴더 `명령`).

## 설치

```bash
node scripts/install-snippet-pack.mjs commands --dry-run     # 미리보기
node scripts/install-snippet-pack.mjs commands               # 설치 (폴더 이름: 명령)
node scripts/install-snippet-pack.mjs commands --workspace D:\WikiDesk
```

이미 있는 상용구는 덮어쓰지 않는다(`snippet-packs.md` 와 같은 규칙). `/` 가 든 제목은 파일 이름에 못 쓰는 글자라서 앱이 `%2F` 로 바꿔 저장한다(앱에서는 `/접기` 로 보인다).

## 내 명령 만들기

상용구 모달에서 **단축어를 `/` 로 시작**하게 등록하면 된다(예: 단축어 `/주의`, 본문 `{{{#!wiki style="border:1px solid red"` ...). 본문에 쓰는 표시:

| 표시 | 뜻 |
|---|---|
| `{#}` | 커서 자리. **첫 번째**는 펼친 직후 커서가 서는 자리, **두 번째부터**는 Tab 으로 차례로 건너뛰는 자리다. |
| `{!이름}` | 본문이 이것 하나뿐이면 글자를 넣지 않고 동작을 연다. 이름: `표` `그라데이션` `이미지` `자료` `틀` `분류` `별칭`. 모르는 이름이면 글자 그대로 들어간다. |

기존 상용구의 본문에 `{#}` 가 두 번 이상 있으면 예전에는 두 번째가 글자로 남았지만 이제는 Tab 자리가 된다.

## 규칙과 한계

- **단어 시작에서만**: 줄 맨 앞이나 공백 뒤의 `/` 만 명령이다. `a/접기`, 주소(`http://…/접기`) 속 슬래시는 명령이 아니다. 글 중간의 ` / ` 만으로는 목록이 뜨지 않는다(줄 맨 앞의 `/` 만 전체 목록).
- **코드블록 안에서는 쓰이지 않는다.** 코드의 `//` 주석을 칠 때마다 명령 목록이 뜨면 안 되기 때문이다. 코드블록 안의 언어 상용구는 `snippet-language-packs.md`.
- 명령은 위키 문법을 넣을 뿐 **뷰어가 해석하는 것은 아니다**. 예를 들어 `/조건`(`{{{#!if}}}`)은 틀 문서 안에서만 의미가 있다(README 문법 표).
- 실행하는 동작은 위 7가지뿐이다. 다른 툴바 기능(글자색 선택기 등)을 열고 싶으면 요청해 달라.
- 표 편집기가 열린 동안 `/표` 로 지워진 글자는 되돌려지지 않는다(취소해도 `/표` 는 없는 상태). 되돌리려면 Ctrl+Z.

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| **슬래시 명령** | `/` 로 시작하는 이름을 쳐서 불러 쓰는 명령(노션·슬랙에서 쓰는 방식) |
| **상용구** | 짧은 이름(단축어)을 치면 정해 둔 글로 바꿔 주는 기능 |
| **Tab 자리** | 글을 펼친 뒤 Tab 으로 차례로 이동하는 빈칸 위치 |
| **동작 명령** | 글자를 넣는 대신 창(표 편집기 등)을 여는 명령 |

## 구현 위치

- `scripts/snippet-packs/commands.js` — 명령 55개(`COMMANDS_PACK`), `scripts/install-snippet-pack.mjs` 의 `commands`.
- `src/lib/snippetExpansion.js` — 본문 해석(`parseSnippetContent`: `{#}`·`{!이름}`), Tab 자리 이동(`nextStop`, `shiftStops`).
- `src/lib/snippetLanguage.js`(`isSlashCommand`, 코드블록에서 제외), `src/lib/snippetMatch.js`(`/` 는 단어 시작에서만 찾기).
- `src/components/EditorPane.jsx` — 펼치기(`commitSnippetExpansion`), Tab 자리 따라가기(`trackSnippetStops`), 동작 연결(`snippetActionsRef`), 추천 팝업이 꺼져 있어도 `/` 명령은 띄우기(`updateSnippetSuggest`).
- 테스트: `tests/lib/snippetExpansion.test.js`, `tests/lib/snippetLanguage.test.js`(슬래시 규칙), `tests/scripts/commandsPack.test.js`.
