# 표 편집기의 서식 도구 — 숫자 서식 · 조건부 색 · 열 너비 · 줄무늬

## 한 줄 요약

표 편집기의 **셋째 줄 툴바("서식")** 에서 네 가지 도구를 쓴다. 단추를 누르면 아래에 입력 줄(패널)이 열리고, 한 번에 하나만 열린다.

| 도구 | 하는 일 | 문서에 남는 것 |
|---|---|---|
| **숫자 서식** | 숫자 칸의 천 단위 쉼표, 소수 자릿수, 앞 기호(₩ $ …), 뒤 글자(% 원 …)를 바꾼다 | 바뀐 **글자**(`₩1,234,567.00`) |
| **조건부 색** | "0보다 작으면 빨강" 같은 조건에 맞는 칸을 한꺼번에 칠한다 | 칸의 **배경색·글자색·굵게** |
| **열 너비** | 고른 열의 너비를 px 이나 %로 정한다 | 칸의 `<width=120px>` **속성** |
| **줄무늬** | 행을 한 줄 걸러 배경색으로 칠한다 | 칸의 **배경색** |

네 도구 모두 **한 번 적용하는 도구**다. 엑셀의 서식처럼 값이 바뀌었을 때 자동으로 다시 맞춰지지 않는다. 값을 고친 뒤에는 다시 적용한다.

## 적용 범위

- **여러 칸을 골라 두었으면 그 범위**, 한 칸만 골랐으면 **표 전체**에 적용한다(패널 맨 위에 "적용 범위: 고른 범위 / 표 전체"가 보인다). 열 글자(A, B…)나 행 번호를 눌러 한 줄을 고르면 편하다.
- "첫 번째 행을 헤더로"가 켜져 있으면 **맨 윗줄(헤더)은 제외**한다. 헤더의 `2024` 같은 숫자가 서식으로 바뀌거나 헤더가 칠해지지 않게 하려는 것이다.
- **병합에 가려진 칸**은 건너뛴다.
- 결과는 패널 아래 한 줄로 알려 준다(`4칸의 숫자 서식을 바꿨습니다` 등). 바꿀 것이 없으면 이유가 보인다.
- 잘못 적용했으면 **되돌리기(Ctrl+Z 또는 툴바의 ↶)** 로 한 단계씩 되돌린다([table-editor-history.md](table-editor-history.md)). 패널 안의 입력칸에서 누른 Ctrl+Z 는 그 입력칸의 글자 되돌리기다. "적용"을 눌러야 문서에 반영된다.

## 숫자 서식

숫자 칸의 글자를 서식에 맞게 바꾼다. 네 가지를 고른 뒤 **적용**을 누른다.

| 항목 | 선택지 |
|---|---|
| 천 단위 쉼표 | **넣기**(`1234567` → `1,234,567`), **빼기**(`1,234,567` → `1234567`), 그대로 |
| 소수 자릿수 | 그대로, 0~6자리 (`3.14159` → `3.14`, `3` → `3.00`) |
| 앞 기호 | 그대로, 없음, `₩ $ € ¥ £` |
| 뒤 글자 | 그대로, 없음, `% 원 개 명 점 kg` |

- **반올림은 5에서 올림**이다. `1.005` 를 2자리로 하면 `1.01` 이다(컴퓨터의 이진 소수 오차 때문에 흔히 `1.00` 이 되는 문제를 피했다).
- 음수는 부호를 기호 앞에 둔다(`-₩300`). 반올림해서 0 이 되면 부호를 지운다(`-0.001` → `0.00`).
- **`%` 는 글자만 붙인다.** 값에 100 을 곱하지 않는다(`12` → `12%`, `0.12` → `0.12%`).
- 숫자인지 판단하는 규칙은 합계·정렬과 같다([table-editor-stats.md](table-editor-stats.md)): 쉼표, 앞 통화 기호, 뒤 단위(3글자까지)를 읽는다. `서울 3호선`, `2024-01-05`, 전화번호는 숫자가 아니라 건드리지 않는다.
- **앞에 0 이 붙은 정수(`007`)는 코드 번호일 수 있어 건드리지 않는다**(쉼표나 자릿수를 바꾸면 `7` 이 되어 버리므로).
- 옵션이 모두 "그대로"이거나 이미 그 서식이면 "바꿀 숫자 칸이 없습니다"가 보인다. 소수 자릿수를 정할 때 쉼표가 "그대로"이면 원래 쉼표 유무를 따른다(`1,234` → `1,234.0`, `1234` → `1234.0`).

## 조건부 색

조건을 고르고, 맞는 칸에 입힐 서식을 정한 뒤 **색 적용**을 누른다.

| 조건 | 맞는 칸 |
|---|---|
| 값이 다음보다 큼 / 이상 / 작음 / 이하 / 같음 / 다름 | **숫자 칸**만 비교한다(글자·빈 칸은 해당 없음). 기준 값 한 칸 |
| 값이 두 값 사이 | 양 끝 포함, 두 값의 순서는 상관없음 |
| 글자를 포함 | 대소문자 구분 없음. 찾을 글자가 비어 있으면 맞는 칸이 없다 |
| 비어 있음 / 비어 있지 않음 | 공백만 있는 칸도 빈 칸 |
| 최댓값 / 최솟값 | 적용 범위 안 숫자 중 가장 큰(작은) 값. 같은 값이 여럿이면 **모두** |
| 중복된 값 | 앞뒤 공백·대소문자를 무시하고 같은 글자가 둘 이상 있는 칸(빈 칸 제외) |

- 기준 값은 `1,000`, `500원` 처럼 합계와 같은 숫자 읽기 규칙으로 읽는다.
- 입힐 서식은 **배경색**, **글자색**, **굵게**다. 색 선택에서 지운(빈) 항목은 칠하지 않는다. 셋 다 비어 있으면 "칠할 색을 고르세요"가 보인다.
- **미리 보기**: 조건을 고르거나 값을 바꾸는 즉시 맞는 칸이 **주황 점선**으로 표시되고 `3칸이 조건에 맞음`이 보인다. 적용하기 전에 확인할 수 있다.
- **색 지우기**: 조건에 맞는 칸의 배경색·글자색·굵게를 모두 지운다.
- 입힌 색은 칸의 서식이라 나중에 값이 바뀌어도 그대로다. 규칙을 다시 적용해야 새 값에 맞게 칠해진다.

## 열 너비

고른 범위가 걸친 **열**의 너비를 정한다.

1. 열 글자(A, B…)를 눌러 열을 고른다(여러 열도 된다).
2. 숫자를 입력하고 단위(`px` 픽셀 / `%` 표 너비의 비율)를 고른 뒤 **적용**(입력칸에서 Enter 도 됨).
3. **지우기**는 그 열의 너비 지정을 모두 없앤다. 패널 맨 끝의 "지금: 120px"에서 현재 값을 볼 수 있다.

- **정수만** 받는다: px 는 1~9999, % 는 1~100. 소수는 반올림한다. 그 밖의 값은 안내가 나온다.
- 너비는 그 열의 **맨 위 칸 한 곳**에 `<width=120px>` 속성으로 저장된다. 같은 열의 다른 칸에 예전에 있던 너비 지정은 지워진다(한 곳에만 둠). 다른 속성은 건드리지 않는다.
- **가로로 병합된 칸**은 어느 열의 너비인지 알 수 없어 붙이지 않는다. 열 전체가 병합에 걸려 있으면 "붙일 수 있는 칸이 없습니다"가 보인다.
- 편집기의 칸 입력창 폭은 그대로다. 적용 결과는 아래 **뷰어 미리보기**와 실제 뷰어에서 보인다. 글자가 길면 브라우저가 칸을 더 넓히므로 너비는 "원하는 폭"에 가깝다.

## 줄무늬

1. **줄무늬 색**을 고르고, 시작을 **둘째 줄부터**(기본) 또는 **첫 줄부터**로 정한다.
2. **칠하기**: 적용 범위의 행을 한 줄 걸러 그 색으로 칠한다. 줄 순서는 **헤더를 뺀 범위의 첫 행부터** 센다.
3. **해제**: 범위 안에서 **이 색과 같은 배경**을 지운다. 다른 색(조건부 색 등)은 남긴다.

- 칠하는 줄의 기존 배경색은 덮어쓴다. 칠하지 않는 줄은 그대로다.
- 행 단위 속성(`rowbgcolor`)이 아니라 **칸마다 배경색**을 입힌다. 편집기에서 바로 보이고 칸별로 고칠 수 있다.

## 행·열 바꾸기 (전치)

서식 도구는 아니지만 같은 시기에 추가된 **구조 툴바 "표" 묶음**의 단추다. 가로와 세로를 뒤집는다(한 번 더 누르면 원래대로).

- 칸 (행, 열)이 (열, 행)으로 간다. **병합은 가로↔세로가 바뀐다**(가로 2칸 병합은 세로 2칸 병합이 된다). 칸의 서식은 따라간다.
- 행·열 방향이 있는 속성도 맞바뀐다: `rowbgcolor`↔`colbgcolor`, `rowcolor`↔`colcolor`, `width`↔`height`. 표 전체 속성(`tablewidth` 등)은 그대로다.
- **"첫 번째 행을 헤더로"** 는 맨 윗줄에만 굵게를 입히는 설정이라 뒤집으면 엉뚱한 줄이 굵어진다. 그래서 지금의 헤더 행을 **칸의 굵게로 바꿔 두고**(굵은 첫 열이 된다) 체크는 **꺼진다**. 두 번 뒤집으면 모양과 내용은 같지만 체크는 꺼진 채다.
- 전치 뒤 선택은 맨 앞 칸이다.

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| **천 단위 쉼표** | 큰 수를 세 자리씩 끊어 읽기 쉽게 하는 쉼표(`1,234,567`). |
| **반올림(5에서 올림)** | 버리는 자리가 5 이상이면 올리는 계산. |
| **조건부 서식** | 값이 조건에 맞는 칸에만 색을 입히는 기능. 여기서는 한 번 칠하는 방식이다. |
| **줄무늬(지브라)** | 읽기 쉽도록 행을 번갈아 다른 배경색으로 칠한 표. |
| **전치(transpose)** | 행과 열을 맞바꾸는 것. |

## 한계

- 값이 바뀌어도 서식이 자동으로 따라오지 않는다(한 번 적용).
- 숫자 서식은 날짜·시각·통화가 아닌 일반 숫자만 다룬다. 만·억 단위 환산, 백분율 변환(×100)은 없다.
- 조건부 색의 조건은 하나씩만 건다(여러 조건 동시 지정 없음). 색 눈금(그라데이션)·막대도 없다.
- 열 너비는 열 단위만 된다(행 높이 지정은 없다). 너비가 실제로 어떻게 보일지는 뷰어 미리보기로 확인한다.
- 실제 Electron 앱 창이 아니라 브라우저 미리보기에서 확인했다.
