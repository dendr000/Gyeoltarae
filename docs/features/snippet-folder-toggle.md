# 상용구 폴더별 사용 체크 (읽지 않기)

## 한 줄 요약

상용구 모달의 **"폴더별 사용" 탭**에서 폴더마다 체크를 둔다. **체크를 푼 폴더는 앱이 켜질 때 파일을 읽지 않고(시작이 빨라짐), 자동 추천 팝업·스페이스바 자동 치환·Alt+Enter·이 창의 "상용구" 목록·툴바 "상용구 삽입" 목록 어디에도 나오지 않는다.** 다시 체크하면 그 폴더만 바로 읽어 온다. 기본은 모든 폴더가 체크된 상태(= 전체)다.

> **0.143.0 에서 바뀐 점**: 예전에는 체크를 풀어도 추천에서만 빠지고 파일은 전부 읽었으며 목록에는 그대로 보였다. 지금은 **읽지 않고 목록에서도 완전히 숨긴다.** 상용구가 1만 개 넘게 있어도 쓰는 폴더만 읽으면 시작이 훨씬 빠르다.

### 빨리 쓰는 법 (예: 파이썬 강의 들을 때)

1. 상용구 창(사이드바 "상용구 관리" 또는 Alt+T) → 위쪽 **폴더별 사용** 탭.
2. 쓸 폴더 하나의 **이것만**을 누른다(예: `Python`) — 나머지가 모두 꺼진다.
3. 같이 쓸 폴더(예: `명령`, `영어`, `기호`)를 다시 체크한다. 체크하는 즉시 그 폴더만 읽어 온다.
4. 다른 과목을 들을 때는 같은 방법으로 폴더를 바꿔 체크한다.

## 왜 만들었나

`SQL` 폴더에 학습용 이름까지 합쳐 약 1950개가 들어가면서, 글(문단)을 쓸 때도 `name`, `class` 같은 단어에 후보가 뜨는 일이 생겼다. 예전의 "활성 폴더"(모달에서 폴더 하나를 골라 그 폴더와 `공통` 만 쓰는 방식)는 한 폴더만 고를 수 있고 모달을 닫으면 '전체'로 돌아간다. 이 기능은 **폴더마다 켜고 끄는 값을 따로 저장**해서, 평소엔 전체로 쓰다가 필요한 폴더만 빼거나 넣을 수 있게 한다.

## 쓰는 법

1. 상용구 모달(사이드바 "상용구 관리" 또는 Alt+T)을 열고 위쪽 탭에서 **폴더별 사용** 을 누른다.
2. 폴더 이름 앞의 체크를 풀면 그 폴더의 상용구는 자동 추천에서 빠진다. 다시 체크하면 돌아온다.
3. **이것만**: 그 폴더만 체크하고 나머지는 모두 끈다. **모두 선택 / 모두 해제**: 전부 켜거나 끈다.
4. 위쪽 요약에 "자동 추천에 쓰는 폴더 1/2개 (상용구 2개)" 처럼 지금 몇 개가 쓰이는지 보인다. 전부 끄면 경고가 뜬다.

## 동작 규칙

| 항목 | 규칙 |
|---|---|
| 기본값 | 아무 폴더도 끄지 않음(전체 사용). 새로 만든 폴더도 처음엔 체크된 상태 |
| 읽기 | 체크를 푼 폴더의 상용구 파일은 읽지 않는다. 읽지 않은 폴더의 원본 파일은 그대로 있다 |
| 적용 대상 | 자동 추천 팝업, 스페이스바 자동 치환, Alt+Enter, 모달 "상용구" 탭 목록, 툴바 "상용구 삽입" 목록 — 전부 읽은 상용구만 나온다 |
| "폴더별 사용" 탭 | 읽지 않은 폴더도 이름과 개수(스캔으로 센 것)와 함께 보여 준다(다시 켜야 하므로) |
| 다시 켤 때 | 그 폴더만 읽어 색인에 더한다. 읽는 동안 헤더 "저장됨" 옆에 진행 표시가 뜬다(100개 이상일 때) |
| 끌 때 | 읽어 둔 상용구를 색인에서 바로 뺀다(디스크를 다시 읽지 않는다) |
| 꺼진 폴더에 새 상용구 등록 | 상용구 창에서 꺼진 폴더 이름으로 새로 등록하거나 일괄 등록하면 그 폴더를 다시 켠다(안 그러면 방금 만든 것이 안 보이므로) |
| `공통` 폴더 | 특별 취급하지 않는다. 다른 폴더처럼 체크를 풀 수 있다 |
| 활성 폴더와의 관계 | 둘 다 통과해야 쓰인다. 활성 폴더(모달에서 고른 폴더 + `공통`)로 먼저 좁히고, 그중 체크를 푼 폴더를 뺀다. 활성 폴더는 모달을 닫으면 '전체'로 돌아가지만 이 체크는 유지된다 |
| 저장 | 체크를 푼 폴더 이름의 목록을 이 PC 의 화면 설정(localStorage `wikidesk-snippet-disabled-folders`)에 저장한다. 워크스페이스 파일은 건드리지 않는다 |
| 상용구가 없는 폴더 | 탭 목록에 나오지 않는다(개수를 셀 상용구가 없으므로) |
| 한계 | 꺼 둔 폴더를 파일 탐색기에서 직접 고쳐도 앱에는 반영되지 않는다(다시 켤 때 읽어 온다). 폴더 이름은 대소문자까지 같아야 같은 폴더로 본다 |

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| **자동 추천 팝업** | 글을 치는 도중 단축어 앞부분이 맞으면 커서 근처에 뜨는 후보 목록 |
| **스페이스바 자동 치환** | 단축어를 끝까지 치고 스페이스를 누르면 본문으로 바뀌는 기능 |
| **활성 폴더** | 모달에서 고른 폴더 하나. 에디터는 그 폴더와 `공통` 의 상용구만 쓴다(`snippet-active-folder.md`) |
| **localStorage** | 브라우저(앱 화면)가 이 PC 에 저장해 두는 작은 설정 저장소 |

## 구현 위치

- `src/lib/snippetScope.js` — `selectEnabledSnippets`(체크를 푼 폴더 빼기), `withFolderEnabled`(한 폴더 켜고 끄기), `disabledAllExcept`("이것만").
- `src/store/useAppStore.js` — `disabledSnippetFolders` 상태와 `setSnippetFolderEnabled`, `setDisabledSnippetFolders`(저장 포함).
- `src/components/SnippetFolderTab.jsx` — 탭 화면. `src/components/SnippetModal.jsx` — 탭 전환. `src/components/EditorPane.jsx` — 에디터가 쓰는 상용구 계산(`activeSnippets`).
- 테스트: `tests/lib/snippetScope.test.js`, `tests/store/modals.test.js`.

## 알려진 한계

- 체크 설정은 이 PC 의 화면 설정이라 다른 PC 의 같은 워크스페이스에는 따라가지 않는다.
- 폴더 이름을 바꾸거나 지우면 이전 이름의 체크 값이 목록에 남지만, 없는 폴더라서 아무 영향이 없다. 같은 이름의 폴더를 다시 만들면 꺼진 상태로 나타난다.
- 한 폴더 안에서 일부 상용구만 끄는 기능은 없다(폴더 단위만).
