# 묶음 정렬 (Ctrl+Shift+`)

## 한 줄 요약

편집 모드에서 여러 줄을 선택하고 **Ctrl+Shift+`** 를 누르면, 줄 하나씩이 아니라 **묶음 단위**로 이름순 정렬된다. 묶음의 **맨 윗줄 글자**가 기준이고 딸린 줄은 함께 움직인다. **항상 오름차순**이고, 메뉴 **설정**에서 "다시 누르면 뒤집기"를 켜면 이미 오름차순일 때 다시 눌러 내림차순으로 뒤집을 수 있다([settings-menu.md](settings-menu.md)). (줄 하나씩 정렬하는 것은 [Ctrl+`](line-sort.md))

## 사용 예

### 목록과 하위 항목 (들여쓰기)

| 정렬 전 | 정렬 후 (Ctrl+Shift+`) |
|---|---|
| `* 다람쥐` / `  * 하위 2` / `  * 하위 1` / `* 가지` / `  * 가지 하위` | `* 가지` / `  * 가지 하위` / `* 다람쥐` / `  * 하위 2` / `  * 하위 1` |

딸린 줄끼리의 순서는 그대로다(`하위 2` 가 `하위 1` 앞에 있던 대로).

### 번호 목록 — 번호는 제자리에

| 정렬 전 | 정렬 후 |
|---|---|
| `1. 다람쥐` / `2. 가지` / `3. 나비` | `1. 가지` / `2. 나비` / `3. 다람쥐` |

내용만 옮기고 **번호는 1, 2, 3 순서 그대로** 남는다. 번호를 따라 같이 움직이면 정렬 뒤에도 `2. 가지 / 3. 나비 / 1. 다람쥐` 처럼 어긋나기 때문이다. 딸린 줄이 있어도 같다.

### 빈 줄로 나뉜 덩어리

| 정렬 전 | 정렬 후 |
|---|---|
| `나1` / `나2` / (빈 줄) / `가1` / `가2` | `가1` / `가2` / (빈 줄) / `나1` / `나2` |

## 묶음을 나누는 규칙

선택한 줄 중 **가장 얕게 들여쓴 줄**을 "맨 윗줄 들여쓰기"로 본다(전체가 한 칸씩 들여써져 있어도 된다).

1. **들여쓴 줄이 있으면**: 맨 윗줄 들여쓰기의 줄이 묶음의 머리고, 그보다 더 들여쓴 줄은 바로 위 묶음에 딸린다. 탭 한 개는 공백 4칸으로 센다.
2. **들여쓴 줄이 하나도 없으면**: 목록 표시(`*` `-` `+` `1.` `1)` `a.`)로 시작하는 줄이 각각 묶음의 머리가 된다. 표시가 없는 줄은 **빈 줄 뒤에서** 새 묶음이 되고, 그 밖에는 위 묶음에 이어진다.
3. **묶음 사이의 빈 줄은 구분선으로 제자리에 남는다**(빈 줄이 2개였던 자리는 정렬 뒤에도 2개). 딸린 줄 앞의 빈 줄은 묶음 안에 남고, 선택 앞뒤의 빈 줄도 제자리에 있다.

## 비교 규칙

- 줄 정렬과 같은 한국어 이름순이다: 숫자 < 한글 < 영문, 숫자는 크기로(`항목2` < `항목10`), 대소문자 무시, 같은 것끼리는 원래 순서 유지.
- **머리 줄 앞의 목록 표시(`*` `-` `+` `1.` `a.`)는 비교에서 뺀다.** `* 나`, `- 가`, `+ 다` 는 `가, 나, 다` 순서가 된다.
- 머리가 **전부 번호 목록**이면 번호를 그 자리에 남긴다(위 번호 목록 예). 번호 목록과 `*` 목록이 섞여 있으면 번호를 다시 매기지 않는다.

## 하지 않는 경우 (키만 소비하고 아무것도 안 함)

- 선택이 없거나 **묶음이 하나뿐**일 때 — 들여쓰기도 표시도 빈 줄도 없이 줄만 이어진 글은 한 덩어리라서, 그때는 줄 하나씩 정렬하는 **Ctrl+`** 를 쓴다.
- 선택에 코드블록의 여는·닫는 줄(```)이 들어 있을 때.
- 이미 오름차순이라서 바뀌는 것이 없을 때(기본). "뒤집기" 설정을 켰다면 이 경우에 내림차순으로 뒤집는다.
- 줄 전체를 골라 다음 줄 맨 앞에서 끝나는 선택은 그 다음 줄을 포함하지 않는다.
- Alt 가 같이 눌린 조합에는 반응하지 않는다. Mac 은 Cmd+Shift+`.
- Ctrl+Z 로 되돌린다. 정렬한 줄들은 선택된 채로 남는다("뒤집기"를 켜 두었다면 바로 한 번 더 눌러 뒤집을 수 있다).

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| 묶음 | 머리 줄 하나와 그에 딸린 줄들. 정렬할 때 한 덩어리로 움직인다 |
| 머리 줄 / 딸린 줄 | 묶음의 맨 윗줄 / 그보다 더 들여쓴 하위 줄 |
| 들여쓰기 | 줄 앞의 공백이나 탭. 위키 목록에서 하위 항목을 나타낸다 |
| 목록 표시 | 줄 맨 앞의 `*`, `-`, `1.` 같은 글머리 기호 |
| 구분선 | 묶음 사이에 있는 빈 줄. 정렬해도 그 자리에 남는다 |
