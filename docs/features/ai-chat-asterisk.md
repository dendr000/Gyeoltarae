# AI챗 폴더의 별표(*) 짝 맞추기

## 한 줄 요약

최상위 폴더 **"AI챗"** 안의 문서를 편집창에서 쓸 때 **별표(`*`) 하나를 치면 별표 두 개(`**`)가 생기고 커서가 그 사이에 선다.** AI 대화를 붙여 넣어 정리하는 폴더라서 마크다운 강조(`*기울임*`, `**굵게**`)를 자주 쓰기 때문이다. **다른 폴더에서는 동작하지 않는다.**

## 쓰는 법

| 하는 일 | 결과 (`|` 는 커서) |
|---|---|
| `*` 한 번 | `*|*` — 기울임 짝 |
| 바로 이어서 `*` 한 번 더 | `**|**` — 굵게 짝 |
| 글을 쓰고 `*` | 닫는 별표를 **하나씩 넘어간다**(`**굵게|**` → `**굵게*|*` → `**굵게**|`) |
| 글을 **선택**하고 `*` | 선택한 글을 `*글*` 로 감싼다(안쪽 글은 그대로 선택됨) |
| 줄 맨 앞에서 `*` 다음에 바로 공백 | 목록 표시로 보고 자동으로 생긴 닫는 별표를 지워 `* |` 로 만든다 |
| 되돌리기 `Ctrl+Z` | 다른 편집처럼 되돌려진다 |

- **"바로 이어서"** 는 방금 자동으로 짝을 만든 자리에서 커서를 옮기지 않고 친 별표를 말한다. 글 가운데의 `**글*|*` 처럼 모양만 같은 자리에서는 굵게로 넓히지 않고 닫는 별표를 넘어간다.
- 앞에 별표가 붙어 있고 뒤에는 없는 자리(`**|`)에서 치는 별표는 짝을 만들지 않고 그냥 쓴다. 직접 `***` 같은 글을 쓸 때 방해하지 않으려는 것이다.
- 목록 표시(`* 항목`)는 위키 문법에서도 쓰는 줄 맨 앞 별표다. 이때는 닫는 별표가 남지 않게 공백을 치는 순간 지운다. 공백이 아닌 다른 글을 치면 `*글*` 의 시작으로 본다.

## "AI챗 폴더 안"의 기준

- **작업 폴더(워크스페이스) 바로 아래의 "AI챗" 폴더**이고, 그 아래라면 몇 겹 안쪽 폴더의 문서여도 된다(`AI챗\2026\10월\대화.md`).
- 이름이 **정확히 `AI챗`** 이어야 한다. `AI챗2`, `ai챗`, `AI챗 보관` 은 해당하지 않는다. 다른 폴더 안의 `강의\AI챗` 도 해당하지 않는다.
- 작업 폴더 맨 위의 문서 `AI챗.md` 는 폴더가 아니므로 해당하지 않는다.
- 윈도·맥 경로 모양(`\` 와 `/`), 한글을 풀어 쓴 형태(NFD)의 차이는 같게 본다.

## 구조

| 파일 | 역할 |
|---|---|
| `src/lib/asteriskPair.js` | 별표를 칠 때 무엇을 할지(`asteriskPairEdit`)와 "AI챗 폴더 안" 판정(`isAiChatDoc`) — 순수 함수 |
| `src/components/EditorPane.jsx` | 키를 받아 결과를 편집창에 적용, 방금 짝을 만든 자리 기억(`asteriskFreshRef`) |
| `tests/lib/asteriskPair.test.js`, `tests/components/editorAsterisk.test.js` | 규칙·연결 시험 |

기존 자동 괄호(`( [ ' " < {`)는 모든 폴더에서 그대로 동작하고, 별표는 그 목록에 넣지 않았다(폴더 한정이므로).

## 확인한 것 (실제 Electron 창, 실제 키 입력 — Shift+8)

AI챗 폴더 문서에서: `*` → `*|*` · 한 번 더 → `**|**` · "굵게" 입력 → `**굵게|**` · `*` 두 번 → `**굵게**|` · 글 선택 후 `*` → 선택한 글이 `*글*` 로 감싸지고 2글자가 선택된 채 유지 · 줄 맨 앞 `*` 뒤 공백 → `* |`, 이어서 "항목" 입력 → `* 항목|` · `Ctrl+Z` 로 되돌려짐. 다른 폴더(`강의`) 문서에서는 `*` 하나만 입력되고 짝이 생기지 않음.

## 한계

- 한글 입력기(IME)로 글을 조합하는 중에 치는 별표는 이 규칙을 타지 않는다(브라우저가 조합 중에는 키를 따로 알려 주기 때문).
- 다른 폴더(예: 새로 만든 `AI대화`)에 같은 동작이 필요하면 폴더 이름을 정하는 기준(`AI_CHAT_FOLDER`)을 고쳐야 한다. 여러 폴더를 고르는 설정은 아직 없다.
- `2*3` 처럼 곱셈 별표를 AI챗 폴더에서 쓰면 `*|*` 가 생긴다. 닫는 별표를 넘어가면(`*` 를 한 번 더) 정리된다.

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| 짝 맞추기 | 여는 기호를 치면 닫는 기호도 같이 만들어 주는 기능 |
| 마크다운 | `*기울임*`, `**굵게**` 같은 기호로 글을 꾸미는 표기법. AI 챗봇의 답변이 이 방식으로 나온다 |
| 커서(캐럿) | 글을 칠 자리를 알려 주는 깜빡이는 세로 막대 |
| IME | 한글처럼 글자를 조합해서 쓰는 입력 방식(입력기) |
