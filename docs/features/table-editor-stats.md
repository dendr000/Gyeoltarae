# 표 편집기의 합계·평균 표시줄

## 한 줄 요약

표 편집기에서 칸을 여러 개 고르면 표 바로 아래에 **합계 · 평균 · 개수 · 최소 · 최대**가 보인다. 계산 결과는 **보기용**이라 문서에는 아무것도 쓰지 않는다. 값을 누르면 숫자만 복사돼서 원하는 칸에 붙여넣을 수 있다.

## 쓰는 법

1. 표 편집기를 연다(편집 모드의 툴바 "표").
2. 범위를 고른다.
   - **열 글자(A, B, C…)** 를 누르면 그 열 전체, **행 번호(1, 2, 3…)** 를 누르면 그 행 전체, **왼쪽 위 모서리**를 누르면 표 전체가 고른 범위가 된다.
   - 또는 칸을 누른 뒤 **Shift+클릭**으로 범위를 넓힌다.
3. 표 아래 표시줄에 `B1:B5  5칸  합계 30  평균 7.5  개수 4  최소 2  최대 15` 처럼 보인다.
4. 값을 누르면 **쉼표 없는 숫자**(`1266.666667`)가 클립보드에 복사되고 잠깐 "복사됨"이 뜬다. 칸 안에서 Ctrl+V 로 붙여넣으면 된다.

한 칸만 골랐을 때는 합계가 의미 없어서 안내 문장만 보인다.

## 숫자로 읽는 규칙

칸의 글에서 숫자를 읽는다. 아래에 맞으면 숫자 칸, 아니면 **계산에서 빠진다**(오류가 나지 않고 그냥 건너뜀).

| 숫자로 읽는다 | 읽은 값 |
|---|---|
| `12`, `-3`, `+4`, `3.5`, `.5` | 그대로 |
| `1,234`, `12,345,678.9` (쉼표는 3자리씩 맞을 때만) | 1234, 12345678.9 |
| `₩500`, `$12.5`, `-₩300` (통화 기호) | 500, 12.5, -300 |
| `12%` | **12** (0.12 가 아님) |
| `3개`, `500원`, `12kg`, `5.5 점`, `3개월분` (뒤에 붙은 단위, 3글자까지) | 3, 500, 12, 5.5, 3 |

| 숫자로 읽지 않는다 | 이유 |
|---|---|
| `서울 3호선`, `총 5개` | 숫자 앞에 글이 있음 |
| `2024-01-05`, `10:30`, `010-1234-5678`, `1.2.3`, `1,23` | 날짜·시각·전화번호·버전은 숫자가 아님 |
| `1e5`, `3 4`, `3개월분씩` | 지수 표기·숫자 둘·긴 단위는 지원하지 않음 |
| 빈 칸, 글자만 있는 칸 | 숫자가 없음 |

- 읽은 칸 수는 **개수**로 보여 준다. 합계가 이상하면 개수가 기대와 같은지 먼저 본다.
- 칸 안의 `[br]`(줄바꿈 표시)는 공백으로 본다. `12[br]` 는 12, `1[br]2` 는 숫자가 아니다.
- 단위가 붙은 칸(`3호선` 같은 것)도 숫자로 읽히므로 서로 다른 의미의 칸을 한 범위로 고르면 합계가 엉뚱해질 수 있다. 의미가 같은 칸끼리 골라서 쓴다.
- `3만`, `1.5억` 처럼 단위가 크기를 바꾸는 표기는 **그냥 3, 1.5 로 읽는다**(만·억을 곱하지 않는다).

## 병합 셀과 헤더 행

- **병합된 칸**: 병합한 칸은 한 번만 세고, 다른 칸의 병합에 **가려진 칸은 세지 않는다**. 가려진 칸에 글자가 남아 있어도 무시한다.
- **헤더 행**: "첫 번째 행을 헤더로" 가 켜져 있으면 고른 범위의 **맨 윗줄은 계산에서 뺀다**(예: 머리글에 `2024` 가 있어도 합계가 섞이지 않게). 뺐을 때는 표시줄에 "첫 행(헤더)은 계산에서 뺐습니다" 가 보인다. 체크가 꺼져 있으면 맨 윗줄도 센다.
  - 이미 `'''굵게'''` 로 저장된 첫 줄을 불러온 표는 체크가 꺼진 채로 열릴 수 있으니, 숫자 머리글이 있으면 체크를 확인한다.

## 표시 형식

- 소수는 **6자리까지**, 뒤의 0 은 생략한다. 천 단위 쉼표가 붙는다(`1,266.666667`). 복사할 때는 쉼표가 빠진다.
- `0.1 + 0.2` 같은 이진 소수 오차는 15자리 유효숫자로 정리해서 `0.3` 으로 보인다.
- 평균은 숫자로 읽은 칸 수(개수)로 나눈다. 숫자가 하나도 없으면 "숫자가 있는 칸이 없습니다" 가 보인다.

## 같이 바뀐 것

- 표 위에 **열 글자(A, B, C…)**, 왼쪽에 **행 번호(1, 2, 3…)** 가 생겼다. 고른 범위에 든 것은 강조색으로 보인다.
- 툴바 왼쪽의 "선택 범위" 이름이 `(1,1) ~ (2,3)` 에서 엑셀식 `A1:C2`, 한 칸이면 `B2` 로 바뀌었다.

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| **범위** | 연속한 칸의 묶음. `B2:D5` 는 B열 2행부터 D열 5행까지의 직사각형. |
| **합계 / 평균 / 개수 / 최소 / 최대** | 숫자 칸을 모두 더한 값 / 합계를 개수로 나눈 값 / 숫자로 읽은 칸 수 / 가장 작은 값 / 가장 큰 값. |
| **병합** | 여러 칸을 하나로 합친 것. 합쳐진 칸은 왼쪽 위 칸 하나가 대표한다. |
| **상태 표시줄** | 화면 한쪽에 현재 선택에 대한 요약을 보여 주는 줄. 엑셀 아래쪽의 합계 표시와 같은 역할. |

## 한계와 앞으로

- 계산 결과는 **문서에 남지 않고** 값이 바뀌어도 표시줄만 갱신된다. 문서에 숫자를 넣거나 수식을 저장하는 기능은 아직 없다. 방식 비교와 단계 계획은 [docs/plans/table-editor-calculations.md](../plans/table-editor-calculations.md).
- 사칙연산 열 채우기(B×C → D 열), 정렬, 행·열 중간 삽입 같은 기능도 위 계획서에 후보로 적어 두었다.
- 실제 Electron 앱의 클립보드(값 복사)는 브라우저 미리보기에서 클립보드 함수를 가짜로 바꿔 복사되는 값만 확인했다.

- `src/App.css` — `.table-editor-head-cell`, `.table-editor-stats` 스타일(라이트·다크는 기존 색 토큰 사용).
