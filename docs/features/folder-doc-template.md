# 폴더별 새 문서 기본 내용 (따즈아)

## 한 줄 요약

**따즈아** 폴더(그 아래 하위 폴더 포함)에서 새 문서를 만들면 아래 뼈대(분류 세 줄, 목차, 큰 제목 네 묶음)가 자동으로 채워진 채로 시작한다.

````text
[[분류:ddazua]]
[[분류:]]
[[분류:]]
[목차]

=  =
==  ==
* 

==  ==
* 


=  =
==  ==
* 

==  ==
* 


=  =
==  ==
* 

==  ==
* 


=  =
==  ==
* 

==  ==
* 
````

(`* ` 줄 끝의 공백도 그대로다. 위 내용은 `tests/helpers/ddazuaTemplate.js` 에 요청받은 본문을 따로 옮겨 적어 두고 구현과 대조한다.)

## 동작

- **적용 범위**: 폴더 경로 어딘가에 이름이 `따즈아` 인 폴더가 있으면 적용된다. 따즈아 폴더 자신, `따즈아/01 올인원 …` 같은 하위 폴더, 그 아래 더 깊은 폴더 모두 같다. 폴더 이름 **전체**가 같아야 한다(`따즈아 (1)`, `01 따즈아` 는 해당하지 않음).
- **적용되는 길**: 앱이 새 문서를 만드는 모든 길 — "+ 새 문서" 버튼, 폴더 행의 "+문서", 우클릭 메뉴 "새 문서"(모두 같은 새 문서 입력창을 거침), 없는 문서 링크(`[[없는 문서]]`)를 눌러 만드는 문서.
- **적용되지 않는 길**:
  - 파일을 끌어다 놓아 가져온 문서(가져온 내용 그대로).
  - **글양식(틀)을 직접 골라 만든 문서** — 사용자가 고른 글양식이 폴더 기본 내용보다 우선한다.
- **따즈아 밖**의 폴더는 예전과 같다: `[[분류:]]` 한 줄로 시작.
- **분류의 빈 칸 둘**(`[[분류:]]` 두 줄)은 **자동 분류**(`docs/features/auto-category.md`)가 폴더·문서 이름에서 찾은 글자로 위에서부터 차례로 채운다. 자동 분류를 설정하지 않았거나 걸리는 글자가 없으면 빈 채로 남고, 직접 채우면 된다. 예) 폴더 `01 올인원 DBMS!! …`, 문서 `04 외래키와 Join`, 읽어들일 글자 `DBMS, 외래키` → `[[분류:ddazua]]` `[[분류:DBMS]]` `[[분류:외래키]]`.
- **큰 제목 네 묶음**: 각 묶음은 `=  =`(큰 제목, 비어 있음) 아래에 `==  ==`(작은 제목) 둘과 각각의 빈 목록 항목(`* `)이 있다. 묶음 사이는 빈 줄 둘, 묶음 안 작은 제목 사이는 빈 줄 하나다. 제목 자리(두 `=` 사이)와 목록 항목은 직접 채우면 된다.
- 만들어진 문서는 바로 열리고 편집창에 위 내용이 그대로 보인다.

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| **분류(`[[분류:이름]]`)** | 문서를 묶는 이름표. 문서 맨 아래 배지로 모이고, 같은 분류의 문서를 한 페이지에서 볼 수 있다. |
| **`[목차]`** | 문서의 제목들을 모아 자동으로 보여 주는 목차를 그 자리에 넣는 표시. |
| **글양식(틀)** | "새 문서" 만들 때 고를 수 있는 기존 틀 문서. 그 내용을 한 번만 복사해서 시작한다. |

## 구현 위치

- `src/lib/folderDocTemplate.js` — 폴더 이름별 기본 내용 목록(`FOLDER_DOC_TEMPLATES`)과 찾는 함수(`findFolderDocTemplate`). **다른 폴더에도 이런 기본 내용을 쓰려면 이 목록에 `{ folderName, content }` 를 추가**하면 된다.
- `src/store/useAppStore.js` — `createDoc` 에서 적용. 우선순위는 **고른 글양식 > 폴더 기본 내용 > 예전 기본 내용(`[[분류:]]` 한 줄)**, 그 위에 작품 폴더 자동 분류와 폴더 자동 분류(읽어들일 글자)가 차례로 얹힌다.
- 테스트: `tests/lib/folderDocTemplate.test.js`, `tests/store/folderDocTemplate.test.js`, `tests/helpers/ddazuaTemplate.js`(요청받은 본문 기대값).

## 알려진 한계

- **기존 문서와 분류 이름이 다르다.** 이미 있는 따즈아 문서들은 `[[분류:따즈아]]` 로 시작하는데, 이 기본 내용은 `[[분류:ddazua]]` 다(요청받은 그대로). 새 문서와 기존 문서가 서로 다른 두 분류로 나뉘어 보인다. 하나로 합치려면 이 목록의 내용을 `따즈아` 로 바꾸거나 기존 문서의 분류를 `ddazua` 로 바꾸면 된다.
- 폴더 기본 내용은 앱 코드 안에 들어 있어서 바꾸려면 코드를 고쳐야 한다(설정 화면은 없다). 읽어들일 글자(자동 분류)는 우클릭 메뉴에서 바꿀 수 있다.
- **채우기 전의 빈 자리는 뷰어에 그대로 드러난다**(파서로 확인함): 비어 있는 `[[분류:]]` 줄은 "분류:" 글자로, 빈 제목(`=  =`)은 번호만(`1.` `1.1.`), 빈 목록 항목(`* `)은 `*` 한 글자로 보인다. 직접 채우라는 자리라서 채우면 사라진다. (비어 있는 `[[분류:]]` 줄이 "분류:" 로 보이는 건 예전 기본 내용도 같던 기존 동작이다.)
- 따즈아 폴더가 소설·웹툰·만화·포켓몬스터 같은 **작품 폴더 안**에 있으면, 작품 폴더의 자동 분류 규칙이 첫 번째 빈 `[[분류:]]` 줄을 자동 분류 이름으로 채운다. 예를 들어 `소설/작품/따즈아` 에서 만든 문서는 `[[분류:ddazua]]`, `[[분류:작품]]`, `[[분류:작품/따즈아]]`, `[[분류:]]` 로 시작한다(자동 시험으로 확인). 현재 `D:\WikiDesk\강의\따즈아` 위치는 작품 폴더가 아니라서 해당 없다.
