# 폴더별 새 문서 기본 내용 (따즈아 01·02) — 틀로 이전됨

> **이 문서는 옛 방식의 기록이다.** 2026-10-12 에 코드에 내장돼 있던 이 내용을 없애고 **글양식(틀) + 폴더 기본 틀 설정**으로 옮겼다. 지금 방식과 쓰는 법은 [`folder-default-template.md`](folder-default-template.md) 를 본다.

## 무엇이었나

따즈아 아래의 두 폴더에서 새 문서를 만들면 코드(`src/lib/folderDocTemplate.js`)에 적힌 뼈대가 자동으로 채워졌다. 새 강의 폴더가 생길 때마다 코드를 고쳐야 해서, 폴더에서 틀을 지정하는 방식으로 바꿨다.

## 01 올인원 폴더의 내용

````text

[[분류:]]

[목차]

````

(`* ` 줄 끝의 공백도 그대로다.) 비어 있는 `[[분류:]]` 칸 둘은 폴더의 **자동 분류**(`docs/features/auto-category.md`)가 폴더·문서 이름에서 찾은 글자로 위에서부터 차례로 채운다.

## 02 배워서 바로 써먹는 폴더의 내용

````text
[[분류:ddazua]]
[[분류:DBMS]]
[[분류:DBMS/]]
[목차]
[clearfix]

=  =
```DBeaver
```

=  =
```DBeaver
```

=  =
```DBeaver
```
````

- `[[분류:DBMS/]]` 는 뒤에 직접 이어 쓰는 분류(예: `DBMS/정규화`)이고, `[clearfix]` 는 목차 오른쪽에 떠 있는 요소가 아래 내용과 겹치지 않게 끊어 주는 표시다.
- 비어 있는 `[[분류:]]` 칸이 없어서 자동 분류가 찾은 분류는 맨 위 분류 줄들 바로 뒤에 새 줄로 들어간다.

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| **분류(`[[분류:이름]]`)** | 문서를 묶는 이름표. 문서 맨 아래 배지로 모이고, 같은 분류의 문서를 한 페이지에서 볼 수 있다. |
| **`[목차]`** | 문서의 제목들을 모아 자동으로 보여 주는 목차를 그 자리에 넣는 표시. |
| **글양식(틀)** | 사이드바 "틀"에 만들어 두는 문서. 새 문서를 만들 때 그 내용을 한 번 복사해서 시작한다. |

## 알려진 한계 (옛 방식 — 지금은 해당 없음)

- 폴더를 추가할 때마다 코드를 고쳐야 했다. → 폴더 기본 틀 설정으로 해결.
- 이 내용이 코드에 있어서 다른 PC 의 같은 워크스페이스에서도 자동으로 쓰였다. 지금은 틀과 설정이 워크스페이스 안에 있으므로 워크스페이스 폴더를 옮기면 따라가지만, 틀이 없는 다른 워크스페이스에서는 적용되지 않는다.
