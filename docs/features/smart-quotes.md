# 뷰어의 둥근 따옴표 표시

## 한 줄 요약

뷰어(오른쪽 렌더링 화면)가 글 속의 곧은 따옴표를 **열림/닫힘이 구분되는 둥근 따옴표**로 바꿔 보여 준다. 원문(편집창, 저장된 파일)은 바뀌지 않는다.

| 원문(편집창) | 뷰어에 보이는 글 |
|---|---|
| `그가 "안녕" 했다` | 그가 “안녕” 했다 |
| `이름이 'sglee'인 학생` | 이름이 ‘sglee’인 학생 |
| `it's and don't` | it’s and don’t |
| `"He said 'hi'"` | “He said ‘hi’” |

## 왜 글꼴로는 안 됐나

키보드로 치는 `'` 와 `"` 는 열림·닫힘을 구분하지 않는 **글자 하나**다. 그래서 글꼴을 바꿔도 여는 쪽과 닫는 쪽이 똑같이 그려진다. 이 PC에 설치된 글꼴(Consolas, 맑은 고딕, 나눔고딕, Noto Sans KR, Pretendard,
Segoe UI, Fira Sans, Georgia, Cascadia Mono, Courier New, 굴림, 바탕)을 같은 크기로 나란히 그려 확인했는데, 모두 `'a'` 의 앞뒤 따옴표 모양이 같았다. 둥근 따옴표(‘ ’ “ ”)는 서로 다른 글자라서 구분이 된다.

## 규칙

- **열림/닫힘은 바로 앞 글자로 정한다.** 줄·칸의 맨 앞, 공백 뒤, 여는 괄호(`(` `[` `{`) 뒤, 다른 여는 따옴표 뒤, 줄표(`–` `—`) 뒤는 **여는** 따옴표이고, 글자·숫자·마침표·닫는 괄호 뒤는 **닫는** 따옴표다. 단어 속 아포스트로피(`it's`)는 닫는 모양(’)이다.
- **굵게·기울임 같은 태그를 사이에 두어도 이어서 본다**: `"'''굵게'''"` → “**굵게**”.
- **문단·목록·표 칸·줄바꿈이 바뀌면 새 줄로 본다.** 앞 문단 끝 글자에 영향받지 않는다.
- 바꾸지 **않는** 곳: 코드블록(``` 와 `{{{ }}}`, 색 입힌 것 포함), 인라인 코드, 태그 속성(`style="..."`, 링크 주소 등), 스타일 선언. 그래서 코드를 복사해도 곧은 따옴표 그대로고, 링크·분류·스타일은 깨지지 않는다.
- 이미 둥근 따옴표인 글은 그대로이고, 변환을 두 번 해도 결과가 같다.

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| **곧은 따옴표(straight quote)** | 키보드로 치는 `'` `"`. 여는 것과 닫는 것이 같은 글자. |
| **둥근 따옴표(curly/smart quote)** | ‘ ’ “ ”. 여는 쪽과 닫는 쪽이 다른 글자라 모양으로 구분된다. |
| **아포스트로피** | 글자 사이의 `'`(it's, don't). 닫는 작은따옴표(’)와 같은 모양으로 쓴다. |

## 구현 위치

- `src/lib/smartQuotes.js` — 변환 규칙(`applySmartQuotes`), 화면에서 고른 글을 원문에서 찾기 위한 되돌리기(`toStraightQuotes`).
- `src/lib/wikiParser.js` — `parseWikiText` 가 결과 HTML 을 돌려주기 직전에 한 번 적용. 그래서 본문·분류 페이지·자료 카드·틀 미리보기 등 파서를 거치는 모든 뷰어 화면에 같이 적용된다.
- `src/components/ViewerPane.jsx` — Shift+더블클릭으로 편집창 위치로 점프할 때, 선택한 글의 둥근 따옴표를 곧은 따옴표로 되돌려서 원문에서 찾는다(안 그러면 `it’s` 를 원문의 `it's` 에서 못 찾는다). 실제 마우스 Shift+더블클릭으로 `it’s` 를 눌러 원문 위치로 점프하는 것을 확인했다.
- 테스트: `tests/lib/smartQuotes.test.js`.

## 알려진 한계

- **편집창은 바뀌지 않는다.** 편집창은 원문이 그대로 보이는 화면이고, 원문의 `'` 는 `'''굵게'''` 같은 문법에도 쓰여서 바꾸면 문법이 깨진다. 그래서 편집창에서는 여전히 열림/닫힘이 구분되지 않는다. (원문에 둥근 따옴표를 직접 입력하면 어느 화면에서나 구분된다.)
- **뷰어에서 글을 복사하면 둥근 따옴표가 복사된다.** 코드블록 안은 곧은 그대로다.
- 판단이 앞 글자 하나에 기대는 규칙이라 드물게 틀린다. 예: 줄임 연도 `'80s` 는 ‘80s(원래는 ’80s), 길이 표기 `5'10"` 는 5’10”.
- 플로팅 목차(화면 구석의 목차)의 제목 글은 바뀌지 않는다. `[[#제목]]` 이동이 원문 제목과 맞춰 보는 값이라서다.
- 끌 수 있는 설정은 없다(항상 켜짐).
