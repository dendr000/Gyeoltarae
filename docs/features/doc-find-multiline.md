# 문서 찾기·바꾸기 — 줄바꿈 찾기와 포커스

## 한 줄 요약

문서 찾기(Ctrl+F)와 찾아 바꾸기(Ctrl+Shift+F)의 **찾을 내용·바꿀 내용에 줄바꿈을 넣을 수 있다.** 입력칸에서 **Shift+Enter** 로 줄바꿈을 넣고, 여러 줄을 붙여 넣어도 그대로 들어간다. 보이는 대로 찾고 바꾸므로 `\n` 같은 표기는 쓰지 않는다. 표 편집기의 찾기·바꾸기(Ctrl+F)는 별개이고 바뀌지 않았다.

## 사용법

| 하고 싶은 것 | 방법 |
|---|---|
| 줄바꿈을 넣기 | 찾기 칸 또는 바꿀 내용 칸에서 **Shift+Enter** (또는 여러 줄을 복사해 붙여 넣기) |
| 다음 찾기 | **Enter** 또는 **F3** (찾기 칸) |
| 이전 찾기 | **Ctrl+Enter** 또는 **Shift+F3** (찾기 칸) — 예전의 Shift+Enter 는 줄바꿈에 쓰므로 옮겼다 |
| 하나 바꾸기 | 바꿀 내용 칸에서 **Enter** |
| 닫기 | **Esc** |

입력칸은 줄이 늘면 따라서 커진다(최대 약 120px, 넘으면 칸 안에서 스크롤).

## 예

| 하고 싶은 일 | 찾을 내용 | 바꿀 내용 |
|---|---|---|
| 빈 줄을 한 줄로 줄이기 | (빈 줄 하나) `Shift+Enter` 두 번 | `Shift+Enter` 한 번 |
| 줄 끝의 줄바꿈을 쉼표로 | `Shift+Enter` 한 번 | `, ` |
| 쉼표로 이어 쓴 글을 한 줄씩으로 | `, ` | `Shift+Enter` 한 번 |
| 두 줄짜리 덩어리를 찾기 | `가` `Shift+Enter` `나` | — |
| 본문에서 여러 줄을 복사해 그대로 찾기 | 붙여 넣기 | — |

- 줄바꿈도 **그냥 글자 하나**다. 문서에 글자 그대로 적힌 `\n`(예: 코드의 `printf("\n")`)과 헷갈리지 않는다. `\n` 두 글자를 찾으면 그 두 글자만 찾는다.
- 대소문자를 구분하지 않고, 정규식이 아니라 입력한 글자를 그대로 찾는다(이전과 같다).

## 찾은 글의 표시

- 찾기 칸에 글을 칠 때, 다음·이전으로 옮길 때 **현재 찾은 글이 편집창에 노란 배경으로 칠해지고** 그 위치로 스크롤된다. 여러 줄에 걸친 글도 칠해진다.
- **줄바꿈만 찾은 경우**에는 칠할 글자가 없어서 배경은 보이지 않는다. 그 줄 위치로 스크롤되고 `2/5` 같은 순서 표시로 확인한다.
- 찾기 바를 닫거나 글이 바뀌어 그 자리가 더 이상 찾은 글이 아니면 표시가 지워진다.

## 모두 바꾸기

- **한 번의 편집**으로 바꾼다. 줄바꿈처럼 일치하는 곳이 수천 개여도 빠르고, **Ctrl+Z 한 번**으로 전부 되돌아온다. (예전에는 일치하는 곳마다 따로 바꿔서 그 수만큼 느리고 되돌리기도 그만큼 눌러야 했다.)
- 첫 일치의 시작부터 마지막 일치의 끝까지만 다시 쓰고, 그 밖의 글은 건드리지 않는다.

## 같이 고친 오류: 찾기 칸에서 치면 문서가 덮어써지던 문제

- **이전 동작(오류)**: 찾기 칸에 첫 글자를 치면 포커스가 편집기로 넘어가고 그 글자가 선택되어 있었다. 이어서 친 글자가 **문서의 선택된 글을 덮어썼고**, Enter(다음 찾기)를 거듭 누르면 **문서에 줄바꿈이 들어갔다.** (실제 Electron 창에서 실제 키 입력으로 재현했다: 찾기 칸에 "가나"를 치니 문서의 "가"가 "나"로 바뀌었다.)
- **지금**: 찾는 동안 포커스는 찾기 칸에 그대로 있고 문서는 바뀌지 않는다. 바꾸기 뒤에도 포커스가 원래 칸으로 돌아와서 Enter 를 거듭 눌러도 안전하다. 자세히는 `docs/troubleshooting.md` 2026-10-15.

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| 줄바꿈 | 줄을 나누는 보이지 않는 글자. Enter 를 누르면 들어간다 |
| Shift+Enter | 입력칸 안에서 줄바꿈을 넣는 키(Enter 는 "다음 찾기"에 쓰인다) |
| 포커스 | 지금 키 입력을 받는 칸. 포커스가 편집기에 있으면 친 글자가 문서에 들어간다 |
| 배경판 | 편집창 뒤에 같은 글을 투명하게 겹쳐 그려 두고 줄 강조 같은 배경색을 칠하는 층 |
| CSS 사용자 지정 강조 | 글의 일부 구간에 배경색을 칠하는 브라우저 기능(`CSS.highlights`). 글 자체는 건드리지 않는다 |
