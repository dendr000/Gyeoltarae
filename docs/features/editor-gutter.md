# 편집기 줄 번호와 줄 강조 점

## 한 줄 요약

편집 모드 글 왼쪽에 **줄 번호**가 옅게 보이고, 줄 위에 마우스를 올리면 맨 왼쪽에 **점**이 나타난다. 점을 누르면 그 줄이 **강조**(제목 줄과 같은 배경)된다. 제목(`=제목=`) 줄은 자동으로 강조가 켜진 상태이고 채워진 점이 보인다.

````text
 ●  1  = 제목 =          ← 제목 줄: 자동 강조, 채워진 점
    2  첫 줄             ← 마우스를 올리면 빈 점(○) → 누르면 강조 + 채워진 점
 ●  3  둘째 줄(강조)
    4  이 줄은 길어서 화면에서 두 줄로
       접혀 보여도 번호는 한 번만
````

## 쓰는 법

| 동작 | 결과 |
|---|---|
| 줄 왼쪽 여백에 마우스를 올린다 | 그 줄의 첫 화면 줄 옆에 빈 점이 나타난다(커서 모양이 손가락으로 바뀐다) |
| 점(또는 줄 번호 근처, 왼쪽 56px 안)을 누른다 | 그 줄의 강조가 켜진다. 다시 누르면 꺼진다. **글 커서는 움직이지 않는다** |
| 제목(`=`) 줄 | 항상 켜져 있어서 눌러도 바뀌지 않는다(설정 "제목 강조"가 켜져 있을 때) |
| 코드블록(```) 안의 줄 | 기본은 꺼져 있다 — `================` 처럼 제목 모양이어도 제목으로 보지 않는다. 필요한 줄만 점을 눌러 켜고 끈다 |
| 설정 "제목 강조"를 끈 뒤의 제목 줄 | 다른 줄처럼 기본은 꺼져 있고, 점을 눌러 직접 켜고 끌 수 있다 |
| 툴바 **줄 번호** 버튼 | 줄 번호와 점 전체를 켜고 끈다(기본 켜짐, 이 PC 에 저장). 끄면 글 왼쪽 여백은 예전 크기(32px)로 돌아간다 |

- **긴 줄**이 화면에서 여러 줄로 접혀도 번호는 그 글 줄의 첫 줄에만 붙는다.
- 강조는 **앱을 켜 둔 동안만** 유지된다. 파일에는 저장되지 않고, 앱을 다시 켜면 사라진다. 문서마다 따로 기억한다.
- **문서를 고쳐도 강조가 같은 글에 붙어 있다.** 위에 줄을 넣으면 강조된 줄이 아래로 따라 내려가고, 줄을 지우면 그 줄의 강조도 사라진다. 강조된 줄을 Enter 로 나누면 앞쪽 조각에 남는다. 글자만 입력하는 고침(줄 수 그대로)은 강조를 건드리지 않는다.
- 뷰어(보기) 화면에는 영향이 없다.

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| 줄 여백(거터) | 글 왼쪽의 줄 번호·점이 놓이는 좁은 칸 |
| 논리 줄 / 화면 줄 | 글 자체의 한 줄(Enter 로 나뉨) / 너비를 넘어 접혀 보이는 한 줄 한 줄 |
| 배경판 | 입력칸 뒤에 같은 글을 보이지 않게 겹쳐 그려 제목 강조·줄 번호를 칠하는 요소 (`docs/troubleshooting.md` 2026-10-02, 10-12) |
| CSS counter | 화면에 그릴 때 요소마다 번호를 자동으로 세어 주는 CSS 기능. 줄 번호를 글에 넣지 않고 화면에서만 붙이는 데 쓴다 |

## 동작 원리

- 배경판이 글 한 줄마다 `div.eline` 하나를 만든다(예전에는 줄마다 `span`). 줄마다 block 이라서 ① 줄 번호를 그 줄의 첫 화면 줄 옆에 CSS counter 로 붙이고(`::before`), ② 점을 누른 위치의 줄을 각 줄의 `offsetTop` 으로 바로 찾을 수 있다.
- 입력칸과 배경판의 폭·글꼴·줄 높이(정수 24px)·여백·스크롤바 자리가 같아야 줄 위치가 맞는다(`tests/components/editorLayers.test.js` 가 이 값들이 같은지 지킨다). 줄 여백이 켜지면 두 요소의 왼쪽 여백을 같은 변수(`--editor-pad-left`, 64px)로 함께 넓힌다.
- 줄을 눌렀을 때 글 커서 대신 강조를 켜는 판정은 입력칸 왼쪽 56px 안(`GUTTER_WIDTH`)이다.

## 알려진 한계

- 강조는 저장되지 않는다(앱 재시작 시 사라짐).
- 마지막 줄 아래 빈 곳이나 위쪽 여백을 누르면 아무 일도 없다.
- 줄 번호 옆 점을 누르려고 마우스를 움직일 때 입력칸 왼쪽 56px 안에서는 글 커서를 옮기는 클릭이 되지 않는다(줄 시작으로 커서를 보내려면 글자 쪽을 누르거나 Home 대신 Alt+←).
- 한 번의 고침으로 같은 내용의 줄이 여러 번 바뀌는 드문 경우(붙여넣기로 반복 줄 삽입 등)에는 강조가 비슷한 이웃 줄에 붙을 수 있다.
- 계획서: [`docs/plans/editor-input-improvements.md`](../plans/editor-input-improvements.md) 의 항목 6-2.

## 제목 강조 설정과 코드블록 (0.116.0)

- 메뉴 **설정 > 제목 강조**(체크 항목, 기본 켜짐)를 끄면 제목 줄(`=제목=`)에도 자동 배경이 없다. 값은 이 PC 의 앱 설정 파일(`config.json`)의 `headingHighlight` 에 저장된다(`false` 일 때만 꺼짐).
- **코드블록(```) 안의 줄은 제목 줄로 보지 않는다.** 예전에는 코드 안의 `================` 줄이 제목처럼 생겨서 강조되었다. 판단 규칙은 `src/lib/editorHeading.js`(코드 펜스 규칙은 `codeFence.js` 와 같음, 닫히지 않은 코드블록은 글 끝까지 코드로 봄).
- 코드블록 안이나 제목 강조를 끈 상태에서 특정 줄만 강조하고 싶으면 그 줄의 점을 누른다(다시 누르면 꺼짐).
- 뷰어의 제목 렌더링은 바뀌지 않았다(이 변경은 편집 모드의 강조 표시에만 해당).
- 확인(실제 Electron 창): 제목 강조 켜짐 — 제목 줄만 자동 강조, 코드블록 안 줄은 강조 없음, 점으로 켜고 끄기 되고 제목 줄의 점은 바뀌지 않음 / 꺼짐 — 제목 줄도 자동 강조 없고 점으로 켜고 끄기 됨.
