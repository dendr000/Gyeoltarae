# 표 편집기의 행·열 중간 삽입

## 한 줄 요약

표 편집기에서 **고른 범위의 위·아래·왼쪽·오른쪽에 빈 행/열을 하나 끼울 수 있다.** 예전에는 맨 아래 "+ 행 추가", 맨 오른쪽 "+ 열 추가"밖에 없어서 중간에 넣으려면 아래 줄을 전부 손으로 옮겨야 했다.

## 쓰는 법

툴바(배경색·정렬·병합 단추가 있는 줄)의 오른쪽 끝에 단추 네 개가 있다.

| 단추 | 하는 일 |
|---|---|
| 위에 행 삽입 | 고른 범위의 **첫 행 위**에 빈 행 |
| 아래에 행 삽입 | 고른 범위의 **마지막 행 아래**에 빈 행 |
| 왼쪽에 열 삽입 | 고른 범위의 **첫 열 왼쪽**에 빈 열 |
| 오른쪽에 열 삽입 | 고른 범위의 **마지막 열 오른쪽**에 빈 열 |

- 한 칸만 골랐으면 그 칸의 위/아래/왼쪽/오른쪽이다. 여러 칸(행 번호·열 글자 클릭, Shift+클릭)을 골랐으면 범위의 가장자리 기준이다. 끼우는 것은 항상 **한 줄**이다.
- 끼운 뒤에는 **새 줄에서 같은 위치의 칸**이 골라지고 입력칸에 커서가 간다. (예: B2 에서 "아래에 행 삽입" → 새 행의 B 칸.) 바로 글을 치면 된다.
- 새 칸은 글자·색·굵기가 모두 비어 있는 일반 칸이다. 옆 칸의 서식을 물려받지 않는다.

## 병합된 칸이 있을 때

엑셀과 같은 규칙이다.

- **병합의 한가운데에 끼우면 병합이 한 칸 커진다.** 예: 세로로 3칸 병합된 칸의 둘째 행 위에 끼우면 병합이 4칸이 된다. 새 행에서 병합에 덮이는 칸은 입력칸이 없고, 병합 밖의 칸만 빈 칸으로 생긴다.
- **병합의 맨 위나 바로 아래에 끼우면 병합은 그대로**이고 병합이 밀려날 뿐이다.
- **고른 범위가 병합을 일부만 걸치고 있으면 병합 전체를 기준으로 한다.** 예: 세로 병합의 대표 칸 하나만 골라도 "아래에 행 삽입"은 병합 전체의 아래에 넣는다(병합 안쪽에 끼워서 병합이 커지는 일이 없게 한다). 병합 안쪽에 끼우고 싶으면 병합 안의 가려지지 않은 다른 칸을 고르거나 병합을 먼저 나눈다.
- 새 칸에 포커스를 줄 자리가 병합에 가려져 있으면 그 병합의 대표 칸으로 간다.

## 첫 행을 헤더로 쓸 때

"첫 번째 행을 헤더로"가 켜져 있으면 **맨 윗줄 위에는 끼울 수 없다**(단추가 비활성이고 안내가 보인다). 끼우면 새 빈 행이 첫 행이 되어 헤더 서식(굵게)이 빈 줄로 옮겨 가기 때문이다. 헤더 **아래**에는 끼울 수 있다. 위에 끼워야 하면 체크를 끄고 끼운 뒤 다시 켠다.

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| **삽입** | 기존 줄 사이에 새 줄을 끼워 넣는 것. 뒤의 줄은 한 칸씩 밀린다. |
| **병합** | 여러 칸을 하나로 합친 것. 합쳐진 칸은 왼쪽 위 칸(대표 칸) 하나가 대표한다. 덮인 칸은 입력칸이 없다. |
| **헤더 행** | 표 맨 윗줄을 제목처럼 굵게 보이게 하는 줄. |

## 한계

- 한 번에 한 줄만 끼운다(엑셀처럼 고른 줄 수만큼 끼우는 기능은 없다). 여러 줄이 필요하면 단추를 여러 번 누른다.
- 끼우기를 되돌리는 단추는 없다. 잘못 끼웠으면 그 줄의 "−"(삭제) 단추로 지운다. 모달을 "취소"하면 그 전 편집이 모두 버려진다.
- 행·열을 **이동**하거나 **복제**하는 기능은 아직 없다. (계획서 [table-editor-calculations.md](../plans/table-editor-calculations.md) 의 후보)

## 구현 위치

- `src/lib/tableGrid.js` — `insertRow`, `insertColumn`(병합 처리 포함), `expandToMerges`(고른 범위를 병합 영역까지 넓힘), `visibleCellAt`(포커스를 줄 칸 정하기), `emptyCell`. 화면과 분리한 순수 함수이며 받은 격자를 바꾸지 않는다.
- `src/components/TableEditorModal.jsx` — 툴바 단추 4개, `insertRowAt`·`insertColumnAt`(끼운 뒤 선택과 포커스), 헤더 행 위 삽입 차단(`canInsertRowAbove`).
- 테스트: `tests/lib/tableGrid.test.js` — 병합이 없는 표, 병합의 안쪽·위·아래·옆, 2x2 병합, 병합 가리킴(`mergedInto`)이 밀리는지, 여러 번 번갈아 끼우기, 범위 확장(연쇄 포함), 원래 격자 불변, 모든 병합이 앞뒤가 맞는지 검사하는 보조 함수.
