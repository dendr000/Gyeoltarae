# 문서 편집기의 [br] 단축키 (숫자패드 Enter)

## 한 줄 요약

문서 편집 모드에서 **숫자패드 Enter** 를 누르면 커서 자리에 `[br]`(줄 안 줄바꿈)이 들어간다. 그냥 Enter·Shift+Enter·Alt+Enter 는 그대로다.

## 왜 숫자패드 Enter 인가

| 키 | 문서 편집기에서 이미 하는 일 | `[br]` 용으로 쓸 수 있나 |
|---|---|---|
| Enter | 줄바꿈, 목록(`* 항목`)·번호·인용·들여쓰기 이어쓰기, 위키 링크 닫기, 추천 팝업 확정 | 아니오 |
| Shift+Enter | 목록 이어쓰기 **없이** 그냥 줄바꿈(앞에 `* ` 나 들여쓰기가 있어도 안 붙음) | 아니오 — 이 동작이 필요하다 |
| Alt+Enter | 상용구 수동 치환 | 아니오 |
| Ctrl+Enter | (문서 편집기에서는 쓰이지 않음) | 가능하지만 한 손으로 누르기 불편 |
| **숫자패드 Enter** | 브라우저에서 Enter 와 같은 키로 처리되어 같은 일을 함 | **가능** — `e.code` 가 `NumpadEnter` 로 따로 오므로 구별된다 |

## 동작

- 숫자패드 Enter 를 누르면 **커서 자리에 `[br]`** 이 들어간다(글자를 선택해 두었으면 그 글자를 `[br]` 로 바꾼다 — 글자를 치는 것과 같다).
- 입력칸의 **되돌리기(Ctrl+Z)** 로 한 번에 지워진다.
- 한글 조합 중(글자를 확정하기 전)에는 건드리지 않는다.
- 상용구·파일 추천 팝업이 떠 있을 때의 Enter 확정은 그대로이고, 숫자패드 Enter 도 같은 확정으로 쓰인다(팝업 처리가 먼저다).
- 조합키(Shift·Ctrl·Alt)가 든 숫자패드 Enter 는 해당하지 않는다.
- 규칙은 `src/lib/numpadEnter.js`(`isNumpadEnterKey`), 입력은 `EditorPane.jsx` 의 `handleKeyDown` 에서 `replaceRange` 로 한다.

## Fn+Enter 에 대하여

**Fn 은 키보드 장치가 처리해서 프로그램에는 보이지 않는다.** 노트북에서 Fn+Enter 가 숫자패드 Enter 로 오는 키보드에서는 Fn+Enter 로도 `[br]` 이 들어가고, 그냥 Enter 로 오는 키보드에서는 일반 Enter 와 같다(구별할 수 없다). 안 되면 숫자패드가 있는 키보드의 숫자패드 Enter 를 쓰거나, 다른 키를 정해서 알려 주면 바꿀 수 있다.

## 한계

- 숫자패드가 없는 키보드(Fn+Enter 도 안 되는 경우)에서는 이 단축키를 쓸 수 없다.
- 표 편집기 칸(Shift+Enter 로 `[br]`)과는 별개다. 표 편집기의 키는 바뀌지 않았다.

## 관련 파일

| 파일 | 역할 |
|---|---|
| `src/lib/numpadEnter.js` | 숫자패드 Enter 판단(순수 함수) |
| `src/components/EditorPane.jsx` | 키 처리, `[br]` 입력 |
| `tests/lib/numpadEnter.test.js`, `tests/components/editorBrKey.test.js` | 판단 규칙, 연결·처리 순서 시험 |

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| `[br]` | 위키 문법에서 줄 안 줄바꿈을 뜻하는 표시(한 문단·한 칸 안에서 줄을 바꿈) |
| 숫자패드 Enter | 키보드 오른쪽 숫자 키 묶음의 Enter. 글쇠 위치 이름(`code`)이 일반 Enter 와 달라서 프로그램이 구별할 수 있다 |
| Fn | 노트북 키보드의 기능 전환 키. 키보드 장치 안에서 처리되어 프로그램에는 보이지 않는다 |
