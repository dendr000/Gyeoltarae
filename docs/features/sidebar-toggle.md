# 사이드바 열기·닫기 (Ctrl+M)

## 한 줄 요약

**Ctrl+M** 을 누르면 왼쪽 사이드바(문서/폴더 목록, 분류·자료·틀·그림·상용구·사전)가 닫히고, 다시 누르면 열린다. 사이드바 오른쪽 가장자리의 화살표 단추를 누르는 것과 같다.

## 동작

- 편집 중(글을 쓰는 중)에도 동작한다. 글자가 입력되지는 않는다.
- 새 문서·이름 바꾸기 같은 입력 창이 떠 있는 동안은 무시한다(실수로 화면이 바뀌지 않게).
- Shift·Alt 가 같이 눌린 조합(Ctrl+Shift+M 등)은 반응하지 않는다. 한글 입력 조합 중에도 반응하지 않는다.
- 한글 자판 상태에서도 된다(물리 M 키 위치도 함께 본다). Mac 은 Cmd+M.
- 사이드바를 닫으면 본문이 창 전체 너비로 넓어진다. 열림·닫힘 상태는 저장하지 않아서, 앱을 다시 켜면 열린 상태로 시작한다.
- 단추에 마우스를 올리면 "사이드바 열기 (Ctrl+M)" / "사이드바 닫기 (Ctrl+M)" 로 단축키가 보인다.

## 관련 파일

| 파일 | 역할 |
|---|---|
| `src/lib/sidebarShortcut.js` | 눌린 키가 Ctrl+M 인지 판별하는 순수 함수 |
| `src/App.jsx` | 전역 keydown 에서 사이드바 상태를 뒤집음(Ctrl+W 탭 닫기와 같은 자리) |
| `tests/lib/sidebarShortcut.test.js` | 키 판별 9개 + 연결 확인(소스 점검) 3개 |

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| 사이드바 | 화면 왼쪽의 목록 영역. 문서·폴더 트리와 분류·자료·틀·그림·상용구·사전 목록이 들어 있다 |
| 한글 입력 조합 중 | 한글을 한 글자 만드는 도중(받침이 정해지기 전). 이때의 키는 글자 입력이라 단축키로 보지 않는다 |
| 전역 keydown | 화면 어디에 포커스가 있든 키가 눌리면 받는 처리 |
