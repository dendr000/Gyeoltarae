# 파일 이름에 못 쓰는 글자 (`:` `/` 등)

## 한 줄 요약

문서·폴더 이름에 `:` `/` `?` 같은 글자를 써도 **앱에서는 쓴 그대로 보이고**, 디스크에는 모양이 같은 **전각 글자**(`：` `／` `？`)로 저장된다. 예전에는 `_` 로 바뀌어서 "서문: 시작" 이 "서문_ 시작" 으로 보였다.

## 변환표

| 입력 | 디스크에 저장되는 글자 | 코드 |
|---|---|---|
| `<` | `＜` | U+FF1C |
| `>` | `＞` | U+FF1E |
| `:` | `：` | U+FF1A |
| `"` | `＂` | U+FF02 |
| `/` | `／` | U+FF0F |
| `\` | `＼` | U+FF3C |
| `\|` | `｜` | U+FF5C |
| `?` | `？` | U+FF1F |
| `*` | `＊` | U+FF0A |

Windows 가 이름에 허용하지 않는 글자 9개가 전부 들어 있다. 제어 문자(보이지 않는 0~31번 문자)는 모양이 같은 전각 글자가 없어서 예전처럼 `_` 로 바꾼다.

## 동작

- **만들기·이름 바꾸기**: 문서, 폴더, 분류, 틀, 자료(유형·이름), 상용구 카테고리, 이미지 이름 모두 위 표대로 저장한다.
- **보여 주기**: 폴더 트리, 탭 제목, 검색, `[[문서명]]` 링크 연결 등 앱 안의 이름은 전부 원래 글자(`:` `/`)로 되돌려서 쓴다. 탐색기에서 보면 `：` `／` 로 보인다(글자 모양만 약간 넓다).
- **이름 바꾸기에서 화면에 보이는 이름 그대로 입력**해도 같은 파일이라 실패하지 않는다.
- **분류·틀·자료·상용구 카테고리 이름의 `/`** 는 예전처럼 **계층 구분자**(`포켓몬스터/전국도감`)로 쓰이므로 전각(`／`)으로 바꾸지 않고 하위 폴더로 만든다. 이 이름들의 `:` `?` 등은 전각으로 저장하고 원래 글자로 보여 준다. 자료의 이름과 상용구 카테고리에 쓴 `/` 는 구분자와 구별할 수 없어서 `／` 그대로 보인다.
- **상용구 제목(단축어)** 은 이전 방식(`%2A` 처럼 16진수 인코딩)을 그대로 쓴다. 이 변경과 무관하다.

## 한계

- **이미 `_` 로 바뀌어 저장된 이름은 그대로 `_` 로 보인다.** 원래 무슨 글자였는지 알 수 없어서 되돌리지 않는다. 필요하면 이름 바꾸기로 다시 `:` 를 써 주면 된다.
- **전각 글자를 일부러 쓴 이름**(`：` 등)도 앱에서는 `:` 로 보인다. 앱은 둘을 같은 글자로 취급한다. (작업 폴더를 점검했을 때 전각 글자가 든 이름은 없었다.)
- 이름이 `.` 이나 공백으로 끝나는 경우, `CON`·`NUL` 같은 Windows 예약어는 이 기능이 다루지 않는다.
- 파일 탐색기나 다른 프로그램에서 직접 만든 이름에는 영향이 없다. 그쪽에서는 원래부터 이 글자들을 쓸 수 없다.

## 관련 파일

| 파일 | 역할 |
|---|---|
| `shared/fileNameChars.js` | 변환표와 `encodeFileNameChars` / `decodeFileNameChars` (메인 프로세스와 화면이 함께 씀) |
| `electron/fileSystem.js` | 이름을 저장할 때 변환, 트리·분류·틀·자료·상용구·이미지를 읽을 때 되돌림 |
| `src/store/useAppStore.js`, `src/lib/autoCategory.js`, `src/App.jsx` | 경로에서 폴더 이름을 뽑아 쓰는 곳(작품 폴더 분류, 자동 분류, 안내 문구)에서 되돌림 |
| `tests/electron/fileNameChars.test.js` | 변환 규칙, 실제 디스크 왕복(문서·폴더·분류·틀·자료·상용구·이미지), 화면 연결 소스 점검 |

## 용어 설명 (초보자용)

| 용어 | 뜻 |
|---|---|
| 전각 글자 | 한글·한자와 같은 폭으로 그려지는 넓은 영문·기호(`：` `／` `？`). 반각(보통) `:` `/` `?` 와 모양이 비슷하지만 컴퓨터는 **다른 글자**로 취급해서 파일 이름에 쓸 수 있다 |
| 되돌림(decode) | 디스크에 저장된 전각 글자를 사용자가 쓴 원래 글자로 바꿔 보여 주는 것 |
| 계층 구분자 | `포켓몬스터/전국도감` 처럼 `/` 로 상위·하위를 나누는 표시. 분류·틀 이름에서만 이 의미로 쓴다 |
